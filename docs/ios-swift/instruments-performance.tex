\section{The tools, precisely}
\begin{itemize}
  \item \textbf{Memory Graph Debugger} (Xcode debug bar, \emph{not} Instruments):
        pauses the app, snapshots every live object and its references. Purple
        \textbf{!} = leak/cycle; select an object $\to$ \emph{who holds it}. Snapshot
        only, no timeline. Enable \textbf{Malloc Stack Logging} (scheme $\to$
        Diagnostics) to get the \emph{allocation backtrace}.
  \item \textbf{Leaks} (Instruments): periodically scans for \textbf{unreachable}
        blocks — cycles, un-released CF. \textbf{Blind to abandoned memory}
        (still reachable: unbounded \texttt{Dictionary} cache, observer array).
  \item \textbf{Allocations}: every heap alloc over time. \textbf{Persistent} vs
        \textbf{Transient}; \textbf{Mark Generation} (a.k.a. heapshot) — objects
        created after a mark and still alive show under that generation. Stepwise
        growth per repetition = abandoned or leaked.
  \item \textbf{Footprint $\neq$ live bytes}: Jetsam kills on \emph{footprint}
        (dirty pages, decoded bitmaps). 4000×3000 image = 48 MB decoded, any JPEG size.
  \item \textbf{Time Profiler} \emph{samples} every thread's stack (\textasciitilde1 ms):
        statistical, cheap, no call counts. Read it: \emph{Separate by Thread}
        $\to$ main thread, \emph{Invert Call Tree}, \emph{Hide System Libraries};
        chase high \textbf{self} weight (total includes callees). 80 \% CPU on a
        background thread is harmless; 300 ms of sync I/O on main is a hang.
  \item \textbf{Hang} = main thread not servicing the run loop (Hangs instrument,
        \texttt{MXHangDiagnostic}). \textbf{Hitch} = frame presented late. Different
        metric, different fix. \textbf{Thread Performance Checker} flags priority
        inversions at runtime; \textbf{System Trace} shows \emph{why} a thread is not
        running (lock, page fault).
  \item \textbf{Hitch time ratio} = hitch ms per second of scroll: < 5 ms/s good,
        5–10 warning, > 10 critical. Commit hitch = your layout/decode on main;
        render hitch = offscreen passes (\texttt{masksToBounds}+radius, shadow w/o
        \texttt{shadowPath}), blending.
  \item \textbf{Launch}: pre-main = dyld loads/binds dylibs, ObjC setup,
        static initializers; post-main = \texttt{main} $\to$ \texttt{didFinishLaunching}
        $\to$ first frame. Measure \emph{cold} launch; the watchdog
        (\texttt{0x8badf00d}) kills a stuck launch. CI:
        \texttt{measure(metrics: [XCTApplicationLaunchMetric()])}.
  \item \textbf{MetricKit}: \texttt{MXMetricPayload} (launch, hang rate, memory,
        hitches — aggregated \textasciitilde daily) + \texttt{MXDiagnosticPayload}
        (hang/crash/CPU/disk-write stacks). Tells you \emph{which} problem to bring
        into Instruments.
\end{itemize}

\section{Example — signpost + MetricKit}
\begin{lstlisting}[language=SwiftSheet]
import os; import MetricKit
let sp = OSSignposter(subsystem: "app.feed",
                      category: .pointsOfInterest)
func loadFeed() async throws -> [Post] {
  let s = sp.beginInterval("Feed", id: sp.makeSignpostID())
  defer { sp.endInterval("Feed", s) } // ~free unless recording
  return try await api.fetchFeed()
}
final class Field: NSObject, MXMetricManagerSubscriber {
  func didReceive(_ p: [MXMetricPayload]) {}     // aggregates
  func didReceive(_ p: [MXDiagnosticPayload]) {} // hang stacks
}
MXMetricManager.shared.add(field)  // keep `field` alive
\end{lstlisting}

\section{Traps}
\begin{itemize}
  \trap{\textbf{``Leaks says 0, so no leak''} — memory still climbs = \emph{abandoned}
        memory. Allocations generations, then Memory Graph for the holder.}
  \trap{Memory Graph lives in \textbf{Xcode}, Leaks/Allocations in
        \textbf{Instruments} — three tools, three questions.}
  \trap{Profiling \textbf{Debug} or the \textbf{Simulator}: no inlining, Mac CPU —
        wrong hot spots. Profile scheme, slowest supported device. \texttt{NSLog}
        timing perturbs the run — use \texttt{os\_signpost}.}
  \trap{Dealloc test: \texttt{XCTAssertNil} inside \texttt{DispatchQueue.main.async}
        asserts \emph{nothing} — the test already returned. Assert directly or await
        an expectation.}
  \trap{Zombies: ObjC objects only, never frees. ASan + TSan: not in one run.}
  \trap{``16 ms per frame'' on a ProMotion phone: it is \textbf{8.3 ms}.}
\end{itemize}

\section{Remember}
Growth: \textbf{Leaks $\to$ Allocations $\to$ Graph}. Freeze: \textbf{Hangs $\to$ Time
Profiler (main, inverted)}. Jank: \textbf{Hitches $\to$ commit or render}. Field:
\textbf{MetricKit}. Always: \emph{one change, re-measure}.
