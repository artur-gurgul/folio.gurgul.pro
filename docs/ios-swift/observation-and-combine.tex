\sheettitle{Observation · Combine · cancellables}{ios-swift · folio}

\oneliner{Four ways to observe on iOS — \textbf{NotificationCenter} (broadcast bus),
\textbf{KVO} (one \texttt{NSObject} property), \textbf{Combine} (typed streams +
operators + \emph{demand}), \textbf{\texttt{@Observable}} (per-property read tracking,
iOS 17). Every one hands you a \textbf{lifetime object}; what matters is
\textbf{who owns it} and \textbf{whether the closure owns you back}.}

\section{How Combine works}
\begin{itemize}
  \item \textbf{Publisher} = a recipe; nothing runs until a \textbf{Subscriber} attaches
        — a cold one (\texttt{dataTaskPublisher}) re-runs per subscriber
        (\texttt{share()} to multicast; Subjects are hot).
        \texttt{Future} is the exception: runs \emph{eagerly}, once
        (wrap in \texttt{Deferred}).
  \item \textbf{Demand} is backpressure: \texttt{receive(\_:)} returns \emph{extra}
        demand (additive). \texttt{sink}/\texttt{assign} ask \texttt{.unlimited}.
  \item \textbf{Subjects}: \texttt{PassthroughSubject} — no value, events only;
        \texttt{CurrentValueSubject} — holds \texttt{.value}, replays it to new
        subscribers (state). Dead after \texttt{send(completion:)}.
  \item \textbf{\texttt{@Published}} emits on \textbf{willSet}: inside the sink,
        \texttt{self.x} is still the \emph{old} value — use the argument.
  \item \textbf{Schedulers}: \texttt{receive(on:)} moves \emph{downstream} delivery
        (put it just before UI work); \texttt{subscribe(on:)} moves the
        \emph{upstream} subscribe / request / cancel work. \texttt{DispatchQueue.main}
        over \texttt{RunLoop.main} (paused while the user drags a scroll view).
\end{itemize}

\section{Operators — the pairs that get confused}
\begin{itemize}
  \item \texttt{debounce} = emit last after a \emph{quiet gap} (search box);
        \texttt{throttle} = at most one per interval (\texttt{latest:} first/last).
  \item \texttt{combineLatest} = latest of each on any change, silent until
        \emph{all} emitted once; \texttt{zip} = pairs by index; \texttt{merge} =
        interleave same type.
  \item \texttt{flatMap} keeps every inner alive (\texttt{maxPublishers:});
        \texttt{map}+\texttt{switchToLatest} cancels the stale one.
  \item \texttt{catch} swaps in a fallback \emph{publisher}; \texttt{replaceError}
        a value. Both still end the upstream — do it \emph{inside} the inner
        publisher. \texttt{removeDuplicates} needs \texttt{Equatable}.
\end{itemize}

\section{Example — typeahead VM, no cycle}
\begin{lstlisting}[language=SwiftSheet]
final class SearchVM: ObservableObject {
  @Published var query = ""
  @Published private(set) var results: [Item] = []
  private var bag = Set<AnyCancellable>()
  init(api: API) {
    $query
     .debounce(for: .milliseconds(300),
               scheduler: DispatchQueue.main)
     .removeDuplicates()
     .map { api.search($0).replaceError(with: []) }
     .switchToLatest()             // drop the stale request
     .receive(on: DispatchQueue.main)
     .assign(to: &$results)        // no self capture, no token
    // LEAK: .sink { self.results = $0 }.store(in: &bag)
    // FIX:  .sink { [weak self] in self?.results = $0 }
  }
}
\end{lstlisting}

\section{Traps}
\begin{itemize}
  \trap{\textbf{The cycle:} \texttt{self} $\to$ \texttt{bag} $\to$
        cancellable $\to$ sink closure $\to$ \texttt{self}. \texttt{deinit} never runs,
        so the bag never cancels. \texttt{[weak self]}.}
  \trap{\texttt{assign(to:\textbackslash.x, on: self)} retains \texttt{self} strongly.
        \texttt{assign(to: \&\$x)} (iOS 14) ties the subscription to the
        \texttt{@Published} storage — no cycle, no \texttt{AnyCancellable}.}
  \trap{Dropped cancellable (\texttt{\_ = pub.sink\{\}}) cancels at once — ``my sink
        never fires''.}
  \trap{Block-based NotificationCenter: keep the token and \textbf{call
        \texttt{removeObserver(token)}}; do not rely on releasing it. The block is
        retained by the center — \texttt{[weak self]} inside.}
  \trap{An error reaching the sink \emph{terminates} the subscription: a search box
        stops working after the first failed request.}
  \trap{\texttt{subscribe(on:)} does \emph{not} make the sink run on that queue.}
\end{itemize}

\section{Remember}
\textbf{Values right, demand left, cancellable owns the chain, closure must not own
\texttt{self}.} \texttt{@Published} = willSet. Passthrough = event, CurrentValue = state.
