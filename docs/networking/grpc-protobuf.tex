\sheettitle{gRPC \& Protocol Buffers — wire format, evolution, HTTP/2}{networking · folio}

\oneliner{\textbf{Protocol Buffers} is a schema-first binary encoding: every field travels as
\textbf{(field number, wire type) + value} — names never do, so the \textbf{field numbers are the
contract}. \textbf{gRPC} is RPC over \textbf{HTTP/2}: \ct{POST /pkg.Service/Method}, length-prefixed
protobuf messages on one stream, the result in \textbf{trailers} (\ct{grpc-status}); unary + three
streaming kinds, \textbf{deadlines} built in.}

\hd{Protocol Buffers}
\begin{itemize}
  \item \textbf{Wire types}: 0 \ct{VARINT} (int32/64, uint, sint, bool, enum) · 1 \ct{I64} (fixed64,
        double) · 2 \ct{LEN} (string, bytes, messages, packed repeated) · 5 \ct{I32} (fixed32, float);
        3/4 = deprecated groups.
  \item \textbf{Field numbers} 1–536,870,911 (19000–19999 reserved by protobuf). 1–15 cost a
        \textbf{1-byte} tag, 16–2047 two — give hot fields 1–15.
  \item \textbf{Defaults are not sent} (proto3): \ct{0}, \ct{""}, \ct{false} look exactly like ``unset''.
        Need the difference? \ct{optional} (explicit presence, \ct{hasX}) or a wrapper message.
  \item Field order is irrelevant; a non-repeated field seen twice: \textbf{last one wins}.
        \textbf{Unknown fields are preserved} and re-serialised (proto3).
  \item No self-description: without the \ct{.proto} the bytes are numbers and blobs. Max 2\,GiB.
\end{itemize}

\hd{Schema evolution — old apps live for years}
\begin{itemize}
  \item \textbf{Never change or reuse a field number.} Deleting a field? \ct{reserved 3;} and
        \ct{reserved "email";} so nobody reuses it.
  \item \textbf{Add} fields with new numbers: old clients skip them (unknown), new clients read
        defaults from old data. Safe type swaps: \ct{int32/uint32/int64/uint64/bool}.
  \item \textbf{Renaming} is wire-safe (names are not sent) but breaks the \textbf{JSON} mapping.
  \item \textbf{Enums}: first value \ct{0 = X\_UNSPECIFIED}; old apps get unknown numbers (Swift:
        \ct{.UNRECOGNIZED(Int)}) — handle a default.
  \item Breaking: singular $\leftrightarrow$ repeated, scalar $\leftrightarrow$ message. Add a new
        field / RPC or a \ct{pkg.v2} service instead; gate in CI (\ct{buf breaking}).
\end{itemize}

\hd{Example — contract + Swift client (gRPC Swift 2)}
\begin{lstlisting}[language=Proto]
syntax = "proto3";
package demo;
message User {
  int32 id = 1;  string name = 2;  repeated int32 tags = 3;
  bool active = 4;
  optional string nickname = 6;    // presence: hasNickname
  reserved 5; reserved "email";    // deleted in v1.4
}
service UserService {
  rpc GetUser (GetUserRequest) returns (User);            // unary
  rpc Watch (WatchRequest) returns (stream Event);        // server
  rpc Upload (stream Chunk) returns (UploadResult);       // client
  rpc Chat (stream Msg) returns (stream Msg);             // bidi
}
\end{lstlisting}

\hd{gRPC}
\begin{itemize}
  \item \textbf{Four kinds} (see the \ct{service}): each call is one HTTP/2 stream on a shared connection.
  \item \textbf{Deadlines}: \ct{grpc-timeout} (units \ct{H M S m u n}; \ct{500m} $=$ 500\,ms);
        propagate the remaining budget downstream. Expiry $\to$ \ct{DEADLINE\_EXCEEDED}.
  \item \textbf{Load balancing}: one long-lived HTTP/2 connection pins every call to one backend
        behind an L4 balancer — use L7 (Envoy) or client-side balancing.
  \item \textbf{Browsers} can't read trailers $\to$ \textbf{gRPC-Web} (via a proxy) or
        \textbf{Connect} (plain POST, HTTP/1.1 OK, JSON or binary).
  \item \textbf{Swift}: \textbf{gRPC Swift 2} (Feb 2025): async/await, Swift 6, pluggable transports
        (HTTP/2 on SwiftNIO, in-process for tests). \textbf{Connect-Swift}: Connect / gRPC-Web /
        gRPC over URLSession (gRPC needs \ct{ConnectNIO}).
\end{itemize}

\hd{Traps}
\begin{itemize}
  \trap{Reusing a deleted field number: old apps misread new data — silent corruption.}
  \trap{Checking the HTTP status of a gRPC call — it is 200; read \ct{grpc-status}.}
  \trap{Retrying \ct{DEADLINE\_EXCEEDED} blindly — the server may have finished it.}
\end{itemize}

\hd{Remember}
\textbf{``Numbers on the wire; never reuse one; status in trailers.''}
