\sheettitle{Engineering for bad networks — offline, flaky, captive, metered}{networking · folio}

\oneliner{On a phone the network is a \textbf{variable}: it vanishes (tunnel), \textbf{degrades}
(one bar, 20\,\% loss), \textbf{lies} (a captive portal answers every request with a login page),
\textbf{costs money} (cellular, Low Data Mode) and \textbf{changes under you} (Wi-Fi $\to$ LTE).
Give every request a \textbf{timeout}, a \textbf{retry rule}, an \textbf{idempotency story} and an
\textbf{offline behaviour} — then prove it under a simulated bad network.}

\hd{Retries and idempotency}
\begin{itemize}
  \item Retry \textbf{transient} errors only (\ct{timedOut}, \ct{networkConnectionLost},
        \ct{cannotConnectToHost}, 502/503/504, 429 with \ct{Retry-After}); never 4xx logic errors.
        Exponential backoff + full jitter + a cap.
  \item URLSession already retries \textbf{idempotent} requests when a reused connection drops
        (QA1941) — don't stack your own immediate retry on top.
  \item A timeout means \textbf{unknown}, not failed: POSTs carry an \ct{Idempotency-Key} created
        once per user action and reused on every attempt.
\end{itemize}

\hd{Detecting connectivity}
\begin{itemize}
  \item \ct{NWPathMonitor}: \ct{status} (\ct{.satisfied} / \ct{.unsatisfied} / \ct{.requiresConnection}),
        \ct{unsatisfiedReason}, \ct{isExpensive}, \ct{isConstrained} (iOS 13),
        \ct{usesInterfaceType(.wifi)}. It sees \emph{routes}, not the internet.
  \item \textbf{Don't pre-flight}: attempt, handle the error; retry on \emph{signals} (path
        satisfied, foreground), not only timers.
  \item \textbf{Low Data Mode}: \ct{allowsConstrainedNetworkAccess = false} makes the task fail with
        \ct{URLError.networkUnavailableReason == .constrained} — retry with a lighter request
        (also \ct{.expensive}, \ct{.cellular}).
  \item \textbf{Captive portals}: the OS probes a known URL (Apple: \ct{captive.apple.com}) and shows
        the sign-in sheet; until then requests get redirects, HTML instead of JSON (decode errors on a
        ``200''), or a certificate for the wrong host. Standard: RFC 8908/8910.
\end{itemize}

\hd{Example — path + session setup}
\begin{lstlisting}[language=SwiftSheet]
let monitor = NWPathMonitor()
monitor.pathUpdateHandler = { path in
  Task { @MainActor in
    net.isOnline = path.status == .satisfied
    net.lowData  = path.isConstrained     // Low Data Mode
    net.metered  = path.isExpensive       // cellular, hotspot
    if net.isOnline { await outbox.flush() }  // jittered inside
  }
}
monitor.start(queue: DispatchQueue(label: "net.path"))

let cfg = URLSessionConfiguration.default
cfg.waitsForConnectivity = true            // wait, don't fail -1009
cfg.allowsConstrainedNetworkAccess = false // honour Low Data Mode
cfg.timeoutIntervalForRequest = 20         // idle gap, not total
// delegate: urlSession(_:taskIsWaitingForConnectivity:) -> "Waiting..."
\end{lstlisting}

\hd{Coalescing, queuing, cancelling}
\begin{itemize}
  \item \textbf{Single-flight}: one in-flight \ct{Task} per cache key (an actor holding
        \ct{[Key: Task<Value, Error>]}); five cells asking for the same avatar make one request.
  \item \textbf{Cancel} what the user left: tie requests to the view's lifetime (\ct{.task} modifier,
        stored \ct{Task} cancelled in \ct{deinit}) — bytes for a dismissed screen are waste.
  \item \textbf{Prioritise}: \ct{URLSessionTask.priority}; visible cells before prefetch; separate
        sessions for bulk vs interactive (\ct{httpMaximumConnectionsPerHost}).
  \item \textbf{Outbox} for writes: persist the intent first (optimistic UI), send in order with
        idempotency keys, remove on 2xx, surface permanent 4xx to the user. Background upload:
        a \ct{.background} session (always waits for connectivity).
  \item \textbf{Batch} small writes (analytics) — one radio wake, one request.
\end{itemize}

\hd{Traps}
\begin{itemize}
  \trap{``Check reachability, then request'' — races, and a captive portal is ``reachable''.}
  \trap{Retry-on-timeout for a payment POST without an idempotency key $\to$ double charge.}
  \trap{\ct{timeoutIntervalForRequest} is an \emph{idle} timer: a slow trickle never trips it.}
  \trap{Testing only in the simulator on office Wi-Fi: no radio, no loss, no NAT64.}
\end{itemize}

\hd{Remember}
\textbf{``Attempt, don't ask; bound every wait; retry what is safe; queue what must survive.''}
