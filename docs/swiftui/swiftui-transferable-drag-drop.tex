\oneliner{\textbf{\texttt{Transferable}} (iOS 16) describes \textbf{once}, as an \textbf{ordered list of
representations keyed by \texttt{UTType}}, how a value leaves and enters the app; \texttt{ShareLink},
\texttt{.draggable}, \texttt{.dropDestination}, \texttt{PasteButton} and \texttt{PhotosPicker} all consume it —
replacing separate \texttt{UIActivityItemSource}, \texttt{NSItemProvider} and \texttt{UIPasteboard} code.}

\section{How it works}
\begin{itemize}
  \item \textbf{Representations} (result builder, order = preference): \textbf{Codable} (JSON by default);
        \textbf{Data} (\texttt{exporting:}/\texttt{importing:} closures, whole blob in RAM); \textbf{File} (a file URL,
        lazy — export returns \texttt{SentTransferredFile}, import gets \texttt{ReceivedTransferredFile} whose
        \texttt{.file} is \textbf{temporary — copy it before returning}); \textbf{Proxy} (reuse \texttt{String},
        \texttt{URL}, \texttt{Data}, \texttt{Image}). Modifiers: \texttt{.suggestedFileName}, \texttt{.exportingCondition}.
  \item \textbf{Drag \& drop}: \texttt{.draggable(item) \{ preview \}}; \texttt{.dropDestination(for: T.self)
        \{ items, location in … return true \} isTargeted: \{ \}}. Only offered types that match \texttt{T} arrive.
  \item \textbf{Share}: \texttt{ShareLink(item:subject:message:preview: SharePreview(title, image:))}.
  \item \textbf{Paste}: \texttt{PasteButton(payloadType:)} — the tap is consent, so no ``Allow Paste'' alert (iOS 16
        alerts on programmatic reads of another app's content; UIKit: \texttt{UIPasteControl}).
  \item \textbf{\texttt{PhotosPicker(selection:matching:)}} (16) runs \textbf{out of process} — no photo-library permission;
        the app sees only picked items. \texttt{await item.loadTransferable(type:)} (in \texttt{.task(id: item)})
        returns \texttt{T?}: \texttt{nil} = type not offered, \texttt{throws} = load failed. Video → your own
        \texttt{FileRepresentation} type.
  \item \textbf{Files}: \texttt{.fileImporter} hands back \textbf{security-scoped} URLs outside your sandbox;
        \texttt{.fileExporter} writes a \texttt{FileDocument} (17 adds a \texttt{Transferable} form).
  \item \textbf{UIKit bridge}: \texttt{UIDragItem(itemProvider:)}, \texttt{UIDropInteraction},
        \texttt{UIActivityViewController}. \texttt{NSItemProvider} gained \texttt{register(\_:)} for a
        \texttt{Transferable} and \texttt{loadTransferable(type:)} (16); older SwiftUI: \texttt{.onDrag} / \texttt{.onDrop(of:)}.
\end{itemize}

\section{Example — one type, every surface}
\begin{lstlisting}[language=SwiftSheet]
extension UTType {
  static let note = UTType(exportedAs: "com.acme.note") }
struct Note: Codable, Transferable {
  var title: String; var body: String
  static var transferRepresentation: some TransferRepresentation {
    CodableRepresentation(contentType: .note)   // richest first
    ProxyRepresentation(exporting: \.body)      // fallback: text
  } }
Text(note.title).draggable(note)
Color.clear.dropDestination(for: Note.self) { notes, _ in
  inbox += notes; return true }
ShareLink(item: note, preview: SharePreview(note.title))
\end{lstlisting}

\section{Security-scoped URLs}
\begin{lstlisting}[language=SwiftSheet]
.fileImporter(isPresented: $open,
              allowedContentTypes: [.pdf]) { r in
  guard case .success(let url) = r,
        url.startAccessingSecurityScopedResource() else { return }
  defer { url.stopAccessingSecurityScopedResource() } // balance!
  let data = try? Data(contentsOf: url)
  saved = try? url.bookmarkData()  // persist THIS, not the path
}
\end{lstlisting}
Next launch: \texttt{URL(resolvingBookmarkData:…, bookmarkDataIsStale:)}; stale $\Rightarrow$ re-create the
bookmark while you have access. Unbalanced \texttt{start} calls leak kernel resources.

\section{Traps}
\begin{itemize}
  \trap{\textbf{Silent drop rejection}: \texttt{dropDestination(for: URL.self)} never fires for a photo from Photos —
        it offers image data, not a file URL. Accept what is actually offered.}
  \trap{\textbf{200 MB video as \texttt{DataRepresentation}} — materialised in RAM, memory spike / jetsam. Use
        \texttt{FileRepresentation}.}
  \trap{\textbf{\texttt{ReceivedTransferredFile.file} used after the closure} — gone; copy it inside the closure.}
  \trap{\textbf{Everyone receives plain text}: the custom \texttt{UTType} is not declared in Info.plist, or the text
        representation is listed first.}
  \trap{\textbf{Saving the imported path} instead of a bookmark: works in the callback, fails next launch.}
\end{itemize}

\section{Which representation?}
{\footnotesize
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{18mm}>{\raggedright\arraybackslash}p{54mm}@{}}
\toprule
\textbf{Codable} & your own model between your apps / instances \\
\textbf{Data} & small binary in a standard format (PNG, PDF) \\
\textbf{File} & anything big, or already on disk (video, documents) \\
\textbf{Proxy} & ``as text / as URL'' fallback, no encoding code \\
\bottomrule
\end{tabular}}

\section{Remember}
\textbf{``Describe once, richest first, big things as files, borrowed files by bookmark.''}
