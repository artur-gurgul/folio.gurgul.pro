\sheettitle{Crashes \& symbolication}{build · folio}

\oneliner{A crash report says \textbf{what} killed the process (\emph{Exception Type +
Termination Reason}), \textbf{where} (the crashed thread's backtrace of
\emph{image + offset}), and \textbf{which build} (the \emph{UUID} of every binary image).
Symbolication turns offsets into \texttt{function + file:line} using the \textbf{dSYM whose
UUID matches} — no matching dSYM, no names, ever.}

\section{Exception type → cause → first move}
{\footnotesize
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{21mm}>{\raggedright\arraybackslash}p{32mm}>{\raggedright\arraybackslash}p{22mm}@{}}
\toprule
\textbf{Type (signal)} & \textbf{Meaning} & \textbf{First move} \\
\midrule
\texttt{EXC\_BAD\_ACCESS} (SIGSEGV / SIGBUS) & bad pointer: freed object, \texttt{unowned}, unsafe pointer; \texttt{KERN\_INVALID\_ADDRESS} & Zombies, ASan \\
\texttt{EXC\_BREAKPOINT} (SIGTRAP) & Swift trap: \texttt{!} on nil, index out of range, \texttt{fatalError}, \texttt{precondition}, \texttt{as!}, overflow & top app frame; the \emph{Fatal error} msg \\
\texttt{EXC\_CRASH} (SIGABRT) & \texttt{abort()}: uncaught \texttt{NSException}, C \texttt{assert} & \emph{Last Exception Backtrace} \\
\texttt{EXC\_CRASH} (SIGKILL) \texttt{0x8badf00d} & watchdog: main thread blocked at launch / resume / suspend & main stack; I/O off main \\
\texttt{0xdead10cc} & held a file or SQLite lock while being suspended & \texttt{beginBackgroundTask}, release first \\
no crash log & \textbf{jetsam} (memory limit) & iOS 27 MetricKit \texttt{.memoryException} \\
\bottomrule
\end{tabular}}

\section{How it works}
\begin{itemize}
  \item Reports are JSON \texttt{.ips} (iOS 15+). Always read in order: exception type →
        termination reason → crashed thread (main?) → first frame in \emph{your} image.
  \item \textbf{dSYM} = DWARF debug info split out of the stripped binary
        (\texttt{DEBUG\_INFORMATION\_FORMAT = dwarf-with-dsym}); the archive keeps it.
        Find one by UUID: \texttt{mdfind "com\_apple\_xcode\_dsym\_uuids == <UUID>"}.
  \item \textbf{Bitcode} is gone (deprecated in Xcode 14): the App Store no longer
        recompiles, so the \emph{archive's} dSYM is the shipped one. Old bitcode builds
        needed \emph{Download dSYMs} from App Store Connect.
  \item Where crashes arrive: Xcode \textbf{Organizer} (opt-in users, delayed,
        auto-symbolicated if the dSYM is known) · Crashlytics/Sentry (upload dSYMs from a
        build phase or CI) · \textbf{MetricKit}.
  \item \textbf{MetricKit} (iOS 27): one \texttt{MetricManager} instance;
        \texttt{diagnosticReports} is an \texttt{AsyncSequence} of \texttt{DiagnosticReport}
        (\texttt{Codable}); \texttt{result}: \texttt{.crash} · \texttt{.hang} ·
        \texttt{.cpuException} · \texttt{.diskWriteException} · \texttt{.appLaunch} ·
        \texttt{.memoryException} (memory-limit kills). Before: \texttt{MXMetricManager} +
        subscriber \texttt{didReceive(\_:)} — deprecated in 27.2. Call stacks come
        \emph{unsymbolicated}. Diagnostics arrive immediately (iOS 15+), metrics at most daily.
\end{itemize}

\section{Reproduce and triage}
\begin{itemize}
  \item Memory crashes: scheme → Diagnostics → \textbf{Zombie Objects} (message to a freed
        object), \textbf{Address Sanitizer} (use-after-free, overflow),
        \textbf{Thread Sanitizer} (races; not with ASan), Main Thread Checker.
  \item Hangs/watchdog: Time Profiler, Hangs instrument. OOM: Allocations, Memory Graph,
        downsample images, drop caches on memory warning.
\end{itemize}

\section{Example}
\begin{lstlisting}[language=SwiftSheet]
let metrics = MetricManager()        // iOS 27: hold ONE instance
Task {
  for await report in metrics.diagnosticReports { // never throws
    switch report.result {
    case .crash, .hang, .memoryException:
      send(report)                 // Codable; stacks unsymbolicated
    default: break
    }
  }
}
\end{lstlisting}
\begin{lstlisting}[style=plain]
dwarfdump --uuid MyApp.app/MyApp MyApp.app.dSYM  # equal?
\end{lstlisting}

\section{Traps}
\begin{itemize}
  \trap{Swift traps are \textbf{not} SIGABRT: on arm64 they are \texttt{EXC\_BREAKPOINT
        (SIGTRAP)} (\texttt{EXC\_BAD\_INSTRUCTION}/SIGILL on Intel simulators).}
  \trap{``No crash log'' $\neq$ no crash — jetsam kills leave only a \texttt{JetsamEvent} log.}
  \trap{\texttt{0x8badf00d} is not a bug at the top frame: it is where the main thread
        \emph{was} when time ran out.}
  \trap{Optimized builds inline code: a frame may show the caller's line or skip callees.}
  \trap{Never trust ``I rebuilt the same commit'' — different UUID, dSYM useless.}
\end{itemize}

\section{Remember}
\textbf{``What · Where · Which build.''} Type tells the \emph{category}, the backtrace the
\emph{place}, the UUID the \emph{dSYM}. \texttt{8badf00d} = too slow, \texttt{dead10cc} = lock on suspend.
