\sheettitle{Cross-language FFI — everything meets at the C ABI}{cs · folio}

\oneliner{Languages call each other through the \textbf{C ABI}: an unmangled symbol, the
platform's C calling convention, C types (scalars, pointers, plain structs). One side
\textbf{exports} C-looking functions (\texttt{extern "C"}, Go \texttt{//export}, Swift
\texttt{@c}); the other \textbf{links} them (\texttt{-l}, cgo, module map) or
\textbf{\texttt{dlopen}s} them and declares the types (ctypes, Ruby FFI). Every allocation
keeps \emph{one} owner.}

\section{Libraries and the linker}
\begin{itemize}\raggedright
  \item \textbf{Static} \texttt{.a} = archive of \texttt{.o} (\texttt{ar rcs}); the linker copies in
        only members that resolve an undefined symbol. GNU ld searches each archive
        \textbf{once, where it stands} (\texttt{-lfoo} \emph{after} its users); LLD remembers
        archives, so order does not bite there.
  \item \textbf{Dynamic} \texttt{.so}/\texttt{.dylib}/\texttt{.dll} (\texttt{cc -shared -fPIC};
        macOS \texttt{-dynamiclib}): the loader maps + binds it at launch;
        \texttt{dlopen}+\texttt{dlsym} at run time = what ctypes/FFI do.
  \item Both in one dir, \texttt{-lexample} takes the \texttt{.so}/\texttt{.dylib} (GNU ld, ld64):
        ``static'' links, then fails to launch elsewhere — use \texttt{-Bstatic} or the
        \texttt{.a} path. Module map \texttt{link "example"} = \texttt{-lexample}.
\end{itemize}

\section{Example — one header for C, C++ and cgo}
\begin{lstlisting}[language=C, style=ffi]
#ifdef __cplusplus
extern "C" {        // C++ sees C linkage; C never sees this
#endif
void  PrintHello(const char *u);      // C types only
char *MakeGreeting(const char *name); // malloc'd ...
void  FreeGreeting(char *p);          // ... freed HERE
#ifdef __cplusplus
}
#endif
\end{lstlisting}
\begin{lstlisting}[language=GoSheet, style=ffi]
// #cgo LDFLAGS: -L${SRCDIR} -lexample
// #include <stdlib.h>
// #include "example.h"
import "C"       // the comment right above is the preamble
import "unsafe"
func main() {
    s := C.CString("Hi")             // malloc'd C copy
    defer C.free(unsafe.Pointer(s))  // Go frees it
    C.PrintHello(s) }
\end{lstlisting}

\section{Go as the library}
\begin{lstlisting}[language=GoSheet, style=ffi]
//export SayHello
func SayHello(s *C.char) { fmt.Println(C.GoString(s)) }
func main() {}  // package main required; never called
// go build -buildmode=c-shared -o libhello.so  (c-archive: .a)
\end{lstlisting}
Only \texttt{//export}ed functions are callable; the Go runtime ships inside and starts as a
global constructor (\texttt{c-archive}) or when the \texttt{.so} loads; \texttt{libhello.h} is
written beside it. With \texttt{//export} the preamble may only \emph{declare} (it is copied
into two C files).

\section{Python and Ruby — load at run time}
\begin{lstlisting}[language=Python, style=ffi]
lib = CDLL("./libexample.so")         # dlopen
lib.PrintHello.argtypes = [c_char_p]  # now type-checked
lib.PrintHello(b"Hi")                 # bytes -> char*
lib.MakeGreeting.restype = c_void_p   # default int truncates
p = lib.MakeGreeting(b"Ann"); print(c_char_p(p).value) # copy
lib.FreeGreeting(c_void_p(p))  # a bare int goes as C int
\end{lstlisting}
Ruby FFI: \texttt{attach\_function :PrintHello, [:string], :void} — return type required.
\texttt{CDLL} \textbf{releases the GIL} (\texttt{PyDLL} keeps it). cffi \texttt{cdef()} takes
declarations (no \texttt{\#include}); \emph{ABI mode} \texttt{dlopen}s, \emph{API mode} compiles
an extension (faster).

\section{JVM — JNI}
\begin{itemize}\raggedright
  \item Kotlin \texttt{external fun hello(s: String)} in \texttt{com.ex.Lib} +
        \texttt{System.loadLibrary("example")} ($\to$ \texttt{libexample.so}) bind C glue written
        against \texttt{jni.h}, named as in \textcolor{sheetBlue}{2}, args
        \texttt{(JNIEnv*, jobject, jstring)} — or \texttt{RegisterNatives} in \texttt{JNI\_OnLoad}.
  \item \texttt{JNIEnv*} is \textbf{per thread} (a thread C started: \texttt{AttachCurrentThread});
        a \texttt{jobject} is a \textbf{local ref}, dead after the call (\texttt{NewGlobalRef});
        strings come as \textbf{modified UTF-8}. No glue: FFM API (JDK 22) + \texttt{jextract}.
\end{itemize}

\section{Memory ownership and errors}
\begin{itemize}\raggedright
  \item \textbf{Whoever allocates, frees} — \texttt{FreeGreeting}, Go \texttt{C.free}, Rust
        \texttt{CString\hbox{:}\hbox{:}from\_raw} (never C \texttt{free()}).
  \item C keeps no Go pointer past the call unless pinned (\texttt{runtime.Pinner}); a ctypes
        \texttt{CFUNCTYPE} must stay referenced while C may call it.
  \item \textbf{Errors}: catch in the wrapper, return a code — a Rust panic out of
        \texttt{extern "C"} aborts (1.81+), a C++ exception reaching Swift terminates.
\end{itemize}

\section{Traps}
\begin{itemize}\raggedright
  \trap{No \texttt{extern "C"} $\to$ \emph{undefined reference to \texttt{PrintHello}}; an
        unguarded \texttt{extern "C"} in a header breaks C/cgo.}
  \trap{ctypes: no \texttt{restype} truncates a 64-bit pointer to \texttt{int}; no
        \texttt{argtypes}: a \texttt{str} goes as \texttt{wchar\_t*} (C prints ``H'');
        \texttt{restype = c\_char\_p} returns a bytes copy — no pointer left to free.}
  \trap{C types differ: \texttt{long} 4\,B on Windows x64, 8\,B on Linux/macOS; plain
        \texttt{char} unsigned on Linux/Android arm64; Apple arm64 puts variadic args on the
        stack (ctypes: set \texttt{argtypes}).}
\end{itemize}

\section{Remember}
\textbf{Speak C at the border: plain names, C types, one owner.}
