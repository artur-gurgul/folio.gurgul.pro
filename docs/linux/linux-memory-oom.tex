\sheettitle{Linux memory — accounting, reclaim, swap, OOM}{linux · folio}

\oneliner{Idle RAM is lent to the \textbf{page cache}, so ``free'' is always small; the number that
matters is \textbf{MemAvailable}. Under pressure the kernel \textbf{reclaims} — drops clean file
pages, writes dirty ones, swaps anonymous ones — first in the background (\textbf{kswapd}), then
inside the allocating task (\textbf{direct reclaim}, a stall); when reclaim stops making progress it
\textbf{OOM-kills} the task with the highest \ct{oom\_score}, system-wide or inside the
\textbf{cgroup} that hit \ct{memory.max}.}

\hd{Per process: VSZ, RSS, PSS, USS}
{\setlength{\tabcolsep}{3pt}
\begin{tabular}{@{}>{\ttfamily}p{6mm}>{\raggedright\arraybackslash}p{70mm}@{}}
\toprule
VSZ & all mapped virtual memory, touched or not — nearly meaningless \\
RSS & resident pages; \textbf{shared pages counted in full} in every process \\
PSS & each shared page divided by its number of sharers — sums to the real total \\
USS & unshared pages only (\ct{smem}'s term) $\approx$ what its exit frees \\
\bottomrule
\end{tabular}}\par
1000 private pages + 1000 shared with one other process: RSS 2000, PSS 1500, USS 1000.
\ct{/proc/PID/smaps\_rollup} sums all mappings: \ct{Rss}, \ct{Pss}, \ct{Pss\_Anon/File/Shmem},
\ct{Private\_*}, \ct{Swap}, \ct{SwapPss}.

\hd{\ct{/proc/meminfo} — the lines that matter}
{\setlength{\tabcolsep}{3pt}
\begin{tabular}{@{}>{\ttfamily}p{16mm}>{\raggedright\arraybackslash}p{60mm}@{}}
\toprule
MemFree & truly unused — low is normal \\
MemAvailable & estimate for new programs \emph{without swapping}: \textbf{alert on this} \\
Buffers & raw disk-block cache (small) \\
Cached & page cache \emph{plus} tmpfs and shmem; not \ct{SwapCached} \\
Shmem & tmpfs, \ct{/dev/shm}, shared anon: swap-backed, on the \textbf{anon} LRU \\
SwapCached & swapped in, copy still in swap: dropped without a write \\
Dirty & waiting for writeback (\ct{Writeback}: being written) \\
AnonPages & heap, stacks — reclaimable only by swapping \\
SReclaimable & slab caches (dentries, inodes) that can be shrunk \\
Unevictable & \ct{mlock()}, ramfs — never reclaimed \\
Committed\_AS & memory promised; \ct{CommitLimit} binds in mode 2 \\
Zswapped & original size held in zswap (\ct{Zswap}: compressed) \\
\bottomrule
\end{tabular}}\par
\textbf{MemAvailable} = MemFree $-$ reserves + file LRU $-$ min(file/2, $\Sigma$\ct{low}) +
reclaimable slab $-$ min(slab/2, $\Sigma$\ct{low}): half the cache is assumed to stay, and
\textbf{Shmem never counts}. \ct{free}(1): \ct{used} = total $-$ available, \ct{buff/cache} =
Buffers + Cached + SReclaimable, \ct{shared} = Shmem.

\hd{Evidence — read it in this order}
\begin{lstlisting}[language=ShellSheet]
$ free -m
       total   used   free  shared  buff/cache  available
Mem:   15890  10410    310    1450        6460       5480
$ cat /proc/pressure/memory

full avg10=4.02 avg60=2.55 avg300=0.61 total=30123456
$ journalctl -k -g oom            # or dmesg -T
nginx invoked oom-killer: gfp_mask=..., order=0, oom_score_adj=0
oom-kill:constraint=CONSTRAINT_NONE,...,task=java,pid=4242,uid=1000
Out of memory: Killed process 4242 (java) total-vm:9123456kB,
 anon-rss:6012345kB, file-rss:1024kB, shmem-rss:0kB,
 UID:1000 pgtables:12800kB oom_score_adj:0
$ cat /proc/4242/oom_score              # 0..2000, top dies
$ echo -500 > /proc/4242/oom_score_adj  # -1000 = exempt
\end{lstlisting}
\ct{nginx} allocated, \ct{java} died; a victim cannot log its own SIGKILL — only the kernel log
and \ct{memory.events} record it. \textbf{PSI}: \ct{some} = share of time $\ge$1 task stalled on
memory, \ct{full} = all non-idle tasks at once (lost work); \ct{total} in $\mu$s; per cgroup
\ct{memory.pressure}. Trigger: write \ct{some 150000 1000000} (150\,ms per 1\,s) and \ct{poll()}.

\hd{Overcommit — \ct{vm.overcommit\_memory}}
\begin{itemize}
  \item \textbf{0} (default): refuse only a single request larger than RAM + swap.
        \textbf{1}: never refuse. \textbf{2} strict: \ct{Committed\_AS} $\le$ \ct{CommitLimit} =
        (RAM $-$ hugetlb) $\times$ \ct{overcommit\_ratio} (50)\,\% + swap; \ct{malloc}, \ct{mmap},
        \ct{fork} get \ct{ENOMEM} instead of a later kill. Charged: private writable and shared
        anon mappings; read-only and shared file maps are free.
  \item In 0/1 memory is promised, not given: \ct{malloc(1~GB)} succeeds, pages arrive on first
        touch — the OOM kill happens at a page fault, far from the allocation.
\end{itemize}

\hd{Page cache, writeback, reclaim}
\begin{itemize}
  \item Flusher threads start at \ct{dirty\_background\_ratio} 10\,\%; the writer itself is
        throttled at \ct{dirty\_ratio} 20\,\% (of free + reclaimable); data dirty $>$30\,s is
        written on the 5\,s wakeup.
  \item LRU lists: active/inactive $\times$ file/anon; a \textbf{refault} = an evicted page
        needed again. \textbf{MGLRU} (\ct{/sys/kernel/mm/lru\_gen/enabled}): generations instead
        of two lists; \ct{min\_ttl\_ms}=N protects the last N\,ms of working set — OOM instead of
        thrashing.
  \item \ct{drop\_caches} 1 page cache · 2 slab · 3 both; skips dirty pages (\ct{sync} first). A
        benchmark tool, never a fix.
\end{itemize}

\columnbreak

\hd{The OOM killer}
\begin{itemize}
  \item \textbf{Badness} = RSS + swap entries + page-table pages, + \ct{oom\_score\_adj}
        $\times$ allowed/1000 — so \ct{oom\_score} spans 0--2000. ``Allowed'' = RAM + swap, or the
        cpuset / mempolicy nodes, or the memcg limit (\ct{constraint=} in the log).
  \item Skipped: \ct{oom\_score\_adj} \pdfonly{\textminus}\htmlonly{−}1000, tasks already reaped, tasks mid-\ct{vfork}.
        One victim, SIGKILL; after a 2\,s grace the \textbf{oom\_reaper} frees its anon memory even
        if it is stuck. Going below the last value a \ct{CAP\_SYS\_RESOURCE} task set needs it too.
  \item \ct{vm.panic\_on\_oom}: 0 kill · 1 panic unless cpuset/mempolicy/memcg-constrained · 2
        always. \ct{oom\_kill\_allocating\_task}=1: kill the caller, no scan. SysRq-\ct{f}: run
        the OOM killer now. Exit status \textbf{137} = 128 + SIGKILL (9).
\end{itemize}

\hd{cgroups, Kubernetes, systemd}
\begin{itemize}
  \item \ct{memory.events}: \ct{high} (throttled), \ct{max}, \ct{oom}, \ct{oom\_kill},
        \ct{oom\_group\_kill}; also \ct{memory.peak}, \ct{memory.reclaim} (proactive). Charged:
        anon, page cache, tmpfs, kernel objects, socket buffers — to the cgroup that \emph{first
        touched} the page, even after the task moves. Group kills spare \pdfonly{\textminus}\htmlonly{−}1000 tasks.
  \item \textbf{Kubernetes}: limit = the container's \ct{memory.max}; over it $\to$
        \ct{OOMKilled}, exit 137, restart per \ct{restartPolicy}. On cgroup v2 the kubelet sets
        \ct{memory.oom.group} per container (\ct{singleProcessOOMKill: false}).
        \ct{oom\_score\_adj}: Guaranteed \pdfonly{\textminus}\htmlonly{−}997, BestEffort 1000, Burstable
        min(max(2, 1000 $-$ 1000·request/node RAM), 999).
  \item \textbf{systemd}: \ct{MemoryMin/Low/High/Max/SwapMax/ZSwapMax=}, \ct{OOMScoreAdjust=},
        \ct{OOMPolicy=} \ct{continue} · \ct{stop} · \ct{kill} (= group kill).
        \textbf{systemd-oomd} (default on since Fedora 34) watches only units with
        \ct{ManagedOOMSwap=kill} / \ct{ManagedOOMMemoryPressure=kill}: it kills cgroups holding
        $>$5\% of swap, largest first, or the most reclaim activity first;
        \ct{ManagedOOMPreference=avoid|omit}.
\end{itemize}

\hd{Swap, zram, zswap}
{\setlength{\tabcolsep}{3pt}
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{8mm}>{\raggedright\arraybackslash}p{37mm}>{\raggedright\arraybackslash}p{30mm}@{}}
\toprule
\textbf{what} & \textbf{how} & \textbf{when full}\\
\midrule
swap & partition or file on disk; cold \emph{anon} pages leave RAM & OOM once RAM is gone too\\
zram & \ct{/dev/zramN}, a compressed RAM disk used \emph{as} swap (Fedora 33+) & \ct{backing\_dev}: idle or incompressible pages to disk\\
zswap & compressed cache \emph{in front of} disk swap, zsmalloc pool & LRU writeback to the swap device\\
\bottomrule
\end{tabular}}\par
\ct{vm.swappiness} 0--200, default 60: relative I/O cost of swap vs file paging; 100 = equal,
$>$100 suits zram/zswap; \textbf{0 does not disable swap} (it swaps once free + file $<$
\ct{high}). \ct{page-cluster} 3 = 8-page swap readahead. Without swap, anon memory is pinned: only
file cache — code pages too — can go, so the box thrashes, then OOMs.

\hd{Transparent huge pages}
\ct{enabled}: \ct{always} · \ct{madvise} (only \ct{MADV\_HUGEPAGE} ranges) · \ct{never}; build
default (Kconfig: \ct{always}). \ct{defrag}: \ct{always} · \ct{defer} · \ct{defer+madvise} · \ct{madvise} (default) ·
\ct{never}. 2\,MB pages cut TLB misses; cost compaction stalls, \textbf{khugepaged} work, bloat.
\textbf{mTHP}: \ct{hugepages-<size>kB/enabled}, PMD size \ct{inherit}, others \ct{never}. Redis:
\ct{never}, and \ct{overcommit\_memory=1} for \ct{fork()} snapshots.

\hd{Traps}
\begin{itemize}
  \trap{A full tmpfs or \ct{/dev/shm} shows as \ct{Cached} yet is not reclaimable — only swap or
        \ct{rm} frees it.}
  \trap{\ct{memory.high} alone never kills: a leaking task is throttled forever unless an agent
        (systemd-oomd, kubelet) acts on PSI or \ct{memory.events}.}
\end{itemize}

\hd{Remember}
\textbf{Read available, not free. Reclaim $\to$ thrash $\to$ kill; \ct{high} throttles, \ct{max} kills.}
