\sheettitle{HealthKit — authorization, data model, queries, sync}{ios-platform · folio}

\oneliner{HealthKit is an \textbf{on-device, encrypted store} shared by apps, reached via \textbf{one long-lived \ct{HKHealthStore}}. Access is \textbf{per type and per direction}
(read / share); \textbf{read status is never revealed} — a denied read looks like ``no data''.
Data = \textbf{immutable samples}; totals come from \textbf{statistics queries}
(they de-duplicate iPhone + Watch), changes from \textbf{observer + anchored} ones.}

\hd{How it works}
\begin{itemize}
  \item \textbf{Setup}: HealthKit capability (+ \emph{Clinical Health Records} only if used); plist
        \ct{NSHealthShareUsageDescription} (\textbf{read}), \ct{NSHealthUpdateUsageDescription}
        (\textbf{write}). Xcode adds \ct{healthkit} to \emph{required device capabilities} — remove it if optional.
  \item \textbf{Availability}: \ct{isHealthDataAvailable()} first. iPhone, Watch, visionOS; iPad only from
        \textbf{iPadOS 17}; macOS links the framework but gets \ct{false}. \textbf{One store per app}, kept.
  \item \textbf{Authorization}: \ct{requestAuthorization(toShare:read:)}, per type. The sheet shows only for
        types \emph{not yet decided}, then returns at once. \textbf{Success $=$ processed, not granted}.
        \ct{authorizationStatus(for:)} reports \textbf{share only}; \ct{getRequestStatusForAuthorization}
        says whether a prompt would show.
  \item \textbf{Read denied} $\Rightarrow$ you see only \emph{your own} samples — so ``has diabetes data''
        cannot leak through an error.
  \item \textbf{Writing}: build an \ct{HKQuantitySample}, \ct{save}. You may \textbf{delete only what you
        saved}. To ``edit'': \ct{HKMetadataKeySyncIdentifier} + a higher \ct{HKMetadataKeySyncVersion}
        $\to$ HealthKit replaces the old sample. \ct{HKMetadataKeyWasUserEntered} marks manual entries.
  \item \textbf{Locked device}: reads fail with \ct{errorDatabaseInaccessible}; \textbf{saves still
        work} — staged, merged on unlock.
\end{itemize}

\hd{Example — steps per day, last 7 days (async, iOS 15.4+)}
\begin{lstlisting}[language=SwiftSheet]
let store = HKHealthStore()             // one per app, keep it
let steps = HKQuantityType(.stepCount)
guard HKHealthStore.isHealthDataAvailable() else { return }
try await store.requestAuthorization(toShare: [], read: [steps])
// returning = sheet dismissed, NOT "granted"; denied read = empty
let cal = Calendar.current
let start = cal.date(byAdding: .day, value: -6, to: cal.startOfDay(for: .now))!
let week = HKQuery.predicateForSamples(withStart: start, end: .now)
let q = HKStatisticsCollectionQueryDescriptor(
  predicate: .quantitySample(type: steps, predicate: week),
  options: .cumulativeSum,             // merges iPhone + Watch overlap
  anchorDate: start,                   // buckets start at midnight
  intervalComponents: DateComponents(day: 1))
let days = try await q.result(for: store)  // results(for:) = live updates
days.enumerateStatistics(from: start, to: .now) { s, _ in
  print(s.startDate, s.sumQuantity()?.doubleValue(for: .count()) ?? 0) }
\end{lstlisting}

\hd{Workouts}
\textbf{watchOS}: \ct{HKWorkoutSession} + \ct{HKLiveWorkoutBuilder}. \textbf{iOS 17}:
\ct{HKWorkoutSession} on iPhone/iPad (a Watch session can \ct{startMirroringToCompanionDevice}).
\textbf{iOS 26}: \ct{HKLiveWorkoutBuilder} on iPhone/iPad — standalone: \ct{prepare()} (countdown) $\to$
\ct{startActivity} + \ct{beginCollection} $\to$ delegate streams metrics $\to$ \ct{stopActivity}, end,
\ct{finishWorkout()}. Heart rate needs an external strap; the phone locks $\to$ show a Live Activity.
Logging one after the fact: \ct{HKWorkoutBuilder}.

Async \ct{\ldots QueryDescriptor} (iOS 15.4+): \ct{result(for:)} one-shot, \ct{results(for:)} an
\ct{AsyncSequence} of updates. Persist \ct{HKQueryAnchor} (\ct{NSSecureCoding}).

\hd{Clinical records and App Review}
\ct{HKClinicalRecord}: FHIR (allergies, meds, labs), \textbf{read-only}, own plist key.
\textbf{5.1.3(i)}: no health data for ads, marketing or data mining; third parties only for health research,
with permission. \textbf{(ii)}: no false data, \textbf{no personal health information in iCloud}.
\textbf{2.5.1}: health/fitness use, integrate with Health.

\hd{Traps}
\begin{itemize}
  \trap{``Was read denied?'' is unknowable — design the empty state instead.}
  \trap{Observer created in a view controller: a background wake finds no query. Register at launch.}
  \trap{\ct{doubleValue(for:)} with an incompatible unit throws an ObjC exception — a crash, not a Swift error.}
  \trap{Buckets anchored at ``now'' split days at 14:32 — anchor at midnight.}
\end{itemize}

\hd{Remember}
\textbf{Write status is visible, read status never is; statistics merge, samples don't; the observer says
\emph{that}, the anchor says \emph{what}.}
