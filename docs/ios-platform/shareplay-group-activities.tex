\sheettitle{SharePlay — Group Activities}{ios-platform · folio}

\oneliner{\textbf{SharePlay} = your app's activity shared over a \textbf{FaceTime call} or \textbf{Messages
conversation} (and, iOS 17, \textbf{AirDrop} nearby). You define a \ct{Codable} \ct{GroupActivity};
one person \ct{activate()}s it; the system hands a \ct{GroupSession} to \emph{every} participant's
\ct{sessions()} stream; each app \ct{join()}s and syncs through \textbf{AVPlayer's playback coordinator}
(media), \textbf{GroupSessionMessenger} (small messages) or \textbf{GroupSessionJournal} (files). All
session data is \textbf{end-to-end encrypted}; there is no server of yours in the loop.}

\hd{How it works}
\begin{itemize}
  \item \textbf{Capability}: \emph{Group Activities} $\to$ entitlement \ct{com.apple.developer.group-session}.
        Framework since iOS 15 / macOS 12 / tvOS 15 / visionOS 1.
  \item \textbf{Activity} = \ct{struct: GroupActivity} (\ct{Codable}, sent to every device) with
        \ct{static activityIdentifier} (needed once you have several types) and \ct{metadata}:
        \ct{title}, \ct{subtitle}, \ct{previewImage} (\ct{CGImage}), \ct{fallbackURL} (join from a web
        browser), \ct{type} (\ct{.watchTogether}, \ct{.listenTogether}, \ct{.playTogether},
        \ct{.createTogether}, … iOS 17 added shop/read/learn/workout), \ct{supportsContinuationOnTV}.
  \item \textbf{Start}: \ct{GroupStateObserver().isEligibleForGroupSession} (\ct{ObservableObject}) —
        true in a call/conversation. \ct{prepareForActivation()} asks the user:
        \ct{.activationPreferred} $\to$ \ct{activate()} · \ct{.activationDisabled} $\to$ do it
        \emph{locally} · \ct{.cancelled} $\to$ nothing. Not eligible $\to$ present
        \ct{GroupActivitySharingController} (iOS 15.4): it invites people and starts the call.
  \item \textbf{Share sheet / AirDrop}: \ct{ShareLink(item: activity, …)} with a \ct{Transferable}
        activity; UIKit: \ct{NSItemProvider.registerGroupActivity(\_:)} (15.4) in
        \ct{UIActivityViewController} or a responder's \ct{activityItemsConfiguration} — the
        latter is what \textbf{SharePlay over AirDrop} (iOS 17) finds.
  \item \textbf{Receive} on \emph{every} device, including the starter: \ct{for await s in
        X.sessions()} from launch (e.g. \ct{.task} on the root view). Store it, build UI +
        sync objects, \emph{then} \ct{join()}.
  \item \textbf{Change content}: set \ct{session.activity} (\ct{@Published}, only when
        \ct{.joined}); everyone observes \ct{\$activity} and loads the same item.
  \item Also on the session: \ct{isLocallyInitiated} (am I the starter?),
        \ct{requestForegroundPresentation()} (the activity needs your app on screen).
\end{itemize}

\hd{Example — watch together + reactions}
\begin{lstlisting}[language=SwiftSheet]
struct WatchTogether: GroupActivity {
  let movie: Movie                           // Codable payload
  var metadata: GroupActivityMetadata {
    var m = GroupActivityMetadata(); m.type = .watchTogether
    m.title = movie.title; m.fallbackURL = movie.webURL; return m }
}
func start(_ a: WatchTogether) async throws {  // Alice's tap
  switch await a.prepareForActivation() {
  case .activationPreferred: _ = try await a.activate()
  case .activationDisabled: playLocally(a.movie)
  default: break }                           // .cancelled
}
for await s in WatchTogether.sessions() {    // every device
  session = s; load(s.activity.movie)        // keep strong refs
  player.playbackCoordinator.coordinateWithSession(s)
  messenger = GroupSessionMessenger(session: s, deliveryMode: .unreliable)
  s.join()
  Task { for await (r, ctx) in messenger.messages(of: Reaction.self) {
           show(r, from: ctx.source) } }     // ctx.source: Participant
}
\end{lstlisting}

\hd{Three sync channels}
{\footnotesize
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{19mm}>{\raggedright\arraybackslash}p{27mm}>{\raggedright\arraybackslash}p{25mm}@{}}
\toprule
\textbf{Channel} & \textbf{Carries} & \textbf{Watch out} \\ \midrule
\ct{AVPlayer} \ct{.playback} \ct{Coordinator} (15) & rate, time, pause, seek — intercepted and imposed on the others
  & does \textbf{not} manage the queue; stalls/interruptions \emph{suspend} coordination \\
\ct{GroupSession} \ct{Messenger} (15) & your \ct{Codable}/\ct{Data} to \ct{.all} or \ct{.only(p)};
  $\le$ \textbf{256 KB}; \ct{.reliable} (default) or \ct{.unreliable} (16, UDP)
  & live traffic only — no history for late joiners \\
\ct{GroupSession} \ct{Journal} (17) & \ct{Transferable} files: \ct{add}, \ct{attachments}, \ct{load}
  & available to everyone \emph{whenever} they joined; not for fast messages \\
\bottomrule
\end{tabular}}\par
\textbf{Local detour}: \ct{let s = player.playbackCoordinator.beginSuspension(for: …)} — rewind or 2× for
yourself, \ct{s.end()} rejoins the group's time. Same movie, different URLs per device (CDN, locale)?
\ct{AVPlayerPlaybackCoordinatorDelegate} \ct{playbackCoordinator(\_:identifierFor:)} returns a shared id.

\hd{Privacy and platforms}
\begin{itemize}
  \item E2E encrypted; Apple sees neither content nor playback events, nor your app's identity.
        \ct{Participant.id} is a \ct{UUID}, no personal data — map people to accounts yourself.
  \item iOS 26: \ct{Participant.isNearbyWithLocalParticipant} (same room vs remote).
        \textbf{visionOS}: spatial Personas, \ct{session.systemCoordinator}, \ct{SpatialTemplate}
        for seating; visionOS 26 shares with people nearby.
\end{itemize}

\hd{Traps}
\begin{itemize}
  \trap{\ct{activate()} with no call/conversation \textbf{fails} — check eligibility, fall back to
        \ct{GroupActivitySharingController} or the share sheet.}
  \trap{The coordinator syncs \emph{time}, not \emph{which item}: drive item changes through
        \ct{session.activity}, or players drift to different movies.}
  \trap{Late joiner sees an empty canvas: the messenger never replays. Diff
        \ct{\$activeParticipants}, send a snapshot to \ct{.only(new)} — or keep state in the Journal.}
  \trap{\ct{.unreliable} is best-effort: cursors and drags, never moves or scores.}
  \trap{\ct{.invalidated} is terminal: drop the session, messenger and tasks. \ct{join()} only once
        your UI can show the activity.}
  \trap{``SharePlay needs my backend'' — no: FaceTime's infrastructure relays it; you only need
        content every device can load.}
\end{itemize}
