\sheettitle{Wallet passes · .pkpass, signing, updates}{ios-platform · folio}

\oneliner{A Wallet pass is a \textbf{signed zip} (\ct{.pkpass}): \ct{pass.json} + images +
\ct{manifest.json} (SHA-1 of every file) + a \textbf{PKCS \#7 signature} of the manifest made with your
\textbf{Pass Type ID certificate}. Wallet surfaces it when \textbf{relevant} (time, place) and keeps it
current via \textbf{your web service}: an \textbf{empty APNs push} says ``changed'', the device \emph{pulls}.}

\hd{How it works}
\begin{itemize}
  \item \textbf{One style key} in \ct{pass.json}: \ct{boardingPass} (+ \ct{transitType} air/train/bus/boat/generic) ·
        \ct{eventTicket} · \ct{coupon} · \ct{storeCard} · \ct{generic}. Each holds \ct{headerFields},
        \ct{primaryFields}, \ct{secondaryFields}, \ct{auxiliaryFields}, \ct{backFields}
        (\ct{key}, \ct{label}, \ct{value}, \ct{changeMessage}).
  \item \textbf{Richer layouts} via \ct{preferredStyleSchemes} + \ct{semantics}: poster event ticket
        (iOS 18, \ct{"posterEventTicket"}), \ct{semanticBoardingPass} (iOS 26, live flight status),
        poster generic (iOS 27). Keep the legacy fields — older iOS renders those.
  \item \textbf{Identity} = \ct{passTypeIdentifier} + \ct{serialNumber}.
        \textbf{Barcodes}: first one the device can show wins — QR, PDF417, Aztec, Code128 (iOS 27 adds
        EAN-13, Code 39, Codabar, ITF).
  \item \textbf{Relevance}: \ct{relevantDates} (start/end; single \ct{relevantDate} deprecated) ·
        \ct{locations} ($\leq$ 10) + \ct{maxDistance} · \ct{beacons} — the \emph{system} decides to surface it.
  \item \textbf{Lifecycle}: \ct{expirationDate}, \ct{voided} (used coupon), \ct{associatedStoreIdentifiers}
        + \ct{appLaunchURL}.
\end{itemize}

\hd{Barcode vs NFC}
A barcode is a picture — a screenshot works anywhere. An \textbf{NFC pass} adds \ct{nfc}
\{\ct{message} ($\leq$ 64 bytes), \ct{encryptionPublicKey} (P-256), \ct{requiresAuthentication}\}: the
terminal speaks Apple's \textbf{Value Added Services} protocol and only the reader holding the private
key can read it. Needs a \textbf{special NFC entitlement from Apple} — you cannot self-enable it.

\hd{Signing — the build step (server side)}
\begin{enumerate}
  \item Portal: register \ct{pass.com.example.ticket}, download its \textbf{Pass Type ID certificate}.
  \item Write \ct{manifest.json} = \{\ct{"pass.json": "<sha1 hex>"}, \ldots\} for \emph{every} file,
        localized ones included.
  \item \ct{signature} = detached PKCS \#7 (CMS) of \ct{manifest.json}, cert + private key, with the
        \textbf{WWDR intermediate} embedded.
  \item Zip, rename \ct{.pkpass}, serve with its MIME type $\to$ Safari/Mail offer \emph{Add to Apple Wallet}.
\end{enumerate}
The same cert sends the \textbf{update pushes}: expired $\to$ no new passes \emph{and} no updates.

\hd{In the app — PassKit}
\begin{lstlisting}[language=SwiftSheet]
let pass = try PKPass(data: pkpassData)   // throws on a bad signature
let lib = PKPassLibrary()
if lib.containsPass(pass) { _ = lib.replacePass(with: pass) }
else if let vc = PKAddPassesViewController(pass: pass) {
  present(vc, animated: true) }            // user confirms "Add"
\end{lstlisting}
\ct{addPasses(\_:)} for several; \ct{PKAddPassButton} for the badge. Reading passes
(\ct{passes()}) needs the \ct{com.apple.developer.pass-type-identifiers} entitlement and returns
\textbf{only your} pass types.

\hd{Verify with Wallet (identity)}
\ct{PKIdentityAuthorizationController} (iOS 16, iPhone, special entitlement): ask for fields of an ID
in Wallet; the user approves; an \textbf{encrypted CBOR} response goes to your \textbf{server} to decrypt.

\hd{Traps}
\begin{itemize}
  \trap{Expecting data in the push: it is \ct{\{\}}; forget to bump \ct{lastUpdated} $\to$ nothing pulled.}
  \trap{Editing a file after hashing, or one missing from the manifest $\to$ invalid pass.}
  \trap{No WWDR intermediate in the signature $\to$ rejected with no detail.}
  \trap{New \ct{serialNumber} for the same ticket = a second pass, not an update.}
  \trap{\ct{sharingProhibited} hides Share, it is not DRM; a QR screenshots fine — NFC doesn't.}
  \trap{Poster ticket without legacy fields $\to$ blank pass on older iOS.}
\end{itemize}

\hd{Remember}
\textbf{``Hash every file, sign the manifest; push nothing, pull everything.''}
