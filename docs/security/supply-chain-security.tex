\sheettitle{Supply-chain security — from a maintainer's laptop to your app}{security · folio}

\oneliner{Your app ships code from hundreds of people you never vetted, and a package manager
\textbf{runs some of it at install time}. Attackers go for the weakest link: a \textbf{maintainer account}
(phishing, stolen token), a \textbf{look-alike name}, an \textbf{install script}, a \textbf{public name shadowing a
private one}. Defence is layered: \textbf{pin} (lockfile + \ct{npm ci}), \textbf{delay} (release cooldown),
\textbf{don't execute} (no dependency scripts), \textbf{verify} (provenance), \textbf{inventory} (SBOM) and
\textbf{rehearse} the response. OWASP Mobile Top 10 (2024) \textbf{M2}.}

\hd{How it works}
\begin{itemize}
  \item \textbf{Typosquatting}: a look-alike such as \ct{react-native-reanimate} next to the real name.
  \item \textbf{Dependency confusion} (Birsan, 2021\unverified): internal \ct{acme-utils} not on npm $\to$ attacker
        publishes it publicly with a higher version $\to$ resolver prefers it. Fix: \textbf{scoped} names
        (\ct{@acme/}) mapped to your registry, and own the scope on npm.
  \item \textbf{Install scripts}: \ct{preinstall}/\ct{install}/\ct{postinstall} run with your user's rights
        on laptops and CI — where the tokens live. That is how worms spread.
  \item \textbf{Provenance}: \ct{npm publish \dd provenance} (automatic with trusted publishing) signs, via
        \textbf{Sigstore}, a statement linking the tarball to a repo commit + CI run;
        \ct{npm audit signatures} checks it. A new version \emph{missing} it is a red flag.
\end{itemize}

\hd{Example — lock it down (npm / pnpm)}
\begin{lstlisting}
# .npmrc
ignore-scripts=true               # opt specific deps back in
@acme:registry=https://npm.acme.example/   # no confusion
# CI
npm ci                  # exact lockfile; fails if it drifts
npm audit signatures    # registry signatures + provenance
npm sbom --sbom-format cyclonedx > sbom.json
# pnpm-workspace.yaml  (pnpm 10: dep scripts OFF by default)
minimumReleaseAge: 1440   # minutes; default in pnpm 11
allowBuilds:              # pnpm 11 (was onlyBuiltDependencies)
  esbuild: true
\end{lstlisting}

\hd{Pinning beyond npm}
\begin{itemize}
  \item \textbf{SPM}: commit \ct{Package.resolved} (the Git commit per package + binary checksums);
        \ct{binaryTarget} needs a checksum. Xcode fails the build if an XCFramework's signature changes.
  \item \textbf{CocoaPods}: commit \ct{Podfile.lock}, \ct{pod install} (not \ct{update}) in CI. Trunk goes
        \textbf{read-only 2 Dec 2026} — move to SPM.
  \item \textbf{Gradle}: dependency locking + \ct{verification-metadata.xml} (checksums / PGP).
  \item \textbf{Bots}: Dependabot / Renovate for small, reviewable PRs; Renovate \ct{minimumReleaseAge} $=$ cooldown.
  \item \textbf{SBOM}: CycloneDX (OWASP) or SPDX (ISO/IEC 5962) — answers ``are we affected?'' in minutes.
\end{itemize}

\hd{npm itself changed (after Sep 2025)}
Classic tokens \textbf{revoked 9 Dec 2025}; write tokens are granular, $\leq$ 90 days (7-day default); 2FA
for local publishing, WebAuthn over TOTP; \textbf{trusted publishing} (OIDC from GitHub Actions / GitLab)
means no token to steal.

\hd{Incident response}
Find affected versions in \emph{every} lockfile and image $\to$ did an install run in the window? $\to$ treat
that machine/runner as compromised: \textbf{rotate every secret it held} $\to$ rebuild from clean $\to$ pin a safe
version $\to$ ship, and invalidate bundles built in the window.

\hd{Traps}
\begin{itemize}
  \trap{``We pin in \ct{package.json}'' — transitive deps still float. The \textbf{lockfile} is the pin, and
        \ct{npm install} in CI may rewrite it.}
  \trap{\ct{npm audit} finds \emph{known CVEs}, not a malicious version published an hour ago.}
  \trap{Build-time only? chalk's payload shipped \emph{inside} web bundles to end users.}
  \trap{Removing the bad version is not recovery — the stolen tokens still work.}
\end{itemize}

\hd{Remember}
\textbf{``Pin, delay, don't execute, verify, inventory — and rotate when it happens.''}
