\begin{itemize}
  \item \textbf{Bearer}: non-connectable adverts — AD \ct{0x2A} message · \ct{0x2B} beacon · \ct{0x29}
        PB-ADV; nodes scan all the time. GATT only through a \textbf{Proxy}: service \ct{0x1828}
        (provisioning \ct{0x1827}, solicitation \ct{0x1859}). No links, no LE pairing.
  \item \textbf{Managed flooding}: TTL 7 bits — 0 never relayed, arriving as 1 not relayed again,
        2–127 relayable; a message cache drops repeats. \textbf{Directed forwarding} (1.1) discovers
        paths per subnet and mixes with flooding.
  \item \textbf{Node $\to$ elements} (one unicast address each) $\to$ \textbf{models}: a client
        \emph{publishes} to an address, servers \emph{subscribe} — a group is a topic.
  \item \textbf{Features}: Relay · Proxy · Friend (queues for its LPN) · \textbf{Low Power} (sleeps,
        polls its Friend; PollTimeout 1\,s … $\approx$96\,h in 100\,ms steps).
  \item \textbf{Keys}, AES-128-CCM twice: \textbf{NetKey} (network layer, $\le$4096 subnets — relays
        forward but cannot read) · \textbf{AppKey} (payload, bound per model, $\le$4096) ·
        \textbf{DevKey} (per node, from the provisioning ECDH, never on air).
  \item \textbf{Size}: unsegmented access message $\le$11\,B; segmented 12\,B $\times$ $\le$32 = 384\,B
        upper transport $\to$ $\le$380\,B (32-bit TransMIC) / 376\,B. Control, not bulk.
  \item \textbf{Replay}: SEQ 24 bits per element + 32-bit \textbf{IV Index}; a persisted replay list per
        source. SEQ lasts 2.66 years at one message / 5\,s, 19 days at / 100\,ms, then IV Update via
        beacons (up to 96\,h to spread; started only by primary-subnet nodes).
  \item \textbf{Provisioning} (PB-ADV / PB-GATT, often a phone): beacon with 128-bit Device UUID $\to$
        algorithm choice $\to$ P-256 ECDH (device key in band, or OOB / X.509) $\to$ OOB auth $\to$
        NetKey + unicast address; both sides derive the DevKey.
\end{itemize}

\begin{itemize}
  \item \textbf{Radio}: IEEE 802.15.4 (2006 / 2015), 2.4\,GHz O-QPSK, channels 11–26, 250\,kbit/s,
        $\le$127-byte frames, CSMA-CA, MAC acks + retries, MAC-layer encryption. \textbf{6LoWPAN} (RFC
        4944 / 6282) compresses and fragments IPv6 (min MTU 1280); MLE replaces neighbour discovery.
  \item \textbf{Roles}: Router (``Mesh Extender'' in 1.4) · \textbf{Leader} (one per partition, hands
        out router IDs, re-elected) · REED (promotes below 16 routers) · FED · MED (radio on) ·
        \textbf{SED} (polls its parent) · SSED (listens on a schedule) · Border Router (any FTD, several
        allowed). All attach as a child first (MLE Parent / Child ID Request).
  \item \textbf{Routing}: proactive distance-vector (like RIPng) in MLE adverts; $\le$32 active routers
        (64 IDs, kept at 16–23), $\le$511 children each. Link quality 3 / 2 / 1 / 0 $\to$ cost 1 / 2 /
        4 / $\infty$; path cost = minimum sum.
  \item \textbf{Addresses}: mesh-local ULA /64 — \textbf{ML-EID} (stable, for apps) + \textbf{RLOC}
        (moves with topology) + ALOC anycast; BR prefixes via SLAAC / DHCPv6. \textbf{Dataset}:
        channel, PAN ID (2\,B), XPAN ID (8\,B), name, prefix, Network Key, PSKc; joining = DTLS
        Joiner $\to$ Commissioner via a Joiner Router.
  \item \textbf{Border router}: IPv6 both ways; devices register services by unicast \textbf{SRP},
        the BR re-advertises them over \textbf{mDNS}; Border Agent for outside commissioners.
  \item \textbf{1.3.0} (19 Jul 2022): standard BRs, SRP / DNS-SD — what Matter needs. \textbf{1.4}
        (Sep 2024): \textbf{credential sharing} (BR shows a 9-digit one-time code $\to$ ePSKc $\to$
        DTLS $\to$ dataset; required in 1.4 BRs) · NAT64 / DNS64 + DHCPv6-PD · diagnostics · TREL
        (802.15.4 frames in UDP/IPv6 over Wi-Fi / Ethernet) · TCAT (TLS + X.509 over BLE, bulk setup).
\end{itemize}

\section{Traps}
\begin{itemize}
  \trap{``Matter = Thread'' — app layer vs one transport; no BR, no way off the mesh.}
  \trap{A NetKey holder cannot forge app messages, but can flood, or fill replay lists with SEQ
        \ct{0xFFFFFF} so nodes ignore everyone until the next IV Update.}
  \trap{Mesh starter kit with a fixed NetKey — the owner can never rekey; ship a provisioning
        database and unique keys instead.}
  \trap{Mesh guests get their own NetKey + AppKey; a Key Refresh that skips them revokes them.}
  \trap{A BR per vendor, each forming its own network: share Thread credentials.}
\end{itemize}
