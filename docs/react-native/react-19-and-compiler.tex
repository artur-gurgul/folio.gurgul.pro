\sheettitle{React 19 · 19.2 · React Compiler — Actions, \texttt{use}, Activity, auto-memo}{react-native · folio}

\oneliner{React 19 (Dec 2024) makes async updates first-class: an \textbf{Action} is a function run
in a \textbf{transition}, and React tracks its \textbf{pending}, \textbf{optimistic} and \textbf{error}
state (\ct{useActionState}, \ct{useOptimistic}). 19.2 (Oct 2025) adds \ct{<Activity>} and
\ct{useEffectEvent}; \textbf{React Compiler 1.0} (Oct 2025) memoises components and hooks
\textbf{at build time}. RN: React 19.0 in \textbf{0.78}, 19.1 in 0.80, 19.2 in \textbf{0.83}.}

\hd{React 19 — Actions and friends}
\begin{itemize}
  \item \textbf{Action} = function run in a transition (\ct{startTransition(async () \fat{} \{…\})} or
        \ct{useTransition}). \ct{isPending} stays true until the \emph{final} update commits.
        State set \emph{after} an \ct{await} is not in the transition — wrap it in
        \ct{startTransition} again.
  \item \ct{useActionState(action, initial)} $\to$ \ct{[state, dispatch, isPending]};
        \ct{action(prevState, payload)} returns the next state. Dispatches are \textbf{queued}
        and run in order. Renamed from canary \ct{useFormState}.
  \item \ct{useOptimistic(value, reducer?)} $\to$ \ct{[shown, addOptimistic]}. Call
        \ct{addOptimistic} \emph{inside} an Action; when it settles React falls back to
        \ct{value} — no manual rollback.
  \item \ct{use(promise | context)}: \textbf{suspends} until resolved (Suspense + Error
        Boundary); the one API allowed in \ct{if}/loops. The promise must be \emph{stable}
        (from a parent, cache or library) — not created in render.
  \item \textbf{\ct{ref} is a plain prop} of function components: \ct{forwardRef} no longer
        needed, to be deprecated. Ref callbacks may \textbf{return a cleanup}.
        \ct{<Ctx value=\{v\}>} replaces \ct{<Ctx.Provider>}.
  \item Web-only (\ct{react-dom}): \ct{<form action>}, \ct{useFormStatus}. RN: \ct{dispatch} from \ct{onPress}.
\end{itemize}

\hd{React 19.2 (RN 0.83) and 19.3}
\begin{itemize}
  \item \ct{<Activity mode="visible"|"hidden">}: hidden $=$ children hidden, \textbf{effects
        unmounted} (cleanups run), updates deferred to idle, \textbf{state kept}. Pre-render the
        next tab; keep a back screen's state without its subscriptions.
  \item \ct{useEffectEvent(fn)}: an ``event'' called from an Effect that reads the
        \emph{latest} props/state but is \textbf{not reactive} — never in deps, only called from
        Effects of the same component. Needs \ct{eslint-plugin-react-hooks@latest}.
  \item 19.2 also: \textbf{Performance Tracks} (Scheduler, Components) in the profiler.
        19.3 (9 Sep 2026): \ct{<ViewTransition>}, \ct{addTransitionType}, \textbf{Fragment refs}.
\end{itemize}

\hd{Example — an Action in RN (19.x)}
\begin{lstlisting}[language=TSSheet]
function LikeButton({ post }) {
  const [shown, addOptimistic] = useOptimistic(post.likes);
  const [error, like, isPending] = useActionState(
    async (_prev, id) => {
      addOptimistic(n => n + 1);       // instant UI
      try { await api.like(id); return null; }
      catch (e) { return 'Could not like'; } // UI reverts
    }, null);
  return (
    <Pressable disabled={isPending}
      onPress={() => startTransition(() => like(post.id))}>
      <Text>{shown} likes {error ?? ''}</Text>
    </Pressable>);
}
\end{lstlisting}

\hd{Does the compiler end \ct{useMemo}/\ct{useCallback}?}
For \textbf{new} code: mostly — write plain code. Keep them as \textbf{escape hatches} where
identity is a \emph{contract} (an effect dep that must not change). Old ones: leave, or remove
with tests — removing changes the compiled output. Memo is \textbf{per component}: an expensive
function called in 3 components still runs 3 times.

\columnbreak

\hd{React Compiler 1.0}
\begin{itemize}
  \item \ct{babel-plugin-react-compiler} (first Babel plugin) lowers each component/hook to an
        \textbf{HIR}, infers each value's inputs, emits a per-instance cache (\ct{\_c(n)}).
        Granular — even \textbf{after conditional returns}, which manual hooks cannot do.
  \item \ct{compilationMode}: \ct{'infer'} (default: PascalCase + JSX/hooks, or \ct{use*} +
        hooks) · \ct{'annotation'} (only \ct{"use memo"}) · \ct{'syntax'} (Flow) · \ct{'all'}.
        \ct{"use no memo"} opts one function out (debugging).
  \item \textbf{Assumes the Rules of React}: render is pure and idempotent, props/state/hook
        results immutable, hooks at top level, no \ct{ref.current} in render. Unsure $\to$
        \textbf{skip} that function (\ct{panicThreshold: 'none'}) — never a build break.
  \item \textbf{Lint}: \ct{eslint-plugin-react-hooks} (v6+, flat config) \ct{recommended}
        carries the compiler rules (\ct{set-state-in-render}, \ct{set-state-in-effect},
        \ct{refs}, \ldots). Fix lint first: a flagged component is a skipped one.
  \item React 17/18: \ct{target} + \ct{react-compiler-runtime}. Verify: a \textbf{sparkle
        ``Memo'' badge} in React DevTools. \textbf{RN}: supported; \textbf{Expo SDK 54+} on by
        default; bare RN adds the Babel plugin. Meta Quest Store: loads up to 12\% faster.
\end{itemize}

\hd{Example — before / after the compiler}
\begin{lstlisting}[language=TSSheet]
// BEFORE: manual, and still broken
const Row = memo(({ item, onPick }) => ...);
function List({ items, onPick }) {
  const sorted = useMemo(() => sort(items), [items]);
  const pick = useCallback(id => onPick(id), [onPick]);
  return sorted.map(i =>
    <Row key={i.id} item={i} onPick={() => pick(i.id)} />);
}   // inline arrow = new prop each render: memo defeated
// AFTER: plain code; compiler caches sorted, the arrows
function List({ items, onPick }) {
  const sorted = sort(items);
  return sorted.map(i =>
    <Row key={i.id} item={i} onPick={() => onPick(i.id)} />);
}
\end{lstlisting}

\hd{Traps}
\begin{itemize}
  \trap{\ct{use(fetchUser())} in render: new promise each render $\to$ suspends forever.}
  \trap{\ct{addOptimistic} outside an Action: warning, never shown.}
  \trap{Code that \emph{relied} on memo identity (effect deps) can change behaviour —
        bisect with \ct{"use no memo"}.}
  \trap{\ct{Activity} hidden $\neq$ unmounted: state stays, effects \emph{stop}.}
\end{itemize}

\hd{Remember}
\textbf{Action = transition + pending + optimistic + error. Compiler = memo by data-flow, if you
obey the rules.}
