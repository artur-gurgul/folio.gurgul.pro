\sheettitle{API design — HTTP resources and Swift APIs}{design · folio}

\oneliner{An API is a \textbf{contract you can never fully take back}: model
\textbf{resources} (nouns) and let \textbf{methods} carry the verbs, make every write
\textbf{safe to retry}, make every change \textbf{additive}, and judge a Swift API by
\textbf{clarity at the point of use}. Old app versions live for years.}

\section{HTTP: resources, methods, status}
\textbf{Nouns, plural, shallow}: \texttt{/users/7/orders}, not \texttt{/getUserOrders?id=7}
(RPC-in-URL, Richardson L0); past $\sim$2 levels go flat + filter (\texttt{/orders?user=7}).
Non-CRUD action: \texttt{POST /orders/9/cancel} (or a \texttt{cancellation} sub-resource).
Root is always an \textbf{object}, never a bare array (no room for \texttt{next}/meta later).

{\footnotesize\setlength\tabcolsep{3pt}
\begin{tabular}{@{}L{11mm}L{6mm}L{7mm}L{51mm}@{}}
\toprule
\textbf{Method} & \textbf{Safe} & \textbf{Idem.} & \textbf{Use} \\
\midrule

PATCH & no & no & Merge Patch (RFC 7396, \texttt{null} = remove) / JSON Patch (6902) \\
\bottomrule
\end{tabular}}

{\footnotesize\setlength\tabcolsep{3pt}
\begin{tabular}{@{}L{6mm}L{72mm}@{}}
\textbf{2xx} & \textbf{200} body · \textbf{201} + \texttt{Location} · \textbf{202} accepted, not done · \textbf{204} no body \\
\textbf{4xx} & \textbf{400} malformed · \textbf{401} \emph{who are you?} · \textbf{403} known, not allowed · \textbf{404} (or hide existence) · \textbf{409} state conflict · \textbf{412} If-Match failed · \textbf{422} valid JSON, invalid values · \textbf{429} + \texttt{Retry-After} \\
\textbf{5xx} & \textbf{500} bug · \textbf{502} bad upstream reply · \textbf{503} overloaded + \texttt{Retry-After} · \textbf{504} upstream timeout \\
\end{tabular}}
\textbf{Retry} only idempotent requests on 5xx/429/timeout, exponential backoff + jitter.

\textbf{Errors — RFC 9457 problem details} (2023, obsoletes 7807):
\begin{lstlisting}
422 Unprocessable Content   Content-Type: application/problem+json
{"type":"https://api.example.com/probs/validation","status":422,
 "title":"Invalid request","detail":"email is not an address",
 "instance":"/signups/81","errors":[{"field":"email"}]}
\end{lstlisting}
Clients branch on \texttt{type} (a URI; default \texttt{about:blank}), never on
\texttt{detail} text; extra members allowed; never leak stack traces.

\textbf{Pagination}. \emph{Offset} (\texttt{?offset=40\&limit=20}): page jumps, but
\textbf{drifts} (insert $\to$ duplicate row, delete $\to$ skipped row) and costs O(offset).
\emph{Cursor/keyset} (\texttt{?after=<opaque>}): stable under writes, index-fast, no jumps;
needs a \textbf{total order} — sort key + unique tie-breaker (\texttt{created\_at, id}),
the cursor encodes the last pair. Feeds $\to$ cursor. Filters/sort as query params
(\texttt{?status=open\&sort=created}), cap \texttt{limit}, next link in the body or
\texttt{Link: rel="next"} (RFC 8288).

\textbf{Mobile}: latency, not bandwidth, dominates — \textbf{chunky beats chatty} (one call
per screen, not 1 + N). \textbf{BFF} (Backends for Frontends, Sam Newman): a per-client
backend that aggregates and shapes; plus gzip/br, field selection, delta sync
(\texttt{?since=}), ETags.

\section{Evolution — versions + compatibility}
\begin{itemize}
  \item \textbf{URI} \texttt{/v2/} (visible, routable) · \textbf{media type}
        (\texttt{vnd.x.v2+json}) · \textbf{date-pinned} header (Stripe) · \textbf{none},
        additive only (GraphQL \texttt{@deprecated}, protobuf).
  \item \textbf{Safe}: new endpoint, optional request field, response field.
        \textbf{Breaking}: remove/rename, change type/unit, newly required, newly
        nullable, \textbf{a new enum value}, a changed default.
  \item \textbf{Never repurpose a field} (protobuf: never reuse a tag). \textbf{Tolerant
        reader} (Fowler): ignore unknown fields, unknown values $\to$ \texttt{.unknown}.
        Retire: \texttt{Sunset} (RFC 8594) + a min-app-version gate.
\end{itemize}

\section{Swift library API}
\begin{lstlisting}[language=SwiftSheet]
public enum Status: String, Decodable, Sendable {
  case active, suspended, unknown          // tolerant reader
  public init(from d: Decoder) throws {
    let raw = try d.singleValueContainer().decode(String.self)
    self = Status(rawValue: raw) ?? .unknown }
}
// items.remove(at: i) · a.sort() mutates, a.sorted() returns
\end{lstlisting}
\begin{itemize}
  \item \textbf{Swift API Design Guidelines}: \emph{``Clarity at the point of use is your most
        important goal''}, over brevity; \textbf{omit needless words}; name by \textbf{role};
        factories \texttt{make…}; Bools as assertions (\texttt{isEmpty}); conversions
        unlabeled (\texttt{Int64(x)}).
  \item \textbf{Progressive disclosure}: common case in one line
        (\texttt{URLSession.shared.data(from:)}), power via default arguments.
  \item Return \texttt{some P} to keep the concrete type changeable; every \texttt{public}
        is forever — widen later, never narrow.
  \item \textbf{SemVer} MAJOR for a protocol requirement without a default or a new public
        enum case. ABI stable Swift 5.0, module stability 5.1 (\texttt{.swiftinterface},
        \texttt{BUILD\_LIBRARY\_FOR\_DISTRIBUTION}: non-\texttt{@frozen} enums need
        \texttt{@unknown default}). Rename: \texttt{@available(*, deprecated, renamed:)}.
\end{itemize}

\section{Traps}
\begin{itemize}
  \trap{\texttt{If-Match} mismatch is \textbf{412}, not 409. An ETag is opaque, not a hash.}
  \trap{A new enum case breaks JSON decoders and Swift \texttt{switch}es alike.}
  \trap{\texttt{no-cache} = store but revalidate; \texttt{no-store} = never store.}
  \trap{A missing Idempotency-Key where one is required is \textbf{400}, not 422.}
\end{itemize}
\textbf{Remember: nouns + HTTP verbs · retry-safe writes · add, never change · cursor
for feeds · clarity at the point of use.}
