\oneliner{Four ways to stop one object knowing too much. \textbf{Coordinator} —
\emph{where to go next} (navigation out of VCs). \textbf{Repository} — \emph{where data
comes from} (hide network/cache/DB behind one protocol). \textbf{DI} — \emph{who builds
my collaborators} (someone outside, at the composition root). \textbf{Clean} — \emph{which
way dependencies point} (always inward, towards business rules).}

\section{How it works}
\textbf{Coordinator.} \emph{Problem:} VCs that push/present each other are coupled to
their siblings, cannot be reused in another flow, bloat with routing, and make deep
links scatter. \emph{3 jobs:} (1) \textbf{build} screens — VC+VM, inject deps
(assembly); (2) \textbf{navigate} — push/present/dismiss on its presenter
(\texttt{UINavigationController}); (3) \textbf{own child flows} —
\texttt{childCoordinators}, \texttt{start()}, remove on finish (forget it $\to$ the flow leaks). The VC only reports
intent (closure \texttt{onSelect}, delegate) — it is a \emph{Mediator} for navigation.
SwiftUI: a router owning \texttt{NavigationPath}/\texttt{[Route]} +
\texttt{navigationDestination(for:)}.

\textbf{Repository.} One source-agnostic API over \emph{several} sources (network,
cache, DB); orchestrates them with a policy (cache $\to$ API $\to$ write-back, merge,
staleness); returns \textbf{domain entities}; is swappable behind a protocol the
\emph{domain} owns. Caching/offline lives \emph{here}.

\textbf{Dependency Injection} = collaborators handed in from outside.
\begin{itemize}
  \item \textbf{Constructor} (\texttt{init}) — default: non-optional, \texttt{let},
        compiler-enforced. \textbf{Property} — optional deps, storyboard VCs (a
        \texttt{nil} window). \textbf{Method} — per-call dependency.
  \item \textbf{Default arg:} \texttt{init(s: URLSession = .shared)} — tests inject.
  \item \textbf{Containers:} Swinject, Resolver, Factory, Needle (compile-time);
        scopes: transient · singleton · scoped/weak.
  \item \textbf{SwiftUI:} \texttt{.environment(\textbackslash.key, v)} /
        \texttt{.environmentObject(o)} — DI by context; missing $\Rightarrow$
        \emph{runtime} crash.
  \item \textbf{Composition root:} the one place near launch that wires concretes.
        \textbf{Service locator} (a container resolved \emph{inside} a type) =
        anti-pattern: hidden deps, global state.
  \item \textbf{IoC} = idea · \textbf{DIP} = principle · \textbf{DI} = technique implementing DIP.
\end{itemize}

\section{Remember}
\textbf{Coordinator = where \emph{to} · Repository = where \emph{from} · DI = who
\emph{builds} · Clean = which \emph{way}.} VIPER = V·I·P·E·R.

\section{Example}
\begin{lstlisting}[language=SwiftSheet]
protocol ArticleRepository {        // owned by the DOMAIN
  func articles() async throws -> [Article] }
final class DefaultArticleRepo: ArticleRepository {
  let api: APIClient; let cache: ArticleCache
  init(api: APIClient, cache: ArticleCache) { // ctor DI
    self.api = api; self.cache = cache }
  func articles() async throws -> [Article] {
    if let c = cache.load(), !c.isStale { return c.items }
    let fresh = try await api.fetch().map(Article.init)
    cache.save(fresh); return fresh }         // write back
}
// composition root: the ONLY place that picks concretes
FeedVM(repo: DefaultArticleRepo(api: LiveAPI(), cache: Disk()))
\end{lstlisting}

{\footnotesize \textbf{I} = business logic (use case) · \textbf{P} = formatting ·
\textbf{R} = navigation + assembly · \textbf{E} = plain models. \textbf{I} $\approx$ Clean's
Use Case, \textbf{P} $\approx$ Interface Adapter. objc.io's original: I hands P
\textbf{plain data, never Entities} (so P can only format); the wireframe (R) owns the
window / \texttt{UINavigationController}. Ownership: V$\to$P$\to$I and P$\to$R strong;
P$\to$V, I$\to$P, R$\to$VC \textbf{weak} (protocols \texttt{: AnyObject}) or the module never
frees. Cost: $\sim$5 types + protocols \emph{per screen} — only for large, multi-team apps.}

\section{Traps}
\begin{itemize}
  \trap{Repository is \textbf{not mainly about testing}: it hides \emph{multiple}
        sources · read flow \textbf{cache $\to$ API $\to$ write-back} · \textbf{single
        source of truth}. Testability falls out.}
  \trap{A class that just forwards \texttt{api.get()} is a renamed network client,
        not a Repository — the value is orchestration.}
  \trap{Coordinator as ``a class that pushes VCs'' misses the point — the
        \textbf{problem} is VCs knowing each other (coupling, no reuse); the 3 jobs follow.}
  \trap{\texttt{.shared} called inside a type defeats DI — inject it.}
  \trap{``Use case needs network so it imports URLSession'' — no: it declares a
        protocol; the outer layer conforms and is injected.}
\end{itemize}
