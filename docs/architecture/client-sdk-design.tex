\sheettitle{Client SDK design — a library inside someone else's app}{architecture · folio}

\oneliner{An SDK is a \textbf{guest with a contract}: a \textbf{small public surface} that is hard
to misuse, \textbf{documented threading} (callbacks on a known queue), \textbf{no crash, no
block, no launch cost}, errors as values, and a \textbf{compatibility promise} — SemVer at the
source level, \textbf{library evolution} at the binary level — enforced by an API-diff check in CI.
Every \ct{public} symbol is forever; shipping it is the easy part, removing it takes a major version.}

\hd{The surface}
\begin{itemize}
  \item \textbf{One entry type}, value-type \textbf{configuration} with safe defaults, required
        values in \ct{init} (not setters you can forget). Allow instances; a \ct{shared} convenience
        is optional — a forced singleton blocks tests and multi-account hosts.
  \item \textbf{Hard to misuse}: \ct{final} classes (\ct{public}, not \ct{open}), enums over flag
        combos, tagged IDs, \ct{some P} returns so the concrete type can change, \ct{internal}
        by default. Kotlin: \textbf{explicit API mode}, no \ct{data} classes in the public API
        (\ct{copy}/constructor break on every new property).
  \item \textbf{Init}: cheap, no I/O, no network; nothing in \ct{+load} / static initialisers; no
        swizzling unless the host opts in. Start work lazily, after launch.
  \item \textbf{Threading}: ``callable from any thread'' stated in the doc comment; state behind
        an \ct{actor} / serial queue; public types \ct{Sendable}; callbacks on a
        \textbf{documented queue} (main by default, or a \ct{callbackQueue} like
        \ct{URLSession}'s \ct{delegateQueue}); never call back synchronously inside the call.
  \item \textbf{Errors}: one domain \ct{enum} (non-\ct{@frozen}, so new cases are additive) +
        underlying error; invalid config $\to$ \ct{assertionFailure} in debug, an error in release.
        Retries and backoff inside, bounded.
\end{itemize}

\hd{Example — a surface that is hard to misuse}
\begin{lstlisting}[language=SwiftSheet]
public struct PayConfig: Sendable {
  public let apiKey: String                 // required: in init
  public var environment: Environment = .production
  public var logLevel: LogLevel = .error    // silent by default
  public var callbackQueue: DispatchQueue = .main
  public init(apiKey: String) { self.apiKey = apiKey }
}
public enum PayError: Error, Sendable {     // NOT @frozen
  case invalidRequest(String), declined(code: String)
  case transport(underlying: any Error)
}
public final class PayClient: Sendable {
  public init(config: PayConfig)            // no I/O here
  public func pay(_ r: PayRequest) async throws -> Receipt
  public func pay(_ r: PayRequest, completion: @escaping @Sendable
      (Result<Receipt, PayError>) -> Void)  // on callbackQueue
  @available(*, deprecated, renamed: "pay(_:)")
  public func charge(_ r: PayRequest) async throws -> Receipt
}
\end{lstlisting}

\hd{Versioning — the promise}
\begin{itemize}
  \item \textbf{SemVer}: patch = fix, minor = additive, \textbf{major} = anything a caller must
        change. Deprecate first (\ct{@available(*, deprecated, renamed:)}; Kotlin
        \ct{@Deprecated} WARNING $\to$ ERROR $\to$ HIDDEN over several minors), remove at the next major.
  \item \textbf{API-diff in CI}: \ct{swift package diagnose-api-breaking-changes <tag>};
        Kotlin binary-compatibility-validator \ct{apiDump} / \ct{apiCheck} (in the Kotlin Gradle
        plugin from 2.2.0); a committed public-API file makes every surface change a reviewed diff.
  \item \textbf{Support window}: minimum OS, Xcode/Swift, Kotlin, RN versions written down;
        raising one is a \textbf{major}. Old SDK versions live in shipped apps for years.
  \item \textbf{Fleet visibility}: send the SDK version with every request (a header or
        User-Agent) — adoption per version, and the backend can \textbf{disable a broken
        version} remotely (kill switch) while hosts update.
\end{itemize}

\hd{Size, startup, privacy — the host pays}
\begin{itemize}
  \item \textbf{Budget} the SDK: measure the app-size and launch-time \emph{delta} in a sample app
        per release. Few dependencies — a bundled copy of a popular library clashes with the
        host's (duplicate classes / symbols); vendor + rename, or depend on nothing.
  \item \textbf{Static} XCFramework: no dyld cost; \textbf{dynamic}: one copy for app + extensions.
  \item \textbf{Privacy manifest}: the SDK ships its own \ct{PrivacyInfo.xcprivacy} (data
        collected, tracking domains, required-reason APIs). SDKs on Apple's
        commonly-used list (Alamofire, Firebase*, SDWebImage\ldots) need the manifest
        \textbf{and a signature} when shipped as binaries; Xcode checks a new version is signed
        by the \textbf{same developer}.
  \item \textbf{Logging}: default silent or \ct{Logger(subsystem: "com.example.sdk")}; a
        host-settable level and handler; never tokens or PII.
\end{itemize}

\hd{Testing and docs}
\begin{itemize}
  \item Internal seams (\ct{Transport}, \ct{Clock}, \ct{Storage}) for your tests; ship a
        \textbf{test double} (\ct{PayClient.mock}) so hosts can test \emph{their} code.
  \item A \textbf{sample app} in the repo = the integration test CI builds against the
        \emph{binary} artifact (catches a missing \ct{.swiftinterface}, resource bundle or
        privacy manifest) on the minimum OS.
  \item DocC / KDoc for every public symbol incl. threading and error behaviour; a migration
        guide per major.
\end{itemize}

\hd{Traps}
\begin{itemize}
  \trap{Library evolution ``for safety'' in a source-only package — it is for \emph{binaries}
        built separately from clients; it costs indirection.}
  \trap{\ct{@frozen} or \ct{@inlinable} on day one — you can never add a stored property or
        change that body for old apps.}
  \trap{Typed \ct{throws(PayError)} is a promise too — the error type is now public API.}
  \trap{Callback on ``whatever thread the network used'' — host UI updates off-main.}
  \trap{Doing work in \ct{init} or at launch ``to be ready'' — you just slowed every host.}
\end{itemize}

\hd{Remember}
\textbf{Small, final, Sendable · config in init · callbacks on a known queue · errors as
values · additive minors · API diff in CI · the host pays for your size, launch and privacy.}
