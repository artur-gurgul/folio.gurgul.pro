\section{The design, step by step}
\begin{itemize}
  \item \textbf{1 Requirements.} Functional: scroll, infinite load,
        pull-to-refresh, like, detail. Out of scope: upload, stories, DMs. Non-functional:
        cached feed \emph{instantly} on launch, no hitches (16.7/8.3 ms), flaky
        network/offline, memory-safe images. Ranking + fan-out live on the backend; the
        client consumes a ranked list.
  \item \textbf{2 API + model.} \texttt{GET /feed?cursor=<opaque>\&limit=20}
        $\to$ \texttt{\{items, nextCursor\}}; items carry multi-resolution image URLs
        and \texttt{viewerHasLiked}. Normalize: entities by \texttt{id} in one store,
        the feed = ordered \emph{id list} $\to$ one like updates every screen.
  \item \textbf{3 Layers.} View $\to$ ViewModel (UI state enum, no UIKit) $\to$
        use cases $\to$ \textbf{Repository} (hides remote vs local) $\to$ data sources.
        Dependencies point inward; the domain owns the repository protocol (DIP)
        $\to$ fake repo in tests.
  \item \textbf{4 Data flow.} \emph{Read}: observe local store (1) $\to$ fetch page
        (2) $\to$ upsert + dedup (3) $\to$ store emits (4). \emph{Write}: optimistic
        store write $\to$ outbox $\to$ server $\to$ ack or \textbf{revert}.
  \item \textbf{Offline-first + sync.} Push dirty ops, pull \emph{since cursor}.
        Retries need \textbf{idempotency} (client UUID key; ``set'' not ``increment'').
        Backoff + jitter; per-item success. Deletes = \textbf{tombstones}. Conflicts —
        \emph{name the policy}: server-wins, LWW (loses edits; clock skew), version/ETag
        + \texttt{If-Match} (412), field merge, CRDT. Triggers: foreground,
        \texttt{NWPathMonitor}, \texttt{BGAppRefreshTask}, silent push.
  \item \textbf{Pagination.} \emph{Cursor/keyset}: stable under inserts, opaque,
        resumable. \emph{Offset}: new posts at the top shift pages $\to$ duplicates and
        gaps. Prefetch the next page N rows before the end.
  \item \textbf{Images.} Memory: \texttt{NSCache} of \emph{decoded, downsampled}
        images (cost limit, purged under pressure). Disk: size-bounded LRU of
        bytes. Downsample with ImageIO to points × scale, off main; coalesce
        duplicate URL requests; \textbf{cancel on reuse} and check the cell still
        shows the same id; prefetch via \texttt{prefetchItemsAt}.
  \item \textbf{Real-time.} WebSocket deltas for \emph{visible} posts in the
        foreground; APNs when backgrounded. Server count \emph{replaces}, never adds to,
        the optimistic one.
  \item \textbf{Platform.} SPM feature + Core modules (build time, boundaries).
        Flags: cached remote config, safe default. Token in \textbf{Keychain}; 401
        $\to$ refresh + replay.
\end{itemize}

\section{Example — repository: read local, sync in}
\begin{lstlisting}[language=SwiftSheet]
actor FeedRepository: FeedRepositoryProtocol { // init omitted
  let api: APIClient; let store: PostStore; let outbox: Outbox
  private var cursor: String?              // opaque, server-made
  func posts() -> AsyncStream<[Post]> { store.observeFeed() }
  func loadNext() async throws {
    let page = try await api.feed(after: cursor, limit: 20)
    try await store.upsert(page.items)     // dedup by id -> emits
    cursor = page.nextCursor               // nil = end of feed
  }
  func like(_ id: Post.ID) async {
    await store.setLiked(id, true)         // optimistic, instant
    await outbox.enqueue(.like(id), key: UUID()) // retry-safe
  }                  // server rejects -> store.setLiked(id, false)
}
\end{lstlisting}

\section{Traps}
\begin{itemize}
  \trap{Network as source of truth $\to$ blank screen offline and on every cold launch.}
  \trap{\textbf{Offset} pagination on a live feed; loading only at the bottom.}
  \trap{Retrying a POST with no idempotency key $\to$ double like.}
  \trap{Caching only bytes (decode per display); full-res decode on main.}
  \trap{``It just syncs'' — name the conflict policy and how you \emph{detect}
        a conflict (version, not clock).}
  \trap{\texttt{try!} decoding the page — one bad item kills the feed.}
\end{itemize}

\section{Remember}
\textbf{Requirements $\to$ API $\to$ layers $\to$ flow $\to$ hard parts $\to$ trade-offs.}
