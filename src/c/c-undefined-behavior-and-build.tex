\sheettitle{Undefined behaviour \& the C build — preprocess, compile, link}{c · folio}

\oneliner{\textbf{Undefined behaviour} is behaviour ``for which this document imposes no
requirements'' (C23 3.5.3). The optimiser \textbf{assumes it never happens}, so checks vanish and
loops change shape — often only at \ct{-O2}, far from the bug. \textbf{Building} = per
\emph{translation unit} preprocess → compile → assemble to a \ct{.o}; then the \textbf{linker}
resolves every symbol to one definition, places the sections and patches the addresses.}

\section{Four kinds of behaviour (C23 3.5)}
{\scriptsize\setlength{\tabcolsep}{2pt}
\begin{tabular}{@{}L{17mm}L{31mm}L{28mm}@{}}
\toprule
\textbf{kind} & \textbf{the standard} & \textbf{its own example}\\ \midrule
\textbf{undefined} & \textbf{no requirements}; J.2 lists 221 & null pointer dereference\\
unspecified & $\ge$2 options, choice not documented & order of evaluating arguments\\
impl.-defined & unspecified, choice documented & \ct{>>} of a negative value\\
locale-specific & per locale, documented & \ct{islower} beyond a–z\\
\bottomrule
\end{tabular}}\par
A \emph{constraint} violation needs a diagnostic even if it is also UB (5.1.1.3); UB alone needs
none. C23 note 3: observable behaviour \emph{before} the UB still happens as specified.

\textbf{Not UB, same effect}: a loop whose condition is not constant and that does no I/O,
\ct{volatile} or atomic access may be \emph{assumed to terminate} (6.8.6.1) — empty ones are deleted;
\ct{while (1)} is not.

\section{What the optimiser does with it}

\ \ int v = d\pa{}val; \textcolor{tangoComment}{// *d ⇒ d != NULL}\\
\ \ if (!d) return -1; \textcolor{tangoComment}{// so: dead}\\
\ \ return v;\ \}};
  \node[code] (b) at (4.85,0) {int dev\_read(struct dev *d) \{\\
\ \ return d\pa{}val;\ \}\\[1pt]\textcolor{tangoComment}{// the null test is gone}};
  \draw[hot] (a.east |- b.west) -- node[tool, above]{-O2} (b.west);

\begin{itemize}
  \item Overflow ``cannot happen'' ⇒ \ct{x + 1 > x} → \ct{true}, \ct{x * 2 / 2} → \ct{x},
        \ct{for (i = 0; i <= n; i++)} runs exactly $n{+}1$ times. Type rules ⇒ a \ct{float} store
        cannot change a \ct{float *}: a store loop becomes one \ct{memset} (Lattner, 2011).
  \item Linux 2.6.30 \ct{tun} (CVE-2009-1897): \ct{tun\pa{}sk} read before \ct{if (!tun)}; GCC
        deleted the test → local privilege gain.
  \item Fine at \ct{-O0}, broken at \ct{-O2} or with the next compiler = latent UB. Fix the code;
        a lower \ct{-O} only hides it.
\end{itemize}

\begin{tabular}{@{}L{31mm}L{46mm}@{}}
\toprule

\section{C23: new tools, same rules}
Two's complement is now the only representation — signed overflow is \textbf{still} UB.
\ct{<stdckdint.h>}: \ct{ckd\_add(\&r, a, b)} (\ct{\_sub}, \ct{\_mul}) computes as if infinitely
wide, stores the wrapped result, returns \ct{true} on overflow. New: \ct{unreachable()} (reaching
it is UB), \ct{nullptr}, \ct{typeof}, \ct{memset\_explicit}, \ct{[[nodiscard]]},
\ct{[[fallthrough]]}, \ct{[[maybe\_unused]]}. Newly UB: \ct{realloc(p, 0)}. Gone: K\&R
definitions; \ct{int f();} means \ct{f(void)}. GCC 15+ defaults to \ct{-std=gnu23} (Clang 23 still
\ct{gnu17}); GCC 14 turned implicit declarations, implicit \ct{int}, int-conversion and
incompatible pointers into errors (\ct{-fpermissive} undoes it).

\section{Catch it}
\ct{-Wall -Wextra} is not ``all'': add \ct{-Wconversion -Wshadow -Wundef -Wcast-align -Wvla
-Wformat=2 -Wnull-dereference} (the last only when optimising). \ct{-Wall} brings
\ct{-Wstrict-aliasing=3} and (GCC 15) \ct{-Wheader-guard}. Static analysis: \ct{gcc -fanalyzer}
(GCC 10+), \ct{clang -{}-analyze}, \ct{scan-build make}.

{\scriptsize\setlength{\tabcolsep}{2pt}
\begin{tabular}{@{}L{12mm}L{42mm}L{22mm}@{}}
\toprule
\ct{-fsanitize=} & \textbf{finds — only on paths a run executes} & \textbf{cost · limits}\\ \midrule
\ct{address} & out of bounds (heap, stack, globals), use after free / return / scope, double free; leaks (Linux) & $\sim$2$\times$; not with \ct{thread}\\
\ct{undefined} & signed overflow, shift, \pdfonly{$\div$}\htmlonly{÷}0, null, misalignment, bounds — not unsigned wrap & reports, continues; \ct{-fsanitize-trap}\\

\textbf{Ship hardened} (OpenSSF, Aug 2026): \ct{-D\_FORTIFY\_SOURCE=3} (\ct{-O1}+),
\ct{-fstack-protector-strong}, \ct{-fstack-clash-protection}, \ct{-ftrivial-auto-var-init=zero},
\ct{-Wl,-z,relro,-z,now}, the three \ct{-fno-…} above; GCC 14+: \ct{-fhardened}, most in one flag.

{\scriptsize\setlength{\tabcolsep}{2pt}

\section{Linkage, archives, shared libraries}
\textbf{External} (file-scope default): one entity across all TUs. \textbf{Internal}: \ct{static}
at file scope. \textbf{None}: locals (\ct{static} there = storage). A used external name needs
\textbf{exactly one} external definition (6.9.1; C++: the ODR): two → \emph{multiple
definition}, none → \emph{undefined reference}.
\begin{itemize}
  \item Header \emph{declares} \ct{extern int count;}, one \ct{.c} \emph{defines} it.
        \ct{int count;} in a header is a \textbf{tentative definition} per TU — merged as
        ``common'' until GCC 10 / Clang 11 made \ct{-fno-common} the default.
  \item C \ct{inline} with no \ct{extern} declaration in the TU is only an inline definition:
        an un-inlined call (\ct{-O0}) needs an external one elsewhere. Headers: \ct{static inline}.
  \item \ct{\_\_attribute\_\_((weak))}: a default any normal definition overrides. LTO
        (\ct{-flto}, \ct{=thin}): objects carry IR, the link optimises across TUs.
\end{itemize}

\begin{itemize}
  \item Users before providers; cycles need \ct{-{}-start-group … -{}-end-group} (``significant
        performance cost''). lld remembers every archive seen; \ct{-{}-warn-backrefs} flags lines
        GNU ld would reject.
  \item \ct{.so}/\ct{.dylib}/\ct{.dll}: mapped by the dynamic loader at run time, shared,
        replaceable; \ct{-fPIC}; \ct{-fvisibility=hidden} exports only what you mark.
  \item ESP-IDF builds with \ct{-ffunction-sections -fdata-sections -Wl,-{}-gc-sections}. In ROM:
        \ct{.data} stored in flash (LMA), copied to RAM (VMA) at start-up.
        \ct{-Wl,-Map=app.map}, \ct{idf.py size-components}: who uses the flash.
\end{itemize}

#endif
\end{lstlisting}
\ct{SQ(i++)}: two unsequenced writes, UB. \ct{do\{\}while(0)} lets \ct{if (c) SWAP(x, y); else}
parse. \ct{\#if FOO}, \ct{FOO} undefined: silently 0 (\ct{-Wundef}). \ct{\#pragma once} is not in
every preprocessor.

\textbf{Remember: UB is a promise to the optimiser; \ct{-O0} only hides a broken one.}
