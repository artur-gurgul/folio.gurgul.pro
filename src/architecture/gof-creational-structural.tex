\sheettitle{GoF: creational + structural}{architecture · folio}

\oneliner{Creational patterns decide \emph{how an object comes to exist}
(Singleton, Factory Method, Abstract Factory, Builder). The four ``wrappers''
are told apart by \textbf{intent}, not shape: Adapter \iface{changes} the
interface, Decorator \iface{keeps} it and \emph{adds behaviour}, Facade
\iface{simplifies} a whole subsystem, Proxy \iface{keeps} it and \emph{controls access}.}

\noindent\colorbox{sheetOrange!10}{\parbox{\dimexpr\linewidth-2\fboxsep}{
\textbf{Decide in two questions. (1) Same interface as the wrapped object?}
\emph{No} $\to$ dictated by an existing client? \textbf{Adapter} · invented to hide many classes? \textbf{Facade}.
\textbf{(2) Same} $\to$ \emph{adds behaviour}, stackable? \textbf{Decorator} ·
decides \emph{whether / when / how} you reach the real object? \textbf{Proxy}.}}

\raggedright

\pat{Proxy — ``Very Private Rooms Cache''}{Surrogate with the subject's interface that \textbf{controls access}.
\textbf{V}irtual: defer expensive creation (\texttt{lazy var} = built-in virtual proxy; not thread-safe) ·
\textbf{P}rotection: check auth, then forward ·
\textbf{R}emote: local stand-in for another process/server (XPC, API stubs) ·
\textbf{C}aching / smart reference: memoise, ref-count.}
\pat{Decorator}{Holds one object of the \textbf{same protocol}, forwards \emph{every} call, adds behaviour before/after; wrappers \textbf{stack}, order chosen at runtime.
\textbf{Beats subclassing:} $N$ optional features $\to$ $2^N$ subclasses (log+cache+retry = 8); decorators = $N$ types, composed (OCP).
Cost: forwards the whole interface (keep it small, ISP). SwiftUI: \texttt{.padding().background()} $\ne$ \texttt{.background().padding()}.}
\pat{Facade vs Adapter}{Facade does \emph{not} lock the subsystem away (you may bypass it) and is one-way — the subsystem does not know it (a Mediator's peers talk \emph{back}). Adapter = \emph{one} type made to fit an \emph{existing} interface.}
\pat[sheetGreen]{Singleton}{\textbf{Purpose:} exactly one instance + global access point.
\texttt{static let shared = X()} + \texttt{private init()}: static stored properties are initialised \textbf{lazily on first access, once, thread-safely} (\texttt{swift\_once}). Only \emph{creation} is safe — mutable state still needs an \texttt{actor}/lock.\par
\textbf{Downsides:} \textbf{global mutable state} · \textbf{hidden dependencies} (absent from every \texttt{init}) · \textbf{hard to test}: can't swap a fake, state leaks between tests, order-dependent · tight coupling (DIP) · app-long lifetime · SRP.\par
\textbf{Fix:} depend on a \textbf{protocol}, \textbf{inject} it; \texttt{.shared} only as default: \texttt{init(api: API = LiveAPI.shared)}.
\texttt{URLSession.shared}/\texttt{FileManager.default} are \emph{shared instances}, not enforced singletons.}
\pat[sheetOrange]{Remember}{\textbf{Adapter changes · Decorator decorates · Facade fronts many · Proxy protects.}
Hooks: plug adapter · gift-wrap layers · building front · bouncer. \textbf{Factory: Method = one, Abstract = family.}}

\columnbreak

\pat[sheetGreen]{Factory — three different things}{%
\textbf{Simple factory} (not GoF): a function with a \texttt{switch} returning a concrete type.\par
\textbf{Factory Method}: base class declares a creation method, \textbf{a subclass overrides it to decide ONE product}; base code calls it. Inheritance. iOS: override \texttt{class var layerClass} to pick a \texttt{UIView}'s \texttt{CALayer}.\par
\textbf{Abstract Factory}: an \textbf{object} (protocol) with \textbf{several} \texttt{make…} methods for a \textbf{FAMILY} that must match: \texttt{ThemeFactory} (\texttt{makeButton}, \texttt{makeLabel}) as \texttt{Light}/\texttt{Dark}; \texttt{Live} vs \texttt{Mock} services. Composition: passed in.}
\pat[sheetGreen]{Builder}{Solves \textbf{telescoping initialisers} (\texttt{init(a)}, \texttt{init(a,b)}, \texttt{init(a,b,c,…)}).
Builds \textbf{one} product \textbf{step by step}; setters \textbf{return \texttt{Self}} for chaining; \texttt{build()} validates. \textbf{Director} = holds a fixed recipe of steps.
\textbf{Swift: default + named params usually replace it.} \texttt{URLComponents} is a value-type builder; \texttt{@resultBuilder} is a compile-time DSL, related in spirit only.}

\section{Traps}
\begin{itemize}
  \trap{\textbf{Proxy $\ne$ Decorator}: Proxy \emph{controls access}, one, often creates the subject; Decorator \emph{adds behaviour} to what you hand it, stacked.}
  \trap{\textbf{Facade $\ne$ Adapter}: invents a simpler API over many vs fits one to an existing API.}
  \trap{A function returning an object is a \emph{simple factory}, not Factory Method.}
  \trap{``\texttt{static let} makes it thread-safe'' — only its initialisation.}
\end{itemize}
