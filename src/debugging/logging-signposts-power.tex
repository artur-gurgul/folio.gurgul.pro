\section{Unified logging (iOS 10+; \ct{Logger} iOS 14)}
\begin{itemize}
  \item \ct{Logger(subsystem: "com.acme.app", category: "network")}: reverse-DNS area +
        component, both filter keys. Replaced ASL and syslog.
  \item Stored \textbf{binary + compressed}, formatted only when read; a discarded \ct{debug}
        is near-free (the compiler skips building its message). \ct{print} = stdout, ``for
        command-line UI'': no level, metadata or redaction.
\end{itemize}
{\footnotesize\setlength{\tabcolsep}{3pt}
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{12mm}>{\raggedright\arraybackslash}p{36mm}>{\raggedright\arraybackslash}p{13mm}>{\raggedright\arraybackslash}p{10mm}@{}}
\toprule
\textbf{level} & \textbf{persisted (Apple's table)} & \textbf{alias} & \textbf{shown}\\ \midrule
\ct{debug} & no — memory only & \ct{trace} & \\
\ct{info} & only if collected with \ct{log} & & \\
\ct{notice} & yes, to a storage limit (default) & \ct{log} & \\
\ct{error} & yes + the activity's process chain & \ct{warning} & yellow\\
\ct{fault} & same; the slowest level & \ct{critical} & red\\
\bottomrule
\end{tabular}}
\begin{itemize}
  \item \textbf{Privacy} (\ct{.auto}): ints, floats, bools shown; dynamic strings and objects
        \textbf{redacted}. \ct{.public} shows; \ct{.private} = \ct{.sensitive} redact;
        \ct{mask: .hash} prints a per-process hash instead, so equal values correlate.
  \item \textbf{Xcode 15+ console}: metadata under each line, tokenised filters, Space =
        Quick Look, jump to the source line. \textbf{Console.app}: \emph{Action > Include
        Info / Debug Messages} — live stream only; a \ct{.logarchive} already has them.
  \item \textbf{Field}: \ct{try OSLogStore(scope:} \ct{.currentProcessIdentifier)} (iOS 15)
        reads your own entries back for a report; or a sysdiagnose.
\end{itemize}

\section{Example}
\begin{lstlisting}[language=SwiftSheet]
import os
extension Logger {
  static let net = Logger(subsystem: "com.acme.app",
                          category: "network") }
Logger.net.info("GET \(url.path, privacy: .public)")
Logger.net.error("HTTP \(code) user \(uid,
                 privacy: .private(mask: .hash))")
let sp = OSSignposter(logger: .net)
func fetch() async throws -> Feed {
  let st = sp.beginInterval("Fetch", id: sp.makeSignpostID())
  defer { sp.endInterval("Fetch", st) }  // same StaticString name
  sp.emitEvent("CacheMiss")               // a point, not a span
  return try await api.feed()
}
\end{lstlisting}

\end{lstlisting}

\section{Signposts — time, not words}
\begin{itemize}
  \item \textbf{Interval}: begin/end with the same static name. The returned
        \ct{OSSignpostIntervalState} enforces one end per begin, same name, same log — a
        violation \textbf{crashes Debug builds}; Release attaches an error to the end.
  \item ID \ct{.exclusive} (default) if only one such interval runs at a time, else
        \ct{makeSignpostID()}. \textbf{Event} = \ct{emitEvent}, an instant.
  \item \ct{.pointsOfInterest} category $\to$ \emph{Points of Interest}, auto-included with
        Time Profiler. \ct{OSSignposter.disabled} $\approx$ no-op; gate costly metadata on
        \ct{isEnabled}.
  \item \textbf{Xcode 27}: a track \textbf{per signpost name} under its category; os\_log
        overlaid on Time/CPU Profiler thread tracks; StateReporting states in Points of Interest.
  \item CI: \ct{XCTOSSignpostMetric(subsystem:category:name:)} in \ct{measure(metrics:)} —
        no result without a begin/end pair. \ct{xctrace}: \ct{\dd{}run-name} (26);
        \ct{\dd{}recording-options}, \ct{export} straight from \ct{.atrc}/\ct{.logarchive}
        with \ct{\dd{}time-start}/\ct{\dd{}time-end}/\ct{\dd{}duration} (27).
\end{itemize}

\section{Power Profiler (Xcode 26; iOS / iPadOS 26)}
\begin{itemize}
  \item Blank template + \emph{Power Profiler}. System track: \textbf{\% of battery per hour},
        charger, thermal state, brightness, SoC sleep. App lanes: \textbf{power impact} of
        \textbf{CPU · GPU · display · networking} — a score; fix the highest first.
        \emph{All Processes} = system only; app lanes need Launch or Attach.
  \item \textbf{No Mac}: Settings > Developer > \emph{Performance Trace} $\to$ Power Profiler
        mode $\to$ tick the app $\to$ Control Center control; up to \textbf{10\,h}; share the
        \ct{.aar} $\to$ \ct{.atrc} $\to$ Instruments (+ a lower-rate Time Profiler). Testers too.
\end{itemize}

\section{Field — MetricKit \& Organizer}
\begin{itemize}
  \item \textbf{iOS 27} \ct{MetricManager} (\ct{MX…} deprecated in 27.2):
        \ct{logHandle(category:)} + \ct{mxSignpost} $\to$ daily \ct{SignpostIntervalMetric}
        (count, duration histogram, \ct{cpuTime}, \ct{logicalWrites}, \ct{averageMemory} — the
        last three only from \ct{mxSignpost}, not \ct{OSSignposter}). Custom signposts are capped — critical paths only. Diagnostics list the signposts
        active around the event. Test: \emph{Debug > MetricKit > Simulate MetricKit Payloads}.
\end{itemize}
\begin{lstlisting}[language=SwiftSheet]
let mk = MetricManager()                  // iOS 27: keep ONE
let h = MetricManager.logHandle(category: "Feed")
mxSignpost(.begin, log: h, name: "Load")  // ... work ...
mxSignpost(.end, log: h, name: "Load")
Task { for await r in mk.metricReports {  // daily, never throws
  for case .signpostInterval(let m)
      in r.intervalEntries.fullDayEntry.values { upload(m) } } }
\end{lstlisting}
\begin{itemize}
  \item \textbf{Organizer} (anonymised, consenting users, needs volume). \emph{Battery Usage}:
        on-screen \% per 24\,h off power, + background, by Audio · Networking · Processing ·
        Display · Bluetooth · Location · Camera · Torch · NFC. \emph{Energy}: exception
        reports with a sample stack + 14-day trend.
  \item \textbf{Xcode 27}: \emph{Insights Overview}, \emph{Hitches} (all animations, was
        Scrolling), \emph{Storage}; goals per metric; \emph{Generate Recommendations}.
\end{itemize}

\section{Traps}
\begin{itemize}
  \trap{Support asks for logs and there is nothing: \ct{debug}/\ct{info} weren't
        persisted — log what support needs at \ct{notice}+.}
  \trap{\ct{privacy: .public} on a token or email — a PII leak; \ct{.hash} correlates instead.}
  \trap{Power profiled on a charger (cable or MagSafe) reads \textbf{0} — pair wirelessly.
        Impact scores from two device models don't compare.}
  \trap{Thousands of signposts/s recorded \emph{immediately} skip OS buffering — use \ct{\dd{}window}.}
\end{itemize}
