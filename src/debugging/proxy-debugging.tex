\sheettitle{Debugging through a proxy — Charles · Proxyman · mitmproxy · Burp}{debugging · folio}

\oneliner{An HTTPS debugging proxy is a \textbf{consensual man-in-the-middle}: it \textbf{terminates TLS}
with a leaf certificate \textbf{minted on the fly} and signed by \textbf{its own root CA} — which \emph{you}
installed and trusted on the device — and opens a \emph{second} TLS connection to the real server. Whatever
refuses that root (\textbf{pinning}, Android's default distrust of user CAs, clients that ignore the proxy)
shows up as a failed handshake or no traffic.}

Every install makes its \textbf{own} root CA (Charles since 3.10); its private key can impersonate any
site to every phone that trusts it.

\hd{Trusting the root, per platform}
\begin{itemize}
  \item \textbf{Route}: phone and Mac on one Wi-Fi; Settings $\to$ Wi-Fi $\to$ (i) $\to$ Configure Proxy
        $\to$ Manual: the Mac's IP + port. The \textbf{Simulator} uses the Mac's own network settings.
  \item \textbf{iOS device}: Safari $\to$ CA page $\to$ Settings $\to$ \emph{Profile Downloaded} $\to$ Install
        (then listed in General $\to$ VPN \& Device Management) $\to$ \textbf{General $\to$ About $\to$
        Certificate Trust Settings} $\to$ full trust. Skip it and HTTP works while every HTTPS call fails;
        MDM and Configurator payloads are trusted at once.
  \item \textbf{Simulator}: \ct{xcrun simctl keychain booted add-root-cert ca.pem}, or drag the file onto
        its window; Charles (Help menu) and Proxyman automate it.
  \item \textbf{Android}: apps targeting API $\leq$ 23 trust user CAs; \textbf{API 24+} only system CAs, so
        your debug build opts in (below). From Android 11 a CA installs only via Settings. Someone else's
        app: root, or an emulator with \ct{-writable-system} + \ct{adb remount}, to reach the system store —
        since Android 14 roots also live in the updatable Conscrypt APEX. Emulator \ct{-http-proxy host:port}
        sends all its TCP through the proxy.
\end{itemize}

\hd{The minted leaf must pass the device's rules}
iOS 13+ rules bind \emph{every} TLS server certificate, minted ones too: DNS name in the \textbf{SAN} (CN
ignored), SHA-2, RSA $\geq$ 2048, EKU \ct{serverAuth}, $\leq$ 825 days. ATS adds TLS 1.2+, ECDHE, AES-128/256
and accepts a user- or admin-installed anchor — no exception needed. Exempt: the 398-day cap (user-added
roots), Apple's CT policy (public CAs only) and Android 17's default-on CT (skips the user store).

\hd{Binary payloads}
Protobuf has no field names on the wire: Charles and Proxyman read a \textbf{FileDescriptorSet}
(\ct{protoc -oapi.desc api.proto}), mitmproxy 12 a \ct{.proto} (\ct{protobuf\_definitions}; edit as YAML,
re-encoded). No schema: field numbers + wire types only (\ct{protoc \hbox{-}\hbox{-}decode\_raw}).
\textbf{gRPC} = \ct{application/grpc} on \textbf{HTTP/2}: 1-byte flag + 4-byte big-endian length + message.

\hd{Beyond the proxy}
Raw TCP / UDP: mitmproxy \ct{tcp\_hosts} / \ct{udp\_hosts} still MITM TLS and DTLS. \textbf{No proxy at all}
(iOS): Instruments \textbf{HTTP Traffic} (Network template: URLSession headers + bodies, decrypted) · scheme env
\ct{CFNETWORK\_DIAGNOSTICS} = 1–3 · Proxyman \textbf{Atlantis} (swizzles NSURLSession, Bonjour to the Mac;
inspect only) · \ct{rvictl -s <UDID>} $\to$ \ct{rvi0} $\to$ Wireshark (all packets, encrypted).

\hd{Traps}
\begin{itemize}
  \trap{``Charles reads any app's HTTPS'' — only with a CA the \emph{device owner} trusted, never through
        pinning; others' apps need objection (Frida) or apk-mitm — authorised tests only.}
  \trap{Pins off in \textbf{debug} only; \ct{src="user"} in \ct{base-config} ships MITM to every user CA.
        React Native \ct{fetch} rides NSURLSession / OkHttp.}
  \trap{Done? Untrust the root, proxy off (Mac asleep = ``no internet''). HAR files, HTTP Traffic traces and
        CFNetwork logs keep tokens in clear.}
\end{itemize}

\hd{Remember}
\textbf{``Route · trust · (un)pin in debug · look · untrust.''}
