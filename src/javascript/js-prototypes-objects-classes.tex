\sheettitle{Prototypes, objects and classes}{javascript · folio}

\oneliner{Every object has a hidden \ct{[[Prototype]]} link; a read that misses its \emph{own}
properties walks the chain to \ct{null} — objects \textbf{delegate} at run time, nothing is
copied. A write lands on the object itself unless a setter or a read-only property up the chain
says no. \ct{class} wires the same chain and adds real semantics: \ct{new}-only, fields,
\ct{\#private}, \ct{super}.}

\section{Lookup and links}
\begin{itemize}\raggedright
  \item \textbf{Read} \ct{o.k}: own? else the \ct{[[Prototype]]}'s, \ldots{} \ct{null} $\to$
        \ct{undefined}; a getter found anywhere runs with \ct{this} = \ct{o} (the
        \emph{receiver}).
  \item \textbf{Write}: drawing 3. Class fields, \ct{defineProperty} and \ct{\{...o\}}
        \emph{define}: no setter runs, an inherited read-only \ct{k} is shadowed.
  \item \ct{Object.create(p, descriptors)} links without a constructor. \ct{Object.create(null)}
        or \ct{\{\_\_proto\_\_: null\}}: no inherited keys, no \ct{toString} (\ct{String(o)}
        $\to$ TypeError); \ct{Object.groupBy} (ES2024) returns one.
  \item \ct{Object.setPrototypeOf}: ``very slow'' in every engine (MDN); a cycle, a
        non-extensible object or \ct{Object.prototype} $\to$ TypeError. \ct{o.\_\_proto\_\_} is
        a \emph{Normative Optional, Legacy} accessor on \ct{Object.prototype}.
  \item \ct{new F()} links to \ct{F.prototype}, or to \ct{Object.prototype} if that is not an
        object. Arrows, methods, \ct{async} functions: no \ct{.prototype}, no \ct{new};
        generators have one, still no \ct{new}; a bound function has none — \ct{new} uses
        its target's.
  \item \ct{o instanceof C}: \ct{C[Symbol.hasInstance]} if defined, else ``\ct{C.prototype} is on
        \ct{o}'s chain'' — fooled by \ct{Object.create(C.prototype)} (a \ct{\#x in o} brand
        check is not); false for an iframe's (other realm's) array — \ct{Array.isArray}.
\end{itemize}

\section{Descriptors and integrity}
Data \ct{\{value, writable, enumerable, configurable\}} · accessor \ct{\{get, set, enumerable,
configurable\}}. Literal, assignment, class field: all \ct{true}; a \emph{new} key via
\ct{defineProperty}: omitted $\to$ \ct{false} / \ct{undefined}; class methods: non-enumerable;
a class's \ct{C.prototype} is read-only. \ct{configurable:false}: no delete, no
data$\leftrightarrow$accessor switch; only \ct{writable} true$\to$false and (while writable)
\ct{value} may change.\pdfonly{\\[2pt]}\htmlonly{\\}

\ct{freeze} & — & — & — & + \ct{writable:false} (data)\\ \bottomrule

\ct{Object.freeze([]).push(1)} $\to$ TypeError. Faithful shallow copy (prototype, accessors, attributes, symbols):
\ct{Object.create(Object.getPrototypeOf(o), Object.getOwnPropertyDescriptors(o))}.

\section{Prototype pollution}
\ct{JSON.parse('\{"\_\_proto\_\_":\{"admin":1\}\}')} only makes an own key. A recursive merge
\ct{t[k] \qqe{} \{\}; merge(t[k], s[k])} with that key writes into \ct{t.\_\_proto\_\_} =
\ct{Object.prototype}: every object now has \ct{admin}. \ct{Object.assign(t, s)} \emph{sets},
so the key replaces \ct{t}'s prototype; \ct{\{...s\}} defines a plain key. Defend:
null-prototype objects or \ct{Map}, \ct{Object.hasOwn}, reject \ct{\_\_proto\_\_},
\ct{constructor}, \ct{prototype} keys, Node \ct{-{}-disable-proto=throw}.

\section{Classes — what is not sugar}
\begin{lstlisting}[style=js]
class Counter extends Base {
  static #made = 0;         // ES2022: fields, #private, static
  static { /* runs once, in order; may use #private */ }
  #n = 0;                   // per instance; NOT a property
  step = 1;                 // own data property, defined
  inc = () => this.#n += this.step;  // one closure per instance
  get value() { return this.#n; }    // on Counter.prototype
  static is(o) { return #n in o; }   // brand check
}
\end{lstlisting}
\begin{itemize}\raggedright
  \item \textbf{Not sugar}: \ct{new}-only (else TypeError); strict body; TDZ like \ct{let};
        methods non-enumerable, not constructible; \ct{extends Array}/\ct{Error}/\ct{Map}
        makes real built-in instances — magic \ct{length}, \ct{[[MapData]]} (ES5's
        \ct{Array.call(this)} could not); \ct{map} on an \ct{Array} subclass returns the
        subclass (\ct{Symbol.species}).
  \item \textbf{Fields}: base before its body, derived right after \ct{super()} (drawing 2).
        They \emph{define}: a base setter of the same name is not called (\ct{this.x = 1} in a
        constructor would call it).
  \item \textbf{\ct{\#private}}: a lexical name, not a key — invisible to \ct{Reflect.ownKeys},
        \ct{JSON}, proxies, \ct{structuredClone}; \ct{o.\#n} on an object without it $\to$
        TypeError; \ct{\#n in o} cannot be faked, \ct{instanceof} can; \ct{delete this.\#n}
        is a SyntaxError. A base constructor that returns \ct{obj} lets a subclass stamp
        \ct{\#fields} on it, even non-extensible (Stage 3 ``Non-extensible Applies to
        Private'' makes that a TypeError). \ct{static \#x} read via \ct{this} in a subclass
        $\to$ TypeError.
  \item \textbf{\ct{super}} comes from the method's \ct{[[HomeObject]]}, fixed where it is
        written: \ct{super.m()} calls \ct{getPrototypeOf(Home).m} on the current \ct{this}; a
        copied method keeps it; \ct{super.x = v} sets on \ct{this}. \textbf{Mixin}:
        \ct{B \fat{} class extends B \{\ldots\}}, then \ct{extends Ser(Stamped(Model))}.
  \item \textbf{Decorators} (\ct{@dec}; \ct{accessor x = 1} = get/set over a private slot):
        Stage 3 in Mar 2022, \textbf{back to Stage 2.7} on 19 May 2026 with Decorator Metadata
        — in no ES edition. TypeScript $\ge$ 5.0 compiles them (no parameter decorators;
        \ct{experimentalDecorators} is an older, different dialect).
\end{itemize}

\section{Symbols, iterators, generators}
\ct{Symbol('d')}: a unique key; \ct{Symbol.for('k')}: one registry for all realms. The 13
well-known symbols are protocol hooks — \ct{iterator}, \ct{asyncIterator}, \ct{hasInstance},
\ct{toPrimitive}, \ct{toStringTag}, \ct{species}, \ldots; Stage 4 for ES2027: \ct{dispose}
(\ct{using}).
\textbf{Iterator}: \ct{[Symbol.iterator]()} $\to$ \ct{next()} $\to$ \ct{\{value, done\}};
\ct{for\ldots of} calls \ct{return()} on \ct{break}. A generator is a two-way iterator:
\begin{lstlisting}[style=js]
function* g() { const a = yield 1; const b = yield a + 1; return a + b; }
const it = g();  // runs nothing yet
it.next('x');  // {value: 1, done: false}   first argument ignored
it.next(10);   // a = 10 -> {value: 11, done: false}
it.next(5);    // b = 5  -> {value: 15, done: true}
\end{lstlisting}

\section{Remember}
\textbf{Own first, then the chain · writes shadow unless a setter or read-only says no · fields
define, assignments set · freeze is shallow · \ct{Reflect.x} is trap \ct{x}'s default.}
