\sheettitle{Lists, lazy stacks \& scrolling}{swiftui · folio}

\oneliner{\texttt{VStack} builds \emph{every} child now; \texttt{LazyVStack} builds a row only as it nears
the viewport (\textbf{no reuse}); \texttt{List} reuses platform cells but collects \textbf{all ids up front}.
\textbf{\texttt{ForEach} ids} decide which state, animation and callbacks belong to which datum — and since
iOS 17/18 the scroll view \emph{reports} position, snapping, geometry and visibility declaratively.}

\begin{multicols}{2}
\raggedright

\section{How it works}
\begin{itemize}
  \item \textbf{Creation}: \texttt{VStack} = exact layout, all children loaded at once. \texttt{LazyV/HStack},
        \texttt{LazyV/HGrid} (14) create rows on demand; unseen rows' sizes are \emph{estimated}. Apple:
        plain stack first, lazy when profiling says so.
  \item \textbf{\texttt{List}} visits the whole collection first: \emph{rows = elements $\times$ views per
        element} (WWDC23). A variable count (\texttt{if} in \texttt{ForEach}) or \texttt{AnyView} forces it to
        \textbf{build every row} just to count them — filter the \emph{data}, not the views.
  \item \textbf{Ids}: \texttt{Identifiable} or \texttt{id: \textbackslash.key}. \texttt{id: \textbackslash.self}
        hashes the whole value $\Rightarrow$ editing a field = new id = row destroyed + re-inserted.
        Indices shift on insert/delete $\Rightarrow$ state lands on the wrong row. Duplicate ids = undefined.
  \item \textbf{Row lifecycle}: \texttt{onAppear} / \texttt{.task} run when a row is shown;
        \texttt{onDisappear} + \emph{task cancelled} when it leaves; \textbf{again on every scroll-back}.
        Keeping an off-screen row's \texttt{@State} is an implementation detail — durable row state
        lives in the model, keyed by id.
  \item \textbf{Position} (17): \texttt{.scrollPosition(id: \$topID, anchor:)} — two-way: reads the
        top-most target's id, write it to scroll; \textbf{needs \texttt{.scrollTargetLayout()}} on the stack.
        18: \texttt{ScrollPosition} value + \texttt{.scrollPosition(\$pos)}: \texttt{scrollTo(id:)},
        \texttt{scrollTo(edge: .bottom)}, \texttt{viewID(type:)}. Older: \texttt{ScrollViewReader}.
  \item \textbf{Snapping} (17): \texttt{.scrollTargetBehavior(.paging)} = container-sized pages;
        \texttt{.viewAligned} = settle on views of the \texttt{scrollTargetLayout}; or your own
        \texttt{ScrollTargetBehavior}.
  \item \textbf{Observing} (18): \texttt{onScrollGeometryChange(for:of:action:)} maps
        \texttt{ScrollGeometry} (\texttt{contentOffset}, \texttt{contentSize}, \texttt{contentInsets},
        \texttt{containerSize}, \texttt{visibleRect}) to an \texttt{Equatable}; \texttt{action(old, new)} fires
        \textbf{only when that value changes}. \texttt{onScrollVisibilityChange(threshold: 0.5)} per view;
        \texttt{onScrollPhaseChange}: \texttt{idle / interacting / decelerating / animating}.
  \item \textbf{Look} (17): \texttt{contentMargins(\_:\_:for: .scrollContent | .scrollIndicators)} insets
        content inside the scroll area (still scrolls edge to edge); \texttt{scrollTransition \{ c, phase in \}}
        (\texttt{.topLeading / .identity / .bottomTrailing}); \texttt{visualEffect \{ c, proxy in \}} —
        both return a \texttt{VisualEffect}: \textbf{no layout pass}, no \texttt{GeometryReader}.
\end{itemize}

\section{Example — snapping, paged feed}
\begin{lstlisting}[language=SwiftSheet]
ScrollView {
  LazyVStack(spacing: 8) {
    ForEach(feed.items) { item in          // stable entity id
      Row(item: item)
        .onScrollVisibilityChange { seen in  // 18, > 50 %
          if seen { log.impression(item.id) } }
    }
    if feed.hasMore {                      // sentinel row
      ProgressView()
        .task(id: feed.items.count) { await feed.loadNext() }
    }
  }
  .scrollTargetLayout()                    // rows = targets
}
.scrollPosition(id: $topID)                // 17, read + write
.scrollTargetBehavior(.viewAligned)
.contentMargins(.horizontal, 16, for: .scrollContent)
.onScrollGeometryChange(for: Bool.self) { g in
  g.contentOffset.y > 800 } action: { _, far in showTop = far }
\end{lstlisting}

\section{Traps}
\begin{itemize}
  \trap{\texttt{ForEach(items, id: \textbackslash.self)} on editable structs, \texttt{UUID()} created in \texttt{body},
        or \texttt{indices} — lost row state, wrong row animates, duplicate-id warnings.}
  \trap{\texttt{if item.visible \{ Row \}} inside a \texttt{List}'s \texttt{ForEach}, or \texttt{AnyView} rows —
        every row built to learn the count. Filter the array.}
  \trap{\texttt{.onAppear \{ load() \}} on rows = duplicate requests on scroll-back; guard
        \texttt{isLoading} + cursor, dedupe appended ids.}
  \trap{Sentinel with plain \texttt{.task} may stay mounted after a page lands — no re-fire;
        \texttt{.task(id: items.count)}.}
  \trap{\texttt{scrollPosition(id:)} without \texttt{scrollTargetLayout()} — binding never updates.}
  \trap{A \texttt{GeometryReader} per row to read offsets — a layout pass each; use
        \texttt{onScrollGeometryChange} / \texttt{visualEffect}. \texttt{onScrollGeometryChange} watches the
        \emph{first} scroll view only.}
  \trap{Transform returns raw \texttt{contentOffset} $\Rightarrow$ \texttt{action} every frame; map to a \texttt{Bool} / page.}
\end{itemize}

\section{Remember}
\textbf{``Lazy builds late, List counts early; ask the scroll view, don't measure it.''}
