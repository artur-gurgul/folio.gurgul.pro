\sheettitle{TipKit — rules, pacing, invalidation}{swiftui · folio}

\oneliner{A \textbf{tip} is a small, transient view that teaches \emph{one} non-obvious feature.
You declare \textbf{content} + \textbf{eligibility} on a \ct{Tip}; TipKit (iOS 17) keeps state in a
persistent \textbf{datastore}, evaluates \textbf{rules} (\ct{@Parameter} values, counted
\ct{Tips.Event} donations), spaces tips by a global \textbf{display frequency}, and retires a tip for
good once \textbf{invalidated} — user acted, closed it, or it hit its cap.}

\hd{How it works}
\begin{itemize}
  \item \textbf{\ct{Tip}} (\ct{Identifiable, Sendable}): \ct{title}, \ct{message?}, \ct{image?},
        \ct{actions}, \ct{rules}, \ct{options} — the last three are result builders.
  \item \textbf{\ct{Tips.configure(\_:)}} (throws) \emph{must} run before any tip displays.
        Frequency \ct{.immediate} (default) · \ct{.hourly} · \ct{.daily} · \ct{.weekly} · \ct{.monthly}.
  \item \textbf{Parameter rule} = app state. \ct{@Parameter} values are \textbf{persisted} across
        launches (\ct{.transient} resets); assigning one re-evaluates the rules that read it.
  \item \textbf{Event rule} = repeated behaviour: \ct{await event.donate()} (\ct{sendDonation()} from
        sync code); predicate over \ct{\$0.donations}: \ct{.donatedWithin(.days(5))}, \ct{.count},
        \ct{largestSubset(groupedBy:)}. \ct{Event<Info: Codable>} donations carry data to filter on.
        Queries see the latest \textbf{1000} donations; iOS 26: \ct{DonationLimit(maximumCount:maximumAge:)}.
  \item \textbf{Display frequency} = minimum gap after a tip shows before \emph{another, never-shown}
        tip may appear. A tip already shown still reappears while its rules pass.
  \item \textbf{Options}: \ct{MaxDisplayCount(3)} (no default cap) · \ct{MaxDisplayDuration(300)}
        (iOS 18, cumulative, $\geq$ 60 s) · \ct{IgnoresDisplayFrequency(true)}.
  \item \textbf{Observe}: \ct{status} · \ct{shouldDisplay} · \ct{statusUpdates} ·
        \ct{shouldDisplayUpdates}. SwiftUI views observe for you; UIKit code must.
\end{itemize}

\hd{Example — the tip}
\begin{lstlisting}[language=SwiftSheet]
import TipKit
struct ShareTip: Tip {
  @Parameter static var isLoggedIn: Bool = false        // persisted
  static let openedDoc = Tips.Event(id: "openedDoc")    // counted
  var title: Text { Text("Share with one tap") }
  var message: Text? { Text("Send this document to a teammate.") }
  var image: Image? { Image(systemName: "square.and.arrow.up.fill") }
  var actions: [Action] { Action(id: "how", title: "Show me") }
  var rules: [Rule] {                                   // AND: each narrows
    #Rule(Self.$isLoggedIn) { $0 == true }
    #Rule(Self.openedDoc) { $0.donations.donatedWithin(.week).count >= 3 }
  }
  var options: [any TipOption] { MaxDisplayCount(3) }
}
\end{lstlisting}

\hd{Example — configure, feed, present, retire}
\begin{lstlisting}[language=SwiftSheet]
@main struct DocsApp: App {
  init() {
    #if DEBUG
    try? Tips.resetDatastore()                  // BEFORE configure
    #endif
    try? Tips.configure([.displayFrequency(.daily)])
  }
  var body: some Scene { WindowGroup { EditorView() } } }
// login:  ShareTip.isLoggedIn = true           -> rules re-evaluate
// editor: .task { await ShareTip.openedDoc.donate() }
Button("Share", systemImage: "square.and.arrow.up") {
  tip.invalidate(reason: .actionPerformed)      // they found it
  share()
}
.popoverTip(tip) { action in if action.id == "how" { showHelp() } }
\end{lstlisting}

\hd{Testing}
All run \textbf{before} \ct{configure}; precedence \ct{showTipsForTesting([A.self])} >
\ct{hideTipsForTesting} > \ct{showAllTipsForTesting()} > \ct{hideAllTipsForTesting()}.
\ct{resetDatastore()} = first-launch state. Launch args: \ct{-com.apple.TipKit.ResetDatastore 1},
\ct{-com.apple.TipKit.ShowTips A,B}.

\hd{When a tip is the right tool (HIG)}
Simple features (\textbf{$\leq$ 3 actions}), \textbf{1--2 sentences}, actionable. Not for tours,
promotion or critical info — a tip can be missed. Rule it to the people who benefit; pace several
(e.g.\ once per 24 h). Filled SF Symbol; don't repeat the image the tip points at.

\hd{Traps}
\begin{itemize}
  \trap{No \ct{Tips.configure} $\to$ no tip and \textbf{no error}.}
  \trap{Invalidation is \textbf{persisted}: closed once in a test run, gone next run — reset the store.}
  \trap{Forgetting \ct{invalidate(reason: .actionPerformed)} nags people who already use the feature.}
  \trap{Frequency never throttles an already-shown tip: \ct{MaxDisplayCount}.}
  \trap{UIKit: observe in a \ct{Task}, cancel it in \ct{viewWillDisappear}.}
  \trap{CloudKit sync (iOS 18): a \textbf{separate} container; iCloud + Background Modes (remote notifications).}
  \trap{\ct{TipGroup} is iOS 18 (announced as TipSequence); \ct{.ordered} waits for each earlier tip's invalidation.}
\end{itemize}

\hd{Remember}
\textbf{``Configure once · rule who · pace when · cap how often · invalidate when learned.''}
