\section{Pointers}
\begin{itemize}
  \item \textbf{States:} \texttt{allocate} $\to$ \texttt{initialize(to:)} $\to$
        use $\to$ \texttt{deinitialize(count:)} (releases refs) $\to$
        \texttt{deallocate()}. Skipping deinitialise on class refs = leak.
  \item \textbf{Scoped:} \texttt{withUnsafePointer(to:)},
        \texttt{withUnsafeBytes(of:)}, \texttt{withUnsafeBufferPointer} — the
        pointer is valid \textbf{only inside the closure} (the value may move,
        COW-copy or die). Implicit \texttt{\&x} / array / \texttt{String} to a
        C param: valid for \emph{that call}; keeping one draws a
        ``dangling pointer'' warning (5.2+).
  \item \textbf{Binding:} memory is bound to one type at a time; typed
        access through an unrelated type = strict-aliasing UB.
        \texttt{bindMemory(to:capacity:)} rebinds; \texttt{withMemoryRebound}
        rebinds for a scope (e.g. \texttt{sockaddr\_in} $\to$
        \texttt{sockaddr}); \texttt{assumingMemoryBound(to:)} only
        \emph{asserts}, unchecked. For reinterpretation, prefer raw +
        \texttt{load(as:)}.
  \item No bounds checks on \texttt{p[i]} / \texttt{buf[i]} in release.
        C fixed arrays import as \textbf{tuples}; \texttt{withExtendedLifetime(obj)}
        stops ARC releasing an object whose pointer C still uses.
  \item \textbf{\texttt{Unmanaged<T>}}: manual retain counts across
        \texttt{void *}. CF naming rule: \emph{Create/Copy} returns +1
        $\to$ \texttt{takeRetainedValue()}; \emph{Get} $\to$
        \texttt{takeUnretainedValue()}.
\end{itemize}

\section{Example — C callback with context}
\begin{lstlisting}[language=SwiftSheet]
final class Counter { var hits = 0 }
let ctx = Unmanaged.passRetained(Counter()).toOpaque()    // +1
register_cb({ raw in              // @convention(c): no captures
  let c = Unmanaged<Counter>.fromOpaque(raw!)
                            .takeUnretainedValue()   // +0 borrow
  c.hits += 1 }, ctx)
// later, exactly once:
Unmanaged<Counter>.fromOpaque(ctx).release()              // -1
var n: UInt32 = 0xDEADBEEF
let b = withUnsafeBytes(of: &n) { Array($0) }  // EF BE AD DE
\end{lstlisting}

\section{When to reach for it}
C/C++ interop, zero-copy binary parsing, a \emph{measured} hot loop. Keep it
small, audited, behind a safe API. Swift 6.2's \texttt{Span}/\texttt{RawSpan}
are bounds-checked, non-escaping views that replace many
\texttt{withUnsafe…} uses.

\section{Reflection \& casts}
\begin{itemize}
  \item \texttt{T.self} is the \emph{value} of \texttt{T.Type}: call
        \texttt{static} members and \texttt{required init} through it
        (\texttt{decode(User.self, from:)}). \texttt{AnyClass} =
        \texttt{AnyObject.Type}; \texttt{ObjectIdentifier(T.self)} keys by type.
        \texttt{some P} = one hidden type, static; \texttt{any P} = box.
  \item \texttt{Mirror(reflecting:)}: \texttt{children} (label, value),
        \texttt{displayStyle}, \texttt{superclassMirror} (inherited props).
        Stored properties only — \textbf{no methods, computed props,
        setting or construction}. Slow; \texttt{dump()} uses it.
  \item \texttt{is}/\texttt{as?}: classes walk the superclass chain;
        protocols look up conformance records (cached, first lookup slow).
        Casts see through \texttt{Optional} inside \texttt{Any}; \texttt{Int}
        in \texttt{Any} is \emph{not} a \texttt{Double}; \texttt{as? any
        Sequence} works since 5.7, \texttt{any Collection<Int>} needs the
        iOS 16 runtime.
\end{itemize}

\section{Traps}
\begin{itemize}
  \trap{\texttt{withUnsafePointer(to: \&x) \{ \$0 \}} — returns a dangling
        pointer. Do the work inside, or copy out.}
  \trap{\texttt{size} instead of \texttt{stride} for pointer maths;
        \texttt{withUnsafeBytes} is \textbf{host} (little-endian) order — use
        \texttt{.bigEndian} for the wire.}
  \trap{\texttt{x as? AnyObject} always succeeds (boxes a struct).
        \texttt{is Dog} includes subclasses; comparing \texttt{type(of: x)} to
        \texttt{Dog.self} is exact.}
  \trap{Mirror for serialisation or setting — use \texttt{Codable}, key paths.}
\end{itemize}

\section{Remember}
\textbf{``Typed? Mutable? Buffer? — then: in scope, initialised, bound,
aligned, in bounds.''} Metatype is a value; Mirror only reads.
