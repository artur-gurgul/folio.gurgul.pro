\oneliner{Users download a \textbf{per-device slice}: from an \textbf{AAB}, Play builds
\textbf{split APKs} (base + one \textbf{ABI} + one \textbf{density} + the device's
\textbf{languages}); the App Store thins iOS uploads. In RN the heavy part is \textbf{native
libraries $\times$ ABIs} (Hermes, \texttt{libreactnative.so}, every native dependency), then
assets. Measure \emph{download} size.}

\section{How it works}
\begin{itemize}\raggedright
  \item \textbf{ABIs}: the template builds \texttt{armeabi-v7a, arm64-v8a, x86, x86\_64}
        (\texttt{reactNativeArchitectures}). With an AAB that costs \emph{upload} size only.
        Outside Play (per-CPU APKs, \texttt{splits \{ abi \}}) each APK needs its own
        \textbf{versionCode} — e.g. \texttt{versionCode * 1000 + abiCode}, arm64 higher so
        64-bit devices prefer it.
  \item \textbf{R8} (\texttt{enableProguardInReleaseBuilds} in the RN template, off by
        default): tree-shakes, inlines, merges classes, obfuscates; full mode is default
        since AGP 8.0. \texttt{shrinkResources} only works with minify on.
  \item \textbf{Native libs packaging}: uncompressed, page-aligned \texttt{.so}
        (\texttt{useLegacyPackaging = false}) are mmap'd in place — no extraction, smaller
        install/updates; compressed libs are extracted at install (bigger on disk).
  \item \textbf{JS}: mostly dependencies — prune with a bundle visualizer.
  \item \textbf{iOS}: slicing + asset catalogs + ODR (see app-size-and-energy). JSC is a
        system framework there, so Hermes \emph{adds} its engine to an iOS app. RN's
        \texttt{require()}d images are copied as loose files, not an asset catalog, so they
        are not sliced\unverified.
\end{itemize}

\section{Example — Android release config}
\begin{lstlisting}[language=GrSheet]
// android/app/build.gradle
def enableProguardInReleaseBuilds = true
android {
  defaultConfig { resourceConfigurations += ["en", "de"] }
  buildTypes { release {
    minifyEnabled enableProguardInReleaseBuilds
    shrinkResources true       // needs minify
    proguardFiles getDefaultProguardFile(
      "proguard-android-optimize.txt"), "proguard-rules.pro"
  } }
}
// react-native.config.js: stop autolinking a lib on Android
// dependencies: { 'some-lib': { platforms: { android: null } } }
\end{lstlisting}

\section{Measure — the number users see}
\begin{itemize}\raggedright
  \item \texttt{bundletool build-apks \dd{}bundle=app.aab \dd{}output=app.apks}, then
        \texttt{bundletool get-size total \dd{}apks=app.apks} (per-config download sizes;
        \texttt{\dd{}device-spec} for one phone).
  \item Android Studio \textbf{APK Analyzer} (Build $\to$ Analyze APK): per-folder raw vs
        download size, dex references, \texttt{.so} alignment.
  \item \textbf{Play Console} app bundle explorer: size per device configuration.
  \item \textbf{iOS}: \emph{App Thinning Size Report}. CI: fail past a size budget.
\end{itemize}

\section{Traps}
\begin{itemize}\raggedright
  \trap{Dropping \texttt{x86}/\texttt{x86\_64} ``to shrink'' an AAB — Play already serves
        one ABI; you only broke emulators and x86 devices.}
  \trap{Quoting the universal APK or the upload size — users get the split.}
  \trap{R8 full mode removes classes reached only by reflection/JNI $\to$
        release-only \texttt{ClassNotFoundException}; add keep rules, test release.}
  \trap{Stripping native symbols with nowhere to keep them — upload them
        (\texttt{debugSymbolLevel}) or crashes become unreadable.}
\end{itemize}

\section{Remember}
\textbf{Ship an AAB, minify + shrink, prune native deps, right-size assets — measure the
download, not the upload.}
