\section{React Native DevTools — what is in it}
\begin{itemize}\raggedright
  \item Open: \textbf{\texttt{j}} in the Metro terminal, or Dev Menu $\to$ \emph{Open DevTools}
        (\texttt{Cmd/Ctrl+M} Android emulator, \texttt{Ctrl+Cmd+Z} iOS Simulator, shake).
  \item \textbf{Console} · \textbf{Sources} (breakpoints, conditional, logpoints,
        \texttt{debugger;}) · \textbf{Memory} (heap snapshots, allocation timeline) ·
        \textbf{React Components} (edit props/state; ``Memo'' badge = React Compiler) ·
        \textbf{React Profiler} (commit flame graph).
  \item \textbf{0.83}: \textbf{Network} (\texttt{fetch}, XHR, \texttt{<Image>}; headers,
        timings, previews, \textbf{Initiator} = JS call stack; \emph{no} WebSockets, mocking,
        throttling yet) · \textbf{Performance} (JS, React tracks, network, User Timings on one
        timeline) · a \textbf{desktop app}. 0.84 dropped the in-app Perf/Network tabs;
        0.86 added light/dark emulation.
  \item Docs' own scope: React app concerns, \emph{not} a replacement for native tools.
\end{itemize}

\section{History · Radon · LogBox · logs}
\begin{itemize}\raggedright
  \item \textbf{Remote JS debugging} ran your JS in Chrome's V8 — another engine,
        impossible with JSI. \textbf{Flipper}: removed from new projects in \textbf{0.74},
        ``unsupported''. 0.76 announced the end of log forwarding to the Metro terminal.
  \item \textbf{Radon IDE} (Software Mansion): VS Code/Cursor extension running the
        Simulator/emulator \emph{inside} the editor — editor breakpoints, inspector $\to$
        source, network inspector, router integration, previews, replays. Free + paid.
  \item \textbf{LogBox}: fatal = red screen; \texttt{console.error}/\texttt{warn} = badges,
        hidden while DevTools is attached; \texttt{LogBox.ignoreLogs([...])}; \textbf{off in release}.
  \item \textbf{Native logs}: \texttt{adb logcat} (JS console = tag \texttt{ReactNativeJS});
        Xcode console / Console.app. A module's \texttt{Log.d}/\texttt{os\_log} never reaches
        DevTools. Since 0.82 an \textbf{unhandled promise rejection} is a \texttt{console.error}.
\end{itemize}

\section{Debugging a release build}
\begin{itemize}\raggedright
  \item No DevTools, no LogBox in release. Dev builds are slow (\texttt{\_\_DEV\_\_} checks,
        no minify) — never judge performance there.
  \item \textbf{\texttt{debugOptimized}} (Android, 0.82): C++ optimised + JS debuggable;
        $\sim$20 $\to$ $\sim$60 FPS vs \texttt{debug}. \texttt{npx react-native run-android
        \dd{}mode debugOptimized}.
  \item \textbf{JS CPU in release}: \texttt{react-native-release-profiler} —
        \texttt{startProfiling()} / \texttt{stopProfiling(true)}, pull with
        \texttt{npx react-native-release-profiler \dd{}fromDownload \dd{}appId <id>}; open in
        Perfetto / SpeedScope / \texttt{chrome:\dsl{}tracing}.
  \item \textbf{System}: Android Studio \emph{Capture System Activities} (profileable) —
        watch threads \texttt{mqt\_js} (JS) and the UI/RenderThread crossing 16\,ms;
        Perfetto for exported traces. iOS: Instruments on the \emph{Profile} config.
  \item \textbf{Field data}: \texttt{PerformanceObserver} (stable 0.83) works in production —
        marks, measures, \texttt{longtask}, \texttt{event} timings to your analytics.
\end{itemize}

\section{Example — symbolicate a Hermes JS crash}
\begin{lstlisting}[language=ShSheet]
# android/app/build.gradle: emit the Hermes map
react { hermesFlags = ["-O", "-output-source-map"] }
# iOS "Bundle React Native code and images" phase:
export SOURCEMAP_FILE="$(pwd)/../main.jsbundle.map"
# prod stack says  p@1:132161  (bytecode offset)
MAP=android/app/build/generated/sourcemaps/react/\
release/index.android.bundle.map
npx metro-symbolicate $MAP < stack.txt
adb logcat -d | npx metro-symbolicate $MAP
\end{lstlisting}
Native: iOS \textbf{dSYM}, Android R8 \texttt{mapping.txt} + NDK symbols — upload all to the
crash reporter \textbf{per build}; the JS map also \textbf{per OTA update}.

\section{Traps}
\begin{itemize}\raggedright
  \trap{``The map from yesterday's build will do'' — maps are per exact build/commit;
        a mismatched map gives confident, \emph{wrong} lines.}
  \trap{A heap snapshot shows the \textbf{JS heap} only — decoded bitmaps and native
        module memory are invisible there (use Xcode/AS memory tools).}
  \trap{``DevTools shows nothing, the network call never happened'' — WebSocket traffic
        and native-module HTTP (OkHttp/URLSession in a SDK) are not in the Network panel.}
\end{itemize}

\section{Remember}
\textbf{Layer $\to$ tool:} JS/React = DevTools · C++/native = Xcode/Android Studio ·
release = profiler + logs + symbolicated crashes.
