\sheettitle{Auth \& sessions in React Native}{react-native · folio}

\oneliner{The protocol is the native one — \textbf{authorization code + PKCE in the system browser}
(\ct{ASWebAuthenticationSession} / Custom Tabs). The RN work is: a library that does it right,
\textbf{refresh token in Keychain/Keystore}, access token \textbf{in memory}, \textbf{one refresh at a
time} for every caller, and a \textbf{logout that wipes} every cache the user's data reached.}

\hd{Signing in — the libraries}
\begin{itemize}
  \item \textbf{expo-auth-session}: \ct{useAutoDiscovery(issuer)}, \ct{useAuthRequest} (PKCE on by
        default, \ct{S256}), \ct{promptAsync()} opens expo-web-browser
        \ct{openAuthSessionAsync} $\to$ \ct{ASWebAuthenticationSession} / Custom Tabs; then
        \ct{exchangeCodeAsync}, \ct{refreshAsync}; \ct{makeRedirectUri(\{ scheme \})}. Expo Go
        redirects to \ct{exp://}\ldots{} — test real redirects in a dev build.
  \item \textbf{react-native-app-auth}: wraps AppAuth-iOS / AppAuth-Android; \ct{authorize(cfg)},
        \ct{refresh(cfg, \{ refreshToken \})}, \ct{revoke(cfg, \{ tokenToRevoke \})}; Android
        \ct{manifestPlaceholders = [appAuthRedirectScheme: 'com.example.app']};
        \ct{iosPrefersEphemeralSession}.
  \item \textbf{Never a WebView} login: the app can read the password, no SSO cookie; RFC 8252:
        apps MUST NOT use embedded user-agents, servers MAY block them. Redirect: claimed \ct{https} (universal/app link) $>$ custom
        scheme — any app can register a scheme; PKCE makes a stolen \ct{code} useless.
\end{itemize}

\hd{Where tokens live — and the boot sequence}
\begin{itemize}
  \item \textbf{RT}: Keychain/Keystore (\ct{react-native-keychain}, \ct{expo-secure-store}).
        \textbf{AT}: a module variable / non-persisted store. Never redux-persist, AsyncStorage,
        MMKV-plain, logs or crash breadcrumbs.
  \item \textbf{Boot}: keep the splash (\ct{SplashScreen.preventAutoHideAsync()}) $\to$ read RT $\to$
        refresh $\to$ pick the navigator. No RT $\to$ auth stack. Offline $\to$ stay signed in with
        cached data; only \ct{invalid\_grant} means signed out.
  \item \textbf{Reinstall}: iOS Keychain outlives the app, AsyncStorage does not — no
        ``installed'' flag in AsyncStorage $\Rightarrow$ wipe Keychain items first.
  \item \textbf{Rotation}: persist the \emph{new} RT before anything else; two processes (app +
        background task) must not both refresh — share the lock or skip in background.
\end{itemize}

\hd{Biometric re-auth}
\ct{expo-local-authentication} \ct{authenticateAsync()} returns a \textbf{JS boolean} — a UI gate,
hookable on a rooted phone. Stronger: gate the \emph{secret} — a Keychain item with
\ct{ACCESS\_CONTROL.BIOMETRY\_CURRENT\_SET}: the OS releases the RT only after Face ID; a new
enrolment invalidates it (iOS: \ct{NSFaceIDUsageDescription}). Payments, password change:
server-side step-up (\ct{max\_age} / \ct{prompt=login}).

\hd{Example — axios interceptor, single-flight refresh}
\begin{lstlisting}[language=TSSheet]
let refreshing: Promise<string> | null = null;
function refreshOnce(): Promise<string> {
  refreshing ??= doRefresh()            // the first caller creates it
    .finally(() => { refreshing = null; });  // next expiry: new one
  return refreshing;                     // everyone else joins it
}
api.interceptors.response.use(undefined, async (err) => {
  const cfg = err.config;
  if (err.response?.status !== 401 || cfg._retried) throw err;
  cfg._retried = true;                   // retry ONCE, never loop
  try {
    const at = await refreshOnce();
    cfg.headers.Authorization = `Bearer ${at}`;
    return api(cfg);                     // replay the original call
  } catch (e) {
    if (isInvalidGrant(e)) await signOut('expired'); // not on offline
    throw e;
  }
});
// doRefresh(): read RT from Keychain, POST /token with a BARE
// client (no interceptor -> no recursion), save new RT, return AT
\end{lstlisting}

\hd{Logout — wipe everything the user reached}
\begin{enumerate}
  \item \ct{revoke} the RT at the server (RFC 7009) — best effort; offline still logs out.
  \item Delete secure items: \ct{Keychain.resetGenericPassword()} /
        \ct{SecureStore.deleteItemAsync()}; clear the in-memory AT; abort in-flight requests
        (\ct{AbortController}).
  \item Caches: \ct{queryClient.clear()}, reset the Redux root / Zustand store, MMKV
        \ct{clearAll()}, image + file caches, drafts.
  \item Unregister the push token server-side; \ct{Sentry.setUser(null)}; analytics reset.
  \item Navigation: auth-conditional screens swap stacks by themselves (else
        \ct{navigation.reset}) — no ``back'' into the app.
  \item Browser session: \ct{end\_session\_endpoint}, or the next login is silent SSO.
\end{enumerate}

\hd{Traps}
\begin{itemize}
  \trap{Logging out on \emph{any} refresh failure — airplane mode signs everyone out.}
  \trap{Refresh through the intercepted client $\to$ 401 inside refresh $\to$ infinite loop.}
  \trap{Logout that forgets the query cache: user B sees user A's feed.}
  \trap{Biometric check as a boolean in front of an RT stored without access control.}
\end{itemize}

\hd{Remember}
\textbf{Browser + PKCE · RT in Keychain, AT in memory · one refresh, one retry · wipe it all.}
