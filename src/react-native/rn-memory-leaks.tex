\sheettitle{RN memory leaks — two heaps, retainers, images}{react-native · folio}

\oneliner{A leak is \textbf{unwanted reachability} from a \textbf{GC root} after the screen that
needed it is gone. RN has \textbf{two memories}: the \textbf{Hermes JS heap} (DevTools heap
snapshots) and \textbf{native memory} (views, bitmaps, modules — Xcode / Android Studio only).
Proof is a \textbf{staircase}: the same growth on every repeat of an action.}

\section{How it works}
\begin{itemize}\raggedright
  \item \textbf{JS heap}: Hermes' tracing GC frees anything unreachable — cycles included. A
        JS leak is always a \emph{path from a root}: module-level variables, globals, native
        event registries, timers, pending promises.
  \item \textbf{Native memory}: views, \textbf{decoded bitmaps} (Fresco / SDWebImage /
        Glide caches), WebViews, module state — ARC on iOS, ART GC + native heap on
        Android. Invisible to a JS heap snapshot.
  \item \textbf{Across the boundary}: native holding a JS callback or JS holding a
        HostObject keeps the other side alive; a cycle through both heaps is not collected.
  \item \textbf{Mounted $\ne$ leaked, but costs}: stack screens under the top and visited
        tabs stay mounted — \texttt{replace}/\texttt{reset} finished flows.
\end{itemize}

\section{Usual causes}
\begin{itemize}\raggedright
  \item Listeners/subscriptions never removed (\texttt{AppState}, \texttt{Keyboard},
        \texttt{Linking}, \texttt{NativeEventEmitter}, store/WebSocket subscriptions).
  \item \texttt{setInterval}/\texttt{setTimeout}/\texttt{requestAnimationFrame} not cleared;
        fetches resolving into unmounted components.
  \item Closures capturing big objects (one scope = one shared context); module-level
        caches with no bound (\texttt{Map} of responses, images, blobs).
  \item Native: a module keeping callbacks/promises, a strong delegate/block cycle, an
        Android \texttt{Activity}/\texttt{ReactContext} stored in a static field.
\end{itemize}

\section{Hunting a JS leak — 3 snapshots}
\begin{enumerate}\raggedright
  \item DevTools \textbf{Memory}. Do the action once (warm caches), return: snapshot \textbf{A}.
  \item Repeat \textbf{N} times (e.g. 5): snapshot \textbf{B}; once more: \textbf{C}.
  \item \textbf{Comparison} view B vs A, sort by \# Delta / Size Delta: suspects grow by a
        multiple of N and are still there in C.
  \item Select one instance $\to$ \textbf{Retainers}, read to the root; the first edge
        \emph{your} code owns is the bug. \textbf{Retained size} = what freeing it gives back.
\end{enumerate}

\section{Native side + real footprint}
\begin{itemize}\raggedright
  \item \textbf{iOS}: Xcode \emph{Debug Memory Graph} (purple ``!'' = leaked cycles; Malloc
        Stack Logging adds backtraces); Instruments \emph{Allocations} (Mark Generation per
        repeat) + \emph{Leaks}.
  \item \textbf{Android}: Studio \emph{Heap Dump} — shallow / retained / native size, depth,
        \emph{Show activity/fragment leaks}; \emph{Track Memory Consumption} (Java/Kotlin or
        native); LeakCanary (a Profiler task since Studio Panda). Totals:
        \texttt{adb shell dumpsys meminfo <pkg>} (Java/Native heap, Graphics, TOTAL PSS).
        Memory + bitmap memory are Play vitals.
  \item Heap flat but RSS climbing $\Rightarrow$ it is native: images first.
\end{itemize}

\section{Images — the maths and the fixes}
\begin{itemize}\raggedright
  \item Decoded = \textbf{width $\times$ height $\times$ 4 bytes} (RGBA8), whatever the file size.
        Request \emph{display size $\times$ scale} from the CDN.
  \item Android \texttt{<Image resizeMethod="resize">} downsamples \emph{before} decode (for
        images much larger than the view). \texttt{Image.prefetch} fills the \emph{disk} cache.
  \item \textbf{FlashList} recycles a fixed cell pool $\to$ live bitmaps stay bounded.
\end{itemize}

\section{Traps}
\begin{itemize}\raggedright
  \trap{``No warning, so no leak'' — React 18 \emph{removed} the ``state update on an
        unmounted component'' warning; cleanup is still your job.}
  \trap{\texttt{freezeOnBlur}/lazy tabs reduce \emph{renders}, not memory held.}
\end{itemize}

\section{Remember}
\textbf{Repeat · snapshot · compare · retainers.} JS heap flat $\Rightarrow$ bitmaps.
