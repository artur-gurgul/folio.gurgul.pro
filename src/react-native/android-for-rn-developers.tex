\sheettitle{Android for React Native developers}{react-native · folio}

\oneliner{\texttt{android/} is an ordinary \textbf{Gradle} project embedding a JS bundle:
\textbf{AGP} compiles Kotlin/Java (R8 shrinks it), the \textbf{NDK} builds C++ per ABI, the
\textbf{manifest merger} combines every library's manifest, you sign with an \textbf{upload key}
and Play re-signs. Most Android ``RN bugs'' are manifest, permission, SDK-level or R8 problems.}

\section{Gradle, SDK levels, Play rules}
\begin{itemize}\raggedright
  \item \textbf{Three SDK numbers}: \texttt{minSdk} = oldest device that installs;
        \texttt{compileSdk} = APIs you can call; \texttt{targetSdk} = which new
        \emph{behaviours} you opt into.
  \item \textbf{Play target API}: since \textbf{31 Aug 2026} new apps and updates must target
        \textbf{API 36} (Wear/Automotive 35, TV/XR 34; extension to 1 Nov 2026 on request);
        existing apps below 35 stop reaching new users on newer Android.
  \item \textbf{16 KB pages}: targets Android 15+ must support 16 KB-page 64-bit devices
        (Android guide: updates blocked from \textbf{1 Feb 2027}). AGP 8.5.1+/NDK r28+ align by
        default; RN is compliant since 0.77 — check third-party \texttt{.so} in APK Analyzer.
  \item \textbf{Toolchain}: JDK \textbf{17}; AGP comes via RN's Gradle plugin; \textbf{0.87}
        adds \textbf{AGP 9} (\texttt{android.builtInKotlin=false}, \texttt{android.newDsl=false}).
        Since 0.82 \texttt{newArchEnabled=false} is \emph{ignored}.
\end{itemize}

\section{Manifest}
\begin{itemize}\raggedright
  \item \textbf{Merged}: every library adds its manifest — read Android Studio's
        \emph{Merged Manifest} tab; drop an unwanted permission with
        \texttt{tools:node="remove"}.
  \item \textbf{\texttt{android:exported}} must be explicit on any component with an intent
        filter (Android 12+), else the app \emph{won't install}. Launcher activity: true.
  \item Template \texttt{MainActivity}: \texttt{singleTask} (deep links reuse it),
        \texttt{adjustResize}, \texttt{configChanges} (rotation keeps the React root).
        App Links: \texttt{autoVerify} + \texttt{/.well-known/assetlinks.json}.
\end{itemize}

\section{Example — manifest + permission}
\begin{lstlisting}[language=XmlSheet]
<uses-permission android:name="android.permission.CAMERA"/>
<activity android:name=".MainActivity" android:exported="true"
  android:launchMode="singleTask"
  android:windowSoftInputMode="adjustResize">
  <intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW"/>
    <category android:name="android.intent.category.DEFAULT"/>
    <category android:name="android.intent.category.BROWSABLE"/>
    <data android:scheme="https" android:host="example.com"/>
  </intent-filter></activity>
<!-- JS: await PermissionsAndroid.request(PERMISSIONS.CAMERA)
     'granted' | 'denied' | 'never_ask_again' -> openSettings -->
\end{lstlisting}

\section{Runtime permissions}
\begin{itemize}\raggedright
  \item \textbf{Dangerous} permissions (Android 6+) need manifest \emph{and} a runtime
        request: check $\to$ rationale (\texttt{shouldShowRequestPermissionRationale}) $\to$
        request. \texttt{POST\_NOTIFICATIONS} is runtime since Android 13.
  \item Android 11+: \textbf{Deny twice = ``don't ask again''} — the dialog never shows,
        send users to Settings. ``Only this time'' for location/camera/mic; unused apps get
        permissions \textbf{auto-reset}. Re-check on every resume.
\end{itemize}

\section{Back, edge-to-edge, R8, signing}
\begin{itemize}\raggedright
  \item \textbf{BackHandler}: listeners run \textbf{LIFO}; \texttt{return true} consumes;
        none $\to$ default back. An open \texttt{Modal} blocks BackHandler — use
        \texttt{onRequestClose}.
  \item \textbf{Target 36}: predictive back on by default, \texttt{onBackPressed} not called,
        \texttt{KEYCODE\_BACK} not dispatched (BackHandler still works for most cases;
        opt-out \texttt{enableOnBackInvokedCallback="false"}); \textbf{edge-to-edge}
        can't be opted out — use safe-area insets.
  \item \textbf{R8} keeps only what it sees: reflection, JNI, JSON-by-field-name need
        \texttt{-keep class …} / \texttt{@Keep}.
  \item \textbf{Signing}: \texttt{keytool -genkeypair … -validity 10000} $\to$ upload key;
        passwords in \texttt{\~{}/.gradle/gradle.properties}, not git. \textbf{Play App
        Signing} holds the real key, so a lost \emph{upload} key can be reset.
\end{itemize}

\section{Build errors $\to$ fix}
\begin{itemize}\raggedright
  \item \emph{SDK location not found} $\to$ \texttt{ANDROID\_HOME} / \texttt{local.properties}.
        \emph{Java version} errors $\to$ JDK 17 (\texttt{JAVA\_HOME}).
  \item \emph{Duplicate class … in modules} $\to$ two versions of one library: align/exclude.
        \emph{Incompatible Kotlin metadata} $\to$ align Kotlin versions.
  \item \texttt{INSTALL\_FAILED\_UPDATE\_INCOMPATIBLE} $\to$ different signing key: uninstall.
        \emph{Unable to load script} $\to$ \texttt{adb reverse tcp:8081 tcp:8081}.
  \item Release-only \texttt{ClassNotFoundException} $\to$ keep rules. Stale native build
        $\to$ \texttt{./gradlew clean}, delete \texttt{app/.cxx}.
\end{itemize}

\section{Traps}
\begin{itemize}\raggedright
  \trap{The template's \texttt{release} uses the \textbf{debug keystore} — replace it before
        shipping.}
  \trap{Bumping \texttt{targetSdk} ``just for Play'' — it switches on new behaviour
        (back, edge-to-edge); test it like a feature.}
\end{itemize}

\section{Remember}
\textbf{min = who installs · compile = what you call · target = how you behave.}
You sign uploads; Play signs installs.
