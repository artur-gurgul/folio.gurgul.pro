\sheettitle{Ad privacy — App Tracking Transparency \& AdAttributionKit}{security · folio}

\oneliner{Two different systems. \textbf{ATT} is a \emph{permission} for \textbf{tracking} — linking data from
your app with \emph{other companies'} data for ads or ad measurement, or sharing it with a data broker;
unless the user taps Allow, the \textbf{IDFA is all zeros}. \textbf{AdAttributionKit} (iOS 17.4+, successor
of SKAdNetwork) is measurement \emph{without} permission: the \textbf{device} picks the winning ad and sends a
\textbf{delayed, signed, crowd-anonymised postback} with no user or device ID.}

\hd{ATT}
\begin{itemize}
  \item \textbf{Tracking} = the \emph{linking}, whatever the identifier: ads targeted with other companies' data;
        e-mail lists / ad IDs to networks for retargeting; location to a broker; \textbf{an SDK in your app that
        combines your users' data with other apps'} — even if you don't use it that way. \textbf{Not
        tracking}: joins done only \emph{on device}; a broker used solely for fraud / security; credit agencies.
  \item \ct{ATTrackingManager.requestTrackingAuthorization} (callback or \ct{async}) +
        \ct{NSUserTrackingUsageDescription}; needed for the IDFA since \textbf{iOS 14.5}. Status:
        \ct{notDetermined} · \ct{restricted} · \ct{denied} · \ct{authorized}.
  \item \textbf{No prompt} — the completion runs at once — when the app is not
        \ct{UIApplicationStateActive}, in an extension, tracking is restricted, the global ``Allow Apps to
        Request to Track'' is off, or a request is pending. Dismissed $\to$ \ct{notDetermined}: ask later.
  \item \textbf{IDFA} (\ct{ASIdentifierManager}): a UUID only when \ct{authorized}; else (and in the
        Simulator) \ct{00000000-...}. Re-read, never store. \textbf{IDFV} (\ct{identifierForVendor}): one
        value per vendor per device; new after \emph{all} the vendor's apps are deleted; \ct{nil} after reboot
        until first unlock. First-party use only.
  \item \textbf{Fingerprinting is banned whatever the answer} (license agreement): no device ID derived from
        device / network / browser traits — an SDK doing it gets you rejected. \textbf{5.1.2(i)}: no gating,
        no reward for Allow; a primer may explain, never trick.
  \item \textbf{Tracking domains} (\ct{NSPrivacyTrackingDomains}, iOS 17+): without consent, requests to
        them \textbf{fail} — keep tracking and non-tracking endpoints on separate hosts.
  \item \textbf{EU} (current docs): after an answer, no new prompt for \textbf{a year}; FR, DE, IT, PL, RO get a
        full-page sheet (\ct{NSUserTrackingMarkdownUsageDescription}, 27.2 beta).
\end{itemize}

\hd{Example — ask when active; report value without asking}
\begin{lstlisting}[language=SwiftSheet]
// from an ACTIVE scene (after onboarding) - not didFinishLaunching
func idfaIfAllowed() async -> UUID? {
  let s = await ATTrackingManager.requestTrackingAuthorization()
  guard s == .authorized else { return nil }     // zeros anyway
  return ASIdentifierManager.shared().advertisingIdentifier
}
// advertised app: at first launch, then per milestone. No ATT.
// the 6-bit fine value (0...63) is YOUR schema
func reached(_ fine: Int, big: Bool) async {
  try? await Postback.updateConversionValue(fine,
      coarseConversionValue: big ? .high : .low,
      lockPostback: false)        // true = send this window now
}
\end{lstlisting}

\hd{AdAttributionKit}
\begin{itemize}
  \item \textbf{StoreKit-rendered} ads (\ct{SKOverlay}, \ct{SKStoreProductViewController} given the impression)
        record by themselves. \textbf{Custom-rendered}: \ct{AppImpression(compactJWS:)}; click =
        \ct{UIEventAttributionView} over the ad + \ct{handleTap()} (throws without a real tap); view =
        \ct{beginView()}/\ct{endView()}, 26.2+ \ct{handleView()}.
  \item \textbf{Rules} (WWDC25, Info.plist \ct{AdAttributionKitConfigurations}): window view 1–7 d, click
        1–30 d, global or per network; \textbf{cooldown} 0–720 h so a later ad can't steal a conversion.
  \item \textbf{Re-engagement} (iOS 18): \ct{handleTap(reengagementURL:)} with the advertised app's
        \textbf{universal link} opens it; the query holds \ct{Postback.reengagementOpenURLParameter}.
        \textbf{18.4}: overlapping re-engagement windows told apart by a \textbf{conversion tag}
        (\ct{PostbackUpdate}); Settings can create development postbacks.
  \item \textbf{vs SKAdNetwork} (StoreKit, 11.3; v4.0 in 16.1 added 3 windows + coarse): App Store only,
        \ct{SKAdNetworkItems}, \ct{updatePostbackConversionValue}, copies to
        \ct{/.well-known/skadnetwork/...}. AdAttributionKit adds \textbf{alternative marketplaces} (EU),
        re-engagement, JWS. Network IDs work in both; SKAdNetwork updates are \textbf{mirrored} into it;
        Apple now recommends AdAttributionKit.
\end{itemize}

\hd{What teams actually do}
\begin{itemize}
  \item \textbf{Consented} users: IDFA to an MMP (mobile measurement partner), user-level attribution.
  \item \textbf{Everyone}: the network / MMP verifies each postback's signature and aggregates by campaign
        (\ct{source-identifier}) server-side. The 6 bits are a designed schema (revenue buckets, funnel
        steps) with coarse mapped onto it; \emph{lock early} = faster signal, less information.
  \item \textbf{Apple Ads}: \ct{AAAttribution.attributionToken()} (AdServices, 14.3+), POSTed within 24 h.
\end{itemize}

\hd{Traps}
\begin{itemize}
  \trap{Asking in \ct{didFinishLaunching}: not active yet $\to$ no prompt, nothing learned.}
  \trap{``We use IDFV / hashed e-mail, so no ATT'' — tracking is the \emph{linking}, not the ID.}
  \trap{``The SDK tracks, not us'' — its behaviour is yours: ATT, label, manifest.}
  \trap{Expecting per-user or real-time attribution — aggregate, 24 h+ late, tier-limited.}
  \trap{No \ct{updateConversionValue} at first launch — the conversion window never starts.}
  \trap{ATT ``Allow'' is not GDPR consent — two separate duties.}
\end{itemize}

\hd{Remember}
\textbf{``ATT asks before you \emph{link}; AdAttributionKit counts without knowing \emph{who}.''}
Windows \textbf{2 / 7 / 35} days; fine value only in the first; 6 bits.
