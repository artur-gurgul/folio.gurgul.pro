\sheettitle{Device attestation — App Attest, DeviceCheck, Play Integrity}{security · folio}

\oneliner{Attestation lets \textbf{your server} ask the \emph{platform vendor} ``is this request
coming from my genuine, unmodified app on a genuine device?''. \textbf{App Attest} makes a
Secure-Enclave key, has Apple \textbf{attest} it once, then the app \textbf{asserts} (signs) each
sensitive request with it; \textbf{Play Integrity} returns a Google-signed \textbf{verdict}
about app, device and account. Both are evidence for a server-side risk decision — not
authentication, not a jailbreak detector.}

\hd{App Attest (iOS 14+)}
\begin{itemize}
  \item \ct{DCAppAttestService.shared}: check \ct{isSupported} (false on the Simulator; only
        action, extensible-SSO and watchOS extensions work even if \ct{true}).
        One key \textbf{per user per device}; persist the \ct{keyId} — it cannot be recovered.
  \item \ct{attestKey} calls Apple's server: \ct{serverUnavailable} $\to$ retry later with the
        \emph{same} key; any other error $\to$ discard the key, start over. Large apps ramp up
        gradually (Apple's rollout guidance).
  \item Keys survive app updates, \textbf{not} reinstall, device migration or restore from
        backup — expect re-attestation, don't flag it as fraud.
  \item Entitlement \ct{com.apple.developer.devicecheck.appattest-environment} =
        \ct{development} | \ct{production} (the \ct{aaguid} the server must expect).
  \item Assertions: unlimited per key; bind them to the request (hash of body + challenge),
        reserve them for sensitive moments. Newer verification steps also check the
        validation-category and bundle-version extensions in \ct{authData}.
  \item \textbf{DeviceCheck} (\ct{DCDevice.generateToken}): your server asks Apple to read /
        set \textbf{two bits} per device per developer (+ last-update time); they survive
        reinstall — ``promo already used'', not integrity.
\end{itemize}

\hd{Example — client side (the server does all the checking)}
\begin{lstlisting}[language=SwiftSheet]
let svc = DCAppAttestService.shared
guard svc.isSupported else { return .fallback }   // other signals
let keyId = try await svc.generateKey()            // persist it
let ch = try await api.challenge()                 // >= 16 bytes, one-time
let att = try await svc.attestKey(keyId,
            clientDataHash: Data(SHA256.hash(data: ch)))
try await api.register(keyId: keyId, attestation: att, challenge: ch)
// later, per sensitive request
let body = try JSONEncoder().encode(order); let c = try await api.challenge()
let sig = try await svc.generateAssertion(keyId,
            clientDataHash: Data(SHA256.hash(data: body + c)))
try await api.placeOrder(body, challenge: c, keyId: keyId, assertion: sig)
\end{lstlisting}

\hd{Android — Play Integrity API}
\begin{itemize}
  \item \textbf{Standard} request: \ct{prepareIntegrityToken} warm-up, then a few hundred ms;
        \ct{requestHash} = hash of your request; Google mitigates replay. \textbf{Classic}:
        seconds, your own \ct{nonce}, for rare high-value actions. Default quota 10{,}000
        requests/day.
  \item \textbf{Decrypt on the server}: standard $\to$ only via Google's
        \ct{decodeIntegrityToken}; classic may use your own keys (JWE A256KW/A256GCM wrapping a
        JWS ES256). Never decrypt in the app.
  \item \textbf{SafetyNet Attestation}: deprecated 2022, fully turned down \textbf{Jan 2025}.
        Lower level: Android \emph{Key Attestation} (Keystore certificate chain).
\end{itemize}

\hd{Traps}
\begin{itemize}
  \trap{Checking the attestation \emph{in the app} — the attacker owns that code. Server only.}
  \trap{Skipping the counter or reusing challenges $\to$ an old assertion replays.}
  \trap{Hard-blocking when \ct{isSupported} is false or a verdict is missing — locks out real users;
        tier it: allow, limit, step up, refuse.}
  \trap{A genuine phone in a device farm passes: attestation proves \emph{what} runs, not
        \emph{who} drives it — add rate limits per key and the fraud metric.}
  \trap{Caching a Play Integrity verdict — Google warns it enables proxying.}
\end{itemize}

\hd{Remember}
\textbf{``Attest once, assert often, decide on the server.''}
