\sheettitle{URLSession \& networking}{ios-swift · folio}

\oneliner{\texttt{URLSession} moves bytes; \textbf{you} judge them: it throws only on
\textbf{transport} failure — a 404/500 arrives as success, so check the
\textbf{status}, then \textbf{decode}. Three layers, three error types, and UI back on the
\textbf{main} thread.}

\begin{multicols}{2}
\raggedright

\section{How it works}
\begin{itemize}
  \item \textbf{URLRequest}: \texttt{url}, \texttt{httpMethod}, \texttt{setValue(\_:forHTTPHeaderField:)},
        \texttt{httpBody}, \texttt{timeoutInterval}, \texttt{cachePolicy}.
  \item \textbf{Session}: \texttt{URLSession.shared} (no delegate) or
        \texttt{URLSession(configuration:\allowbreak delegate:\allowbreak delegateQueue:)}. Configs:
        \texttt{.default} (disk cache, cookies) · \texttt{.ephemeral} (memory only) ·
        \texttt{.background(withIdentifier:)} (system daemon; download/upload only, no \texttt{dataTask}).
  \item \textbf{Tasks}: \texttt{dataTask} · \texttt{downloadTask} (to a file) · \texttt{uploadTask}.
        Born \emph{suspended} — nothing happens until \texttt{.resume()}.
  \item \textbf{async} (iOS 15): \texttt{try await session.data(for: req)} /
        \texttt{data(from: url)} $\to$ \texttt{(Data, URLResponse)}; cancel = cancel the \texttt{Task}.
  \item \textbf{Threads}: the completion handler runs on the session's \texttt{delegateQueue}
        — a \emph{background serial} \texttt{OperationQueue}, not main. UI:
        \texttt{DispatchQueue.main.async \{…\}} or \texttt{@MainActor}.
  \item \textbf{Three error layers}, in order:
        \textbf{1 transport} \texttt{URLError};
        \textbf{2 HTTP} cast to \texttt{HTTPURLResponse}, require \texttt{200...299};
        \textbf{3 decode} \texttt{DecodingError} (carries \texttt{context.codingPath} — log it).
  \item \textbf{Codable keys}: \texttt{enum CodingKeys: String, CodingKey \{ case fullName = "full\_name" \}}
        \emph{or} \texttt{keyDecodingStrategy = .convertFromSnakeCase}. Pick \textbf{one}.
        Dates: default \texttt{.deferredToDate} (seconds since 2001!) — set \texttt{.iso8601}.
  \item \textbf{TLS}: ATS demands HTTPS; URLSession validates chain + hostname \emph{by default}
        — you only add code to be \emph{stricter} (pinning, below the picture). No-code
        pinning: \texttt{NSPinnedDomains} under \texttt{NSAppTransportSecurity} in Info.plist.
  \item \textbf{Caching}: \texttt{URLCache.shared} (memory + disk) obeys \texttt{Cache-Control};
        \texttt{ETag} $\to$ \texttt{If-None-Match} $\to$ \textbf{304} is transparent (you get the
        cached body). \texttt{cachePolicy}: \texttt{.useProtocolCachePolicy} (default) ·
        \texttt{.reloadIgnoringLocalCacheData} · \texttt{.returnCacheDataElseLoad} (stale OK) ·
        \texttt{.returnCacheDataDontLoad} (offline). \emph{ElseLoad ignores freshness — serves stale data.}
\end{itemize}

\section{Example}
\begin{lstlisting}[language=SwiftSheet]
func load(_ url: URL) async throws -> User {
  var req = URLRequest(url: url, timeoutInterval: 15)
  req.setValue("application/json",
               forHTTPHeaderField: "Accept")
  // 1 transport: throws URLError (offline, TLS...)
  let (data, resp) = try await URLSession.shared
                                   .data(for: req)
  // 2 HTTP: 404 / 500 do NOT throw -- check!
  guard let http = resp as? HTTPURLResponse,
        (200...299).contains(http.statusCode)
  else { throw APIError.badStatus(resp) }
  // 3 decode: throws DecodingError
  return try decoder.decode(User.self, from: data)
}
\end{lstlisting}

{\footnotesize\textbf{Pinning at gate 1} (\texttt{URLSessionDelegate}):
\textbf{(a)} \texttt{urlSession(\_:didReceive:completionHandler:)} gets a \texttt{URLAuthenticationChallenge};
\textbf{(b)} if \texttt{protectionSpace.authenticationMethod ==} \texttt{NSURLAuthenticationMethodServerTrust},
take \texttt{protectionSpace.serverTrust} (a \texttt{SecTrust});
\textbf{(c)} \texttt{SecTrustEvaluateWithError} (keep default validation), then SHA-256 of the
server's public key $\in$ your pins?
\textbf{(d)} yes $\to$ \texttt{.useCredential, URLCredential(trust:)}; no $\to$
\texttt{.cancelAuthenticationChallenge}; other methods $\to$ \texttt{.performDefaultHandling}.\par}

\section{Traps}
\begin{itemize}
  \trap{\textbf{``A 500 lands in \texttt{catch}.''} No — its HTML body then fails at layer 3 as a
        misleading \texttt{DecodingError}. Check status \emph{before} decoding.}
  \trap{\textbf{Completion handler on main?} No — background \texttt{delegateQueue}; UIKit there =
        Main Thread Checker hit.}
  \trap{\textbf{Both key mechanisms}: with \texttt{.convertFromSnakeCase} the JSON key becomes
        \texttt{fullName} \emph{before} matching, so a raw value \texttt{"full\_name"} never matches.
        Acronyms: \texttt{user\_id} $\to$ \texttt{userId}, never \texttt{userID}.}
  \trap{\texttt{CodingKeys} is all-or-nothing: an omitted property needs a default value. A default
        does \emph{not} make a missing JSON key OK (\texttt{keyNotFound}); use an optional or \texttt{decodeIfPresent}.}
  \trap{Pinning needs \emph{your own} session with a delegate — \texttt{URLSession.shared} has none.
        Pin the \textbf{public key} (survives renewal) and ship $\geq 2$ pins (current + backup).}
  \trap{Forgot \texttt{task.resume()} — nothing happens, no error. One session per request = no
        connection reuse + leaked delegate (session retains it until \texttt{invalidateAndCancel}).}
\end{itemize}

\section{Remember}
\textbf{``Wire, Status, Shape.''} Did bytes arrive (\texttt{URLError})? Were they good
(\texttt{statusCode})? Do they fit (\texttt{DecodingError})? Then \textbf{Main}.
