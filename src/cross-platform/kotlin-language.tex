\sheettitle{Kotlin the language — for a Swift engineer}{cross-platform · folio}

\oneliner{Kotlin is Swift's closest cousin: \textbf{nullability in the type system},
\textbf{immutable-by-default bindings}, \textbf{sealed hierarchies + exhaustive
\texttt{when}}, extensions and trailing lambdas. The differences that matter:
\textbf{classes only} (no value-type structs — \texttt{data class} is a reference type),
\textbf{JVM generics are erased} (\texttt{reified} is the escape), extensions are
\textbf{statically dispatched}, and \texttt{internal} means \textbf{Gradle module}.}

\section{Null safety \& types}
\begin{itemize}\raggedright
  \item \texttt{String} never null, \texttt{String?} may be. \sq{} safe call, \elv{} Elvis
        (right side may \texttt{return}/\texttt{throw}), \bb{} = NPE if null (Swift
        \texttt{!}). Smart cast after \texttt{if (x != null)} / \texttt{is} — only for
        \texttt{val}s/locals the compiler can prove unchanged.
  \item \textbf{Platform types} \texttt{String!}: Java values without nullness annotations —
        the compiler trusts you; a null blows up at \emph{first use}, far from the cause.
  \item \texttt{val} = read-only reference (Swift \texttt{let}), \emph{not} deep immutability.
        \texttt{lateinit var}: non-null, set later, throws if read first.
  \item \eqeq{} calls \texttt{equals()}, \eqeqeq{} = same instance. \texttt{Unit} =
        \texttt{Void}, \texttt{Nothing} = \texttt{Never}. No checked exceptions.
\end{itemize}

\section{Classes}
\begin{itemize}\raggedright
  \item \textbf{final by default} — \texttt{open} to subclass. Visibility: \texttt{public}
        (default!), \texttt{internal} = same \textbf{module}, \texttt{protected} =
        subclasses, \texttt{private} top-level = file.
  \item \textbf{\texttt{data class}}: \texttt{equals}/\texttt{hashCode}/\texttt{toString}/
        \texttt{copy()}/\texttt{componentN()} from the \textbf{primary constructor only} —
        body properties ignored. Still a \emph{reference}: \texttt{copy} is shallow.
  \item \textbf{\texttt{sealed class/interface}}: subclasses known at compile time (same
        module + package) $\to$ \texttt{when} without \texttt{else}; exhaustiveness is an
        error for sealed/enum/Boolean subjects. Guards: \texttt{is A if x > 0 \ar{} …}
        (2.2). Swift \texttt{enum} with payloads $\approx$ sealed + \texttt{data class}es.
  \item \textbf{\texttt{@JvmInline value class}}: one property, unboxed at runtime (boxed
        when nullable/generic/as interface) — a zero-cost type-safe id.
  \item \texttt{object} = thread-safe lazy singleton; \texttt{companion object} = statics.
\end{itemize}

\section{Example}
\begin{lstlisting}[language=KotlinSheet]
@JvmInline value class UserId(val raw: String)
data class User(val id: UserId, val name: String?)
sealed interface Load<out T> {            // out: Load<Nothing> fits all
  data object Loading : Load<Nothing>
  data class Done<T>(val value: T) : Load<T>
  data class Failed(val e: Throwable) : Load<Nothing>
}
fun label(s: Load<User>): String = when (s) {   // no else needed
  Load.Loading -> "..."
  is Load.Done -> s.value.name?.uppercase() ?: "anon" // smart cast
  is Load.Failed -> s.e.message!!                // NPE if null
}
inline fun <reified T> Any.asOrNull(): T? = this as? T // T kept
val cfg by lazy { loadConfig() }          // once, SYNCHRONIZED
fun html(init: Html.() -> Unit) = Html().apply(init)   // DSL
\end{lstlisting}

\section{Functions, lambdas, delegation}
\begin{itemize}\raggedright
  \item \textbf{Extensions} compile to static functions taking the receiver:
        \textbf{resolved by the declared type}, never overridden; a \textbf{member always
        wins}. Nullable receivers OK (\texttt{String?.isNullOrEmpty()}).
  \item \textbf{\texttt{inline fun}} pastes body + lambda into the call site: no lambda
        object; \texttt{return} in the lambda returns from the \emph{caller} (non-local).
        \texttt{noinline} keeps a lambda as an object, \texttt{crossinline} bans non-local
        return. \textbf{\texttt{reified T}} (inline only) survives erasure: \texttt{is T},
        \texttt{T::class}.
  \item \textbf{Lambda with receiver} \texttt{T.() \ar{} R}: \texttt{this} is a \texttt{T} —
        \texttt{buildString}, Gradle Kotlin DSL, Compose scopes; \texttt{@DslMarker} stops
        outer receivers leaking in.
  \item \textbf{Delegation}: \texttt{by lazy} (\texttt{SYNCHRONIZED} default),
        \texttt{Delegates.observable} ($\approx$ \texttt{didSet}), \texttt{by map};
        \textbf{class delegation} \texttt{class Logged(d: Repo) : Repo by d} = free forwarding.
\end{itemize}

\textbf{Versions:} \textbf{K2} compiler (new FIR frontend) stable + default since
\textbf{Kotlin 2.0.0} (May 2024). Current \textbf{2.4.20} (Sep 2026); 2.4 made
\textbf{context parameters} (\texttt{context(log: Logger) fun …}) stable, 2.2 \texttt{when}
guards and non-local \texttt{break}/\texttt{continue}.

\section{Traps}
\begin{itemize}\raggedright
  \trap{``\texttt{data class} is a struct'' — no: shared reference, \texttt{copy()} shallow;
        a \texttt{var} in it breaks \texttt{HashSet} lookups after mutation.}
  \trap{Overriding an extension — impossible; the static type decides.}
  \trap{\bb{} to silence the compiler — use \elv, \sq{} or \texttt{requireNotNull(x)}.}
\end{itemize}

\textbf{Remember:} \emph{nulls in types · final + public by default · extensions static ·
erased unless reified.}
