\sheettitle{AI coding agents at work — loop, context, permissions, proof}{ai · folio}

\oneliner{A coding agent is a model calling tools \textbf{in a loop} inside a \textbf{harness} that
decides what each call may touch. You control the \textbf{context} it sees, the \textbf{permissions
and sandbox} around it and the \textbf{check} it must pass: rules files advise; permission rules,
hooks and sandboxes enforce; a test, build or screenshot proves.}

\section{Context is the budget}
\begin{itemize}
  \item The window holds system prompt, rules, tool schemas and \emph{every} message, file read and
        command output; quality degrades as it fills. Chroma's ``context rot'' (Jul 2025, 18
        models): accuracy falls with input length even on simple tasks.
  \item \textbf{One task per session}, \ct{/clear} between; after two failed corrections, clear and
        re-prompt with what you learned. Give exact paths, the full error, a screenshot.
  \item Keep exploration out: a \textbf{subagent} reads in its own window and returns a summary;
        skills and path-scoped rules load on demand. APIs newer than the training data (iOS 27
        SDK, Swift 6.4): hand it the docs page.
\end{itemize}

\section{Permissions \& sandboxes}
{\scriptsize\setlength{\tabcolsep}{2pt}
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{19mm}>{\raggedright\arraybackslash}p{59mm}@{}}
\toprule
\textbf{Claude Code mode} & \textbf{runs without asking}\\
\midrule
\ct{default} (Manual) & reads only\\
\ct{acceptEdits} & + edits, \ct{mkdir} \ct{touch} \ct{mv} \ct{cp} in the working dirs\\
\ct{plan} & reads; no source edits until the plan is approved\\
\ct{auto} & everything; a classifier model reviews risky actions\\
\ct{dontAsk} & only pre-approved tools, the rest denied — CI, scripts\\
\ct{bypassPermissions} & everything — isolated containers / VMs only\\
\bottomrule
\end{tabular}}
\begin{itemize}
  \item Rules: \textbf{deny $\to$ ask $\to$ allow, first match wins}, specificity ignored:
        \ct{Bash(aws *)} denied beats \ct{Bash(aws s3 ls)} allowed; deny holds in every mode.
        Enforced by the client, not the model.
  \item \textbf{Sandbox} (shell only, off by default; Seatbelt, bubblewrap): writes = working dir +
        temp; reads include \ct{\tld/.ssh}, \ct{\tld/.aws} until denied; network via a proxy,
        allow-list starts empty. File tools, MCP servers, hooks run \textbf{outside} it.
  \item \textbf{Codex}: sandbox \ct{read-only} · \ct{workspace-write} (no network) ·
        \ct{danger-full-access} × approvals \ct{on-request} · \ct{never} · granular.
\end{itemize}

\section{Failure modes $\to$ the check}
\begin{itemize}
  \item \textbf{Stale or invented API}, worst past the cutoff — compile, read the docs.
  \item \textbf{Silenced symptom}: \ct{@unchecked Sendable}, \ct{nonisolated(unsafe)}, \ct{try!},
        a weakened test — read the \emph{test} diff first.
  \item \textbf{Plausible, unverified}: demand evidence (test output, command + result,
        screenshot). ``If you can't verify it, don't ship it.''
  \item \textbf{Lost undo}: checkpoints miss changes made through Bash — commit often.
  \trap{A ``Never'' line in \ct{CLAUDE.md} as a security control; \ct{bypassPermissions} outside a
        VM; an unread MCP server — full access, outside the sandbox.}
\end{itemize}

\begin{itemize}
  \item JSON-RPC 2.0: \textbf{host} $\to$ a \textbf{client} per server $\to$ \textbf{server}:

  \item \textbf{2026-07-28}: no \ct{initialize}, no sessions — each request carries version +

\section{Security — the agent is an attack surface}

\begin{itemize}
  \item \textbf{Prompt injection} (OWASP LLM01:2025): orders hidden in a page, issue, README,
        dependency or tool result; RAG and fine-tuning do not fully mitigate it.
  \item \textbf{Hallucinated packages} (USENIX Sec.\ 2025; 16 models, 576\,000 samples): $\ge$5.2\,\%
        (commercial) / 21.7\,\% (open) of package names do not exist — 205\,474 an attacker can
        register. Check and pin each new dependency.
\end{itemize}
