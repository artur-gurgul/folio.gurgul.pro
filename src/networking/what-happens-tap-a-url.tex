\sheettitle{What happens when you tap a URL — end to end, in round trips}{networking · folio}

\oneliner{Before the first response byte, the phone may have to \textbf{wake its radio}, \textbf{resolve}
the name, open \textbf{TCP}, negotiate \textbf{TLS} and \textbf{send} the request — each step costs a network
\textbf{round trip (RTT)}. Cold over TCP + TLS 1.3: \textbf{4 RTT} + server time; HTTP/3: 3; a
\textbf{reused} connection: \textbf{1}. Every latency trick removes one of these rows.}

\hd{The nine steps}
\begin{enumerate}
  \item \textbf{Parse}: scheme, host, port, path (non-ASCII host $\to$ Punycode). A browser applies
        \textbf{HSTS} (incl. preload): \ct{http} $\to$ \ct{https} before any packet; an app's \textbf{ATS} refuses cleartext.
  \item \textbf{Caches first}: a fresh \ct{URLCache} hit returns with \emph{no} network
        (\ct{resourceFetchType == .localCache}); an open connection to the same origin in the
        session's pool skips steps 3–6 (\ct{isReusedConnection}).
  \item \textbf{Radio}: an idle modem (LTE \ct{RRC\_IDLE}; 5G adds \ct{RRC\_INACTIVE}) must be
        promoted to \ct{CONNECTED} before the first packet — latency first, the energy
        \emph{tail} afterwards.
  \item \textbf{DNS}: stub resolver (\ct{mDNSResponder} on Apple) cache $\to$ recursive resolver
        (carrier, 1.1.1.1, Private Relay) $\to$ root $\to$ TLD $\to$ authoritative. A, AAAA and, since
        iOS 14, \textbf{HTTPS} (type 65) records are asked in parallel; answers live for their TTL.
  \item \textbf{Connect}: \textbf{Happy Eyeballs} (RFC 8305) prefers IPv6, starts IPv4 250\,ms later if
        it is slow; TCP 3-way handshake $=$ 1 RTT.
  \item \textbf{TLS 1.3}: ClientHello (SNI, ALPN, key\_share) $\to$ Finished $=$ 1 RTT; chain + hostname
        checked; ALPN picks \ct{h2}.
  \item \textbf{Request}: HTTP/2 \ct{HEADERS} (HPACK) on a new stream $\to$ CDN edge / load balancer
        $\to$ app server $\to$ cache / DB. \textbf{TTFB} $=$ 1 RTT + server think time.
  \item \textbf{Response}: status + headers (\ct{Cache-Control}, \ct{ETag}, \ct{Content-Encoding})
        $\to$ decompress $\to$ stored in \ct{URLCache} $\to$ your code: status, decode, main actor.
  \item \textbf{Render}: browser — DOM + CSSOM, JS, layout, paint, composite; each sub-resource is
        another (pooled) request. App — decode off-main, diff, UI on main, pre-decode images.
\end{enumerate}

\hd{Example — where did the time go?}
\begin{lstlisting}[language=SwiftSheet]
func urlSession(_ s: URLSession, task: URLSessionTask,
                didFinishCollecting m: URLSessionTaskMetrics) {
  func ms(_ a: Date?, _ b: Date?) -> String {
    guard let a, let b else { return "-" }   // skipped step
    return "\(Int(b.timeIntervalSince(a) * 1000))" }
  for t in m.transactionMetrics {   // redirects = several
    print(t.networkProtocolName ?? "?", t.isReusedConnection,
      "dns", ms(t.domainLookupStartDate, t.domainLookupEndDate),
      "tcp", ms(t.connectStartDate, t.secureConnectionStartDate),
      "tls", ms(t.secureConnectionStartDate, t.secureConnectionEndDate),
      "ttfb", ms(t.requestStartDate, t.responseStartDate),
      "body", ms(t.responseStartDate, t.responseEndDate),
      t.isCellular, t.remoteAddress ?? "")  // v6 or v4?
  }
}
\end{lstlisting}

\hd{The mobile angle}
\begin{itemize}
  \item \textbf{Sequential calls multiply RTTs}: login $\to$ profile $\to$ feed $=$ 3 round trips
        minimum. Parallelise (\ct{async let}) or aggregate server-side (BFF, GraphQL).
  \item \textbf{Network switch} (Wi-Fi $\to$ cellular) kills every TCP connection: back to cold.
        HTTP/3 migrates by connection ID; \ct{multipathServiceType = .handover} (MPTCP) keeps TCP alive.
  \item \textbf{Lab $\neq$ field}: the simulator uses the Mac's network. Measure on a device, on
        cellular, and collect \ct{URLSessionTaskMetrics} in production (sampled).
  \item The first request after launch pays everything: warm the connection with the first
        needed call, not a dummy ping.
\end{itemize}

\hd{Traps}
\begin{itemize}
  \trap{``HTTPS is one handshake'' — TCP \emph{then} TLS: two RTTs before the request (QUIC merges them).}
  \trap{Timing with \ct{Date()} around \ct{data(for:)} mixes queueing, DNS and server time — use the metrics.}
  \trap{A pooled connection may already be closed by the server: \ct{-1005} (connection lost).
        URLSession retries it only for \textbf{idempotent} methods — a POST surfaces the error (QA1941).}
  \trap{``DNS is instant'' — a cold miss walks root $\to$ TLD $\to$ authoritative; bad Wi-Fi DNS stalls everything.}
\end{itemize}

\hd{Remember}
\textbf{``Wake, resolve, connect, secure, ask, render'' — each is a round trip until you reuse it.}
