\sheettitle{OpenTelemetry for mobile — one trace from tap to database}{engineering · folio}

\oneliner{\textbf{OpenTelemetry} (OTel) is the vendor-neutral standard for telemetry: an
\textbf{API} you instrument against, an \textbf{SDK} that samples, batches and exports, the
\textbf{OTLP} wire protocol and a \textbf{Collector}. A \textbf{trace} is a tree of
\textbf{spans} sharing one trace-id; the app starts it at the user's tap, and the W3C
\ct{traceparent} header carries it into every backend service — so one timeline shows
where the 3 seconds went.}

\hd{The model}
\begin{itemize}
  \item \textbf{Span} = name, trace-id, span-id, parent, \textbf{kind} (INTERNAL, CLIENT,
        SERVER, PRODUCER, CONSUMER), start/end, \textbf{attributes}, \textbf{events}
        (timestamped points), \textbf{links} (to other traces), \textbf{status} (Unset / Ok /
        Error). A \textbf{trace} = all spans with one trace-id.
  \item \textbf{Metrics}: counters, histograms, gauges — aggregated, cheap, never sampled.
        \textbf{Logs}: records stamped with trace/span id for correlation.
  \item \textbf{Resource} = who emitted it (\ct{service.name}, version, OS, device).
        \textbf{Semantic conventions} fix names: \ct{http.request.method}, \ct{url.full},
        \ct{http.response.status\_code}, \ct{session.id}.
  \item \textbf{API vs SDK}: libraries call only the API (no-op without an SDK); the app
        configures the SDK: provider, sampler, processors, exporter.
  \item \textbf{Context} holds the active span; a \textbf{propagator} injects it into requests
        and the server extracts it. \textbf{Baggage} (\ct{baggage} header): never PII.
\end{itemize}

\hd{Example — a manual root span (Swift)}
\begin{lstlisting}[language=SwiftSheet]
import OpenTelemetryApi
let tracer = OpenTelemetry.instance.tracerProvider
  .get(instrumentationName: "com.example.checkout",
       instrumentationVersion: "1.4.0")
let span = tracer.spanBuilder(spanName: "checkout.tap")
  .setSpanKind(spanKind: .internal)
  .setActive(true)             // URLSession spans become children
  .startSpan()
span.setAttribute(key: "cart.items", value: cart.count) // no PII
do { try await api.placeOrder(cart)    // CLIENT span + traceparent
     span.status = .ok }
catch { span.status = .error(description: "\(type(of: error))") }
span.end()                             // on EVERY path
\end{lstlisting}

\hd{Sampling — who decides what you pay for}
\begin{itemize}
  \item \textbf{Head} sampling: decided at the root, before the outcome is known —
        \ct{TraceIdRatioBased(0.1)} wrapped in \ct{ParentBased}, so every child (and the
        backend) follows the \ct{01} flag. Cheap, consistent, but blind to errors.
  \item \textbf{Tail} sampling: in the Collector after the trace completes — keep all errors,
        all traces > 2~s, 5\,\% of the rest. Needs every span of a trace on the same Collector
        (route by trace-id) and memory to wait.
  \item Mobile: head-sample on device (millions of devices, metered radios); errors and
        crashes via an always-on path.
\end{itemize}

\hd{Export from a phone}
\begin{itemize}
  \item \ct{BatchSpanProcessor} (queue + size/time flush); \ct{SimpleSpanProcessor} only for
        debugging. OTLP retries 429/502/503/504 with backoff; honour \ct{partial\_success}.
  \item Flush when the app backgrounds (short background task), buffer to disk offline,
        cap the queue (drop oldest, count drops), gzip, batch to save radio wake-ups.
  \item Send to \textbf{your} Collector/gateway: it authenticates the app, redacts, samples,
        and lets you switch vendors by config.
\end{itemize}

\hd{Privacy}
No PII in names, attributes, events, baggage: strip URL queries and ids, pseudonymise user
ids. Honour consent; redact again in the Collector; declare it in the privacy manifest.

\hd{Traps}
\begin{itemize}
  \trap{The backend starts a new trace — propagator not configured, or a proxy/CDN strips
        \ct{traceparent}. Check the header on the wire.}
  \trap{Device clocks drift: a child ``starts before'' its parent. Trust durations, not
        cross-device offsets.}
  \trap{User ids or raw URLs as \emph{metric} attributes — cardinality explosion; use route
        templates (\ct{/orders/\{id\}}).}
  \trap{A span not ended on the error path is never exported (and leaks).}
  \trap{Injecting \ct{traceparent} into third-party hosts: leaks ids, can break CORS/signing.}
\end{itemize}

\hd{Remember}
\textbf{Spans say what and how long, context says whose, \ct{traceparent} carries it across,
sampling decides what you pay for, the Collector decides where it goes.}
